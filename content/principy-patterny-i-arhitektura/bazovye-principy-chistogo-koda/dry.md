# Принцип DRY: не повторяйся

Почему копирование одинаковых кусков кода превращает мелкую правку в поиск ошибок по всему проекту и как правильно устранять дублирование?

**DRY** (*Don't Repeat Yourself* — «не повторяйся») — фундаментальный принцип разработки, согласно которому каждая единица знания или логики должна иметь единственное и однозначное представление в программе. Если один и тот же расчёт или проверка скопированы в несколько мест, любое изменение правил заставит искать и вручную обновлять все копии.

### Сравнение подходов

| Критерий | Нарушение DRY (копипаста) | Соблюдение DRY (единая логика) |
| --- | --- | --- |
| **Внесение изменений** | Приходится искать и править все копии по всему коду | Достаточно изменить логику ровно в одном месте |
| **Риск появления багов** | Высокий: легко забыть одну копию и получить рассинхрон | Минимальный: обновление сразу применяется везде |
| **Читаемость и объём** | Код раздувается от однотипных повторяющихся блоков | Код остаётся компактным и легко читается |
| **Инструменты решения** | Копирование и вставка (`Ctrl+C` / `Ctrl+V`) | Методы, циклы, константы, классы и общие модули |

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // ❌ ПЛОХО: формула расчёта скидки и налога продублирована дважды.
        // Если ставка налога изменится, придётся менять её в обоих местах.
        double cartPrice = 2000;
        double cartTotal = (cartPrice * 0.9) * 1.2;
        Console.WriteLine($"Итог в корзине: {cartTotal}");

        double checkoutPrice = 5000;
        double checkoutTotal = (checkoutPrice * 0.9) * 1.2;
        Console.WriteLine($"Итог при оплате: {checkoutTotal}");

        // ✅ ХОРОШО: логика вынесена в единый метод (единый источник правил)
        Console.WriteLine($"Итог в корзине: {CalculateFinalPrice(2000)}");
        Console.WriteLine($"Итог при оплате: {CalculateFinalPrice(5000)}");
    }

    static double CalculateFinalPrice(double basePrice)
    {
        const double discountMultiplier = 0.9; // Скидка 10%
        const double taxMultiplier = 1.2;      // Налог 20%
        return (basePrice * discountMultiplier) * taxMultiplier;
    }
}

```

### Важные нюансы

* **Правило трёх (Rule of Three):** не спешите создавать общую абстракцию при первом же повторе. Если фрагмент встретился дважды — иногда проще оставить его как есть, но когда одна и та же логика появляется в третий раз, её пора выносить в отдельный метод.
* **Случайное совпадение — не дублирование:** если два метода выглядят одинаково (например, `CalculateTax` и `CalculateDelivery` оба умножают сумму на `0.1`), но отвечают за разные бизнес-правила, объединять их нельзя — завтра налог изменится, а стоимость доставки останется прежней.
* **Опасность переусложнения:** попытка склеить непохожие процессы ради экономии пары строк приводит к громоздким методам со множеством флагов и условий `if-else`, которые сложнее поддерживать, чем два простых независимых блока.
* **Практическая реализация:** для устранения повторов в коде используйте вынесение логики в подпрограммы, циклы и именованные константы (см. раздел языка: *Объявление и вызов методов*).
