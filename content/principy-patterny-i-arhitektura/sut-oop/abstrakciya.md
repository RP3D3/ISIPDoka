# Абстракция: выделение главного

Как превратить сложный объект из реального мира в компактную программную модель и не утонуть в лишних деталях?

**Абстракция** — это способ упрощения сложной системы, при котором мы выделяем только те характеристики и действия объекта, которые важны для конкретной задачи, а все второстепенные детали отбрасываем. Один и тот же предмет реального мира в разных программах описывается по-разному: для игры в гонки у автомобиля важны скорость и управляемость, а для приложения такси — госномер, цвет и свободные места.

### Сравнение подходов

| Критерий | Избыточная модель (всё подряд) | Правильная абстракция |
| --- | --- | --- |
| **Состав данных** | В модель добавлены все возможные свойства реального объекта | Оставлены только поля, нужные для решения текущей задачи |
| **Управление объектом** | Внешний код должен знать внутреннее устройство и порядок шагов | Сложная механика скрыта за простыми и понятными действиями |
| **Сложность кода** | Модели перегружены лишними данными и запутанными связями | Код остаётся компактным, прозрачным и лёгким для расширения |
| **Зависимость от деталей** | Изменение внутренней реализации ломает остальной код | Программа работает с общим образом объекта и не зависит от деталей |

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // Один и тот же реальный автомобиль превращается в разные модели под разные задачи

        // 1. Для приложения такси важны только номер и статус «свободен/занят»
        TaxiCar taxi = new TaxiCar { PlateNumber = "А123ВС", IsAvailable = true };
        taxi.StartTrip("ул. Ленина, 10");

        // 2. Для автосервиса номер и маршрут не важны — нужны пробег и уровень масла
        ServiceCar repairCar = new ServiceCar { Mileage = 85000, OilLevelPercent = 25 };
        repairCar.RefillOil();
    }
}

// Абстракция автомобиля для службы такси (устройство двигателя отброшено)
class TaxiCar
{
    public string PlateNumber;
    public bool IsAvailable;

    public void StartTrip(string destination)
    {
        IsAvailable = false;
        Console.WriteLine($"Такси {PlateNumber} выехало по адресу: {destination}");
    }
}

// Абстракция того же автомобиля для автосервиса (пассажиры и адреса отброшены)
class ServiceCar
{
    public int Mileage;
    public int OilLevelPercent;

    public void RefillOil()
    {
        OilLevelPercent = 100;
        Console.WriteLine($"ТО выполнено на пробеге {Mileage} км: масло залито до {OilLevelPercent}%.");
    }
}

```

### Важные нюансы

* **Не существует «единственно верной» абстракции:** набор нужных характеристик всегда определяет задача. То, что является главным для бухгалтерии (оклад, ИНН, стаж), окажется лишним мусором для пропускной системы на входе в офис (номер пропуска и уровень доступа).
* **Две стороны абстракции:** первая — отбор только значимых данных об объекте при проектировании модели; вторая — сокрытие сложных внутренних шагов за одним простым действием (метод `StartTrip` сам меняет статус и оформляет выезд).
* **Связь с принципами YAGNI и KISS:** грамотная абстракция защищает от добавления характеристик «на всякий случай». Если свойство объекта нигде не участвует в расчётах или выводе — его стоит убрать из модели.
* **Практическая реализация:** в коде абстракция воплощается через проектирование классов, структур, абстрактных классов и интерфейсов (см. раздел языка: *Классы и объекты* и *Интерфейсы*).
