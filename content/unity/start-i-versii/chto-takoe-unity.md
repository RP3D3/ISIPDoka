# Что такое Unity

Unity — это среда для разработки игр и интерактивных приложений. Внутри неё есть
две большие части: **движок**, который во время игры считает физику, рисует кадры,
проигрывает звук и обрабатывает ввод, и **редактор**, в котором вы собираете сцену,
настраиваете объекты и пишете скрипты.

Для нас важно, что Unity не заменяет C#. Наоборот: игровая логика пишется на C#,
а Unity предоставляет готовые классы вроде `MonoBehaviour`, `Rigidbody`, `Transform`
и `InputAction`.

## Движок и редактор

**Редактор** — это программа, которую вы открываете через Unity Hub. В ней есть
окна Hierarchy, Scene, Game, Inspector, Project и Console. Вы расставляете объекты,
меняете их свойства и нажимаете Play.

**Движок** — это код, который выполняется в собранной игре или в режиме Play.
Он каждый кадр обновляет сцену, проверяет столкновения, вызывает методы ваших
скриптов и выводит изображение на экран.

Одна и та же сцена выглядит по-разному в редакторе и в игре: в редакторе вы видите
служебные рамки, стрелки и gizmos, а в игре — только то, что попало в камеру.

## Как Unity связан с C#

Скрипт Unity — это обычный класс C#, который наследуется от `MonoBehaviour`:

```csharp
using UnityEngine;

public class HelloUnity : MonoBehaviour
{
    private void Start()
    {
        Debug.Log("Привет, Unity!");
    }
}
```

Файл скрипта кладут в папку `Assets`, а затем добавляют компонентом на объект
сцены. Unity сама вызывает `Start`, `Update` и другие методы в нужный момент.
Подробно жизненный цикл разберём в группе «Скрипты и жизненный цикл».

## Из чего состоит игра

Основные кирпичи Unity:

- **Сцена** (`Scene`) — контейнер для одного уровня, меню или экрана.
- **GameObject** — объект на сцене: камера, свет, куб, персонаж, пустой
  контейнер.
- **Компонент** — часть GameObject: `Transform`, `MeshRenderer`, `Collider`,
  `Rigidbody`, ваш скрипт.
- **Ассет** — файл проекта: модель, текстура, материал, префаб, сцена, скрипт.
- **Префаб** (`Prefab`) — сохранённый шаблон GameObject, который можно
  многократно создавать на сценах.

## Почему Unity

- один проект можно собрать под Windows, macOS, Linux, Android, iOS и веб;
- есть 2D- и 3D-режимы;
- большой выбор готовых ассетов и обучающих материалов;
- C# — полноценный язык, а не «игровой скрипт» с урезанными возможностями;
- много вакансий и готовых решений для прототипов.

У Unity есть и минусы: редактор тяжеловат, версии и пакеты иногда отличаются,
а готовые ассеты могут быть платными. Но для обучения это удобный старт.

## Что важно понять сразу

1. **Unity — это не язык программирования.** Логику вы пишете на C#.
2. **GameObject — не класс, а объект на сцене.** Его поведение задают компоненты.
3. **Композиция важнее наследования.** Вместо огромной иерархии классов вы
   добавляете объекту нужные компоненты.
4. **Inspector — часть программирования.** Значения полей и ссылки на объекты
   часто настраиваются прямо в редакторе.
5. **Версия Unity важна.** Курс рассчитан на Unity 2022.3 LTS и Unity 6, а
   различия мы будем показывать явно.
