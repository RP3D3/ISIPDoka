# Сцена и окружение

Уровень начинается с блокинга: простые кубы и плоскости, чтобы проверить
масштаб, маршрут и расстояния. Красоту добавляем после того, как играбельно.

## Блокинг

1. Создайте плоскость `Ground`.
2. Расставьте кубы как стены и платформы.
3. Обозначьте старт, выход и точки предметов.
4. Пройдите уровень сами.
5. Только потом заменяйте кубы моделями.

Масштаб: персонаж примерно 2 метра, дверь — 2–2.5 метра, платформа — не выше
прыжка.

## Материалы

Создайте папку `Assets/Materials` и несколько материалов:

- `Ground`;
- `Wall`;
- `Danger`;
- `Pickup`.

Цвет помогает читать уровень: опасное — красное, предметы — яркие, выход —
зелёный.

## Свет

Для старта достаточно:

- `Directional Light` — общий свет;
- несколько `Point Light` или `Spot Light` — акценты;
- `Ambient` в настройках освещения.

Не делайте слишком тёмную сцену: игрок должен видеть маршрут.

## Коллайдеры

- стены и пол — `BoxCollider`;
- сложные модели — `MeshCollider` с осторожностью;
- триггеры — `isTrigger`;
- опасные зоны — `BoxCollider` с `isTrigger`.

Проверьте, что игрок не проходит сквозь стены и не застревает в углах.

## Чекпоинты

Простой чекпоинт — триггер, который сохраняет позицию возрождения:

```csharp
using UnityEngine;

public class Checkpoint : MonoBehaviour
{
    private void OnTriggerEnter(Collider other)
    {
        if (other.TryGetComponent(out PlayerRespawn respawn))
        {
            respawn.SetCheckpoint(transform.position);
        }
    }
}
```

## Частые ошибки

- **Слишком большой уровень.** Игрок теряется.
- **Нет ориентиров.** Все стены одинаковые.
- **Тёмная сцена.** Маршрут не виден.
- **Коллайдеры не совпадают с моделями.** Игрок проваливается или застревает.
- **Нет чекпоинтов.** После смерти начинать сначала больно.
