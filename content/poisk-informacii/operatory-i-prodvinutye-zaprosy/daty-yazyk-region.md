# Даты, язык и регион

Для многих вопросов важна свежесть. Для других — местный контекст.
Поисковики позволяют учитывать и то, и другое.

## Даты

В некоторых системах работают операторы:

```text
python 3.13 after:2025-01-01
javascript before:2024-01-01
```

Или фильтр по времени в интерфейсе: за день, неделю, месяц, год.

## Язык

Можно искать:

- только на русском;
- только на английском;
- на любом языке.

Для технических тем английский часто полезнее. Для локальных — русский.

## Регион

Регион влияет на:

- законы;
- сервисы;
- цены;
- новости;
- доступность.

## Частые ошибки

- **Искать устаревшее решение без даты.**
- **Считать, что фильтр «за год» всегда лучше.** Иногда нужна классика.
- **Игнорировать локальные нормы.**
- **Забывать, что операторы дат поддерживаются не везде.**
