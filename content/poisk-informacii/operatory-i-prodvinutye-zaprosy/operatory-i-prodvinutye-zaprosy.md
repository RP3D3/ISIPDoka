# Операторы и продвинутые запросы

Операторы помогают управлять поиском, но не заменяют понимание задачи.

## Что запомнить

| Оператор | Что делает |
|---|---|
| `"..."` | точная фраза |
| `site:` | только этот сайт |
| `filetype:` | только этот формат |
| `-слово` | исключить слово |
| `OR` | альтернативы |
| `intitle:` | слово в заголовке |
| `inurl:` | слово в URL |
| `allintext:` | все слова в тексте |

## Как использовать

1. Начните с простого запроса.
2. Добавьте один оператор.
3. Проверьте выдачу.
4. Уберите лишнее.
5. Повторите.

## Частые ошибки

- **Пробел после двоеточия.**
- **Слишком много операторов.**
- **Опора только на операторы без проверки источника.**
- **Ожидание одинакового синтаксиса во всех поисковиках.**
