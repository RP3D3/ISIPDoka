# Поиск информации и работа с источниками: план области

Область учит не «трюкам Google», а полному циклу работы с информацией:
сформулировать вопрос, найти источники, проверить их, сохранить и
использовать без искажений.

## Группы

### 10. Основы поиска

Зачем нужен поиск, как работает выдача, ключевые слова, уточнение
запроса, язык и регион, персонализация, первичная оценка результатов.

Итог: практика — сформулировать запрос.

### 20. Операторы и продвинутые запросы

Кавычки, `site:`, `filetype:`, минус-слова, `OR`, `intitle`, `inurl`,
даты, комбинирование операторов.

Итог: практика — операторы поиска.

### 30. Поиск для разработчика

Официальная документация, ошибки и стек-трейсы, GitHub, Stack Overflow,
changelog, RFC, API-справочники, поиск по исходникам.

Итог: практика — найти решение ошибки.

### 40. Оценка источников

Автор, дата, первоисточник, репутация, предвзятость, реклама,
AI-контент, перекрёстная проверка.

Итог: практика — проверить источник.

### 50. Научный и профессиональный поиск

Google Scholar, arXiv, PubMed, DOI, ключевые слова, цитирование,
snowballing, систематический поиск, чтение статьи.

Итог: практика — найти статью.

### 60. Поиск с помощью ИИ

Как отвечает LLM, формулировка запроса, проверка ответов, галлюцинации,
цитаты, приватность, AI-агенты.

Итог: практика — проверить ответ ИИ.

### 70. Сохранение и организация

Закладки, read-later, заметки, теги, Zotero, Obsidian, поиск по своим
материалам, архивирование.

Итог: практика — собрать подборку.

### 80. Этика и безопасность

Авторское право, цитирование, плагиат, приватность, трекеры, фишинг,
дезинформация, безопасный поиск.

Итог: практика — безопасный поиск.

### 90. Практика: исследование

План исследования, сравнение источников, итог области и практика:
исследование по задаче.

## Правила

- 2 квиза на тему: radio (3 варианта, 1 правильный) и checkbox
  (4 варианта, 2–3 правильных).
- В каждой теме есть раздел «Частые ошибки».
- Итог группы называется так же, как группа.
- Практика начинается со слова «Практика».
- Картинки — авторские SVG-схемы, без внешних хотлинков.
- Ссылки только на существующие темы области.
- Примеры поисковых запросов даются в виде текста, без привязки к
  конкретному интерфейсу поисковика.
- Учитываем русский и английский языки, но не требуем идеального
  английского.
- AI рассматривается как инструмент поиска, а не как источник истины.

## Главный принцип

**Вопрос → ключевые слова → источник → проверка → сохранение → цитирование.**

Поиск — это не одно нажатие кнопки, а управляемый процесс.
