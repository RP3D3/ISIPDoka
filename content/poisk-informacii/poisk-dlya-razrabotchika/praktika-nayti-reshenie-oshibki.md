# Практика: найти решение ошибки

Возьмите реальную ошибку из учебного проекта или используйте пример.

## Ошибка

```text
TypeError: Cannot read properties of undefined (reading 'map')
```

## 1. Уточните контекст

Запишите:

- язык и версию;
- библиотеку;
- где происходит ошибка;
- что вы ожидали.

## 2. Найдите официальную документацию

Ищите метод или API, который используется в строке с ошибкой.

## 3. Поищите точный текст

```text
"TypeError: Cannot read properties of undefined (reading 'map')"
```

Добавьте название библиотеки и версию.

## 4. Проверьте GitHub

Ищите issues с таким же сообщением. Смотрите дату и статус.

## 5. Сравните ответы

- совпадает ли версия;
- есть ли объяснение;
- есть ли тест;
- можно ли воспроизвести.

## 6. Проверьте у себя

Сделайте минимальный пример. Если не воспроизводится — измените условия.

## Что записать

- [ ] Первоисточник.
- [ ] Причина ошибки.
- [ ] Проверенное решение.
- [ ] Что не сработало.
- [ ] Ссылка на документацию.

## Частые ошибки

- **Копировать ответ без проверки.**
- **Искать только по форумам.**
- **Не указывать версию.**
- **Не делать минимальный пример.**
