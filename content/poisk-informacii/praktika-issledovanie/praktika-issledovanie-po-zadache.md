# Практика: исследование по задаче

Выберите задачу и пройдите полный цикл.

## Задача

> Нужно выбрать способ кэширования для небольшого REST API.

## 1. Вопрос

Сформулируйте основной вопрос и 3–4 подвопроса.

## 2. План

- какие источники нужны;
- какие критерии;
- какой срок;
- какой формат результата.

## 3. Поиск

Найдите:

- официальную документацию;
- 1–2 статьи;
- пример кода;
- обсуждение проблем.

## 4. Сравнение

Сравните по критериям:

- автор;
- дата;
- метод;
- ограничения;
- применимость.

## 5. Вывод

Напишите:

- рекомендацию;
- почему;
- риски;
- что проверить перед внедрением.

## 6. Ссылки

Оформите список источников с датами.

## Чек-лист

- [ ] Есть вопрос и подвопросы.
- [ ] Есть несколько источников.
- [ ] Источники проверены.
- [ ] Противоречия указаны.
- [ ] Вывод связан с источниками.
- [ ] Есть ссылки.

## Частые ошибки

- **Собрать ссылки без вопроса.**
- **Сравнить только один источник.**
- **Скрыть риски.**
- **Не указать дату.**
