# Практика: безопасный поиск

Выполните три проверки.

## 1. Ссылка

Возьмите любую ссылку из письма или чата.

- [ ] Проверьте домен.
- [ ] Проверьте, куда ведёт сокращённая ссылка.
- [ ] Не вводите пароль, если есть сомнения.
- [ ] Откройте сайт вручную, если это известный сервис.

## 2. Приватность

- [ ] Проверьте настройки трекеров.
- [ ] Очистите историю, если нужно.
- [ ] Проверьте, какие расширения имеют доступ.
- [ ] Не отправляйте личные данные в поиск и ИИ.

## 3. Новость

Возьмите новость и проверьте:

- [ ] Есть ли автор.
- [ ] Есть ли дата.
- [ ] Есть ли первоисточник.
- [ ] Что говорят независимые источники.
- [ ] Не вырвана ли цитата из контекста.

## Вывод

Запишите:

- что оказалось безопасным;
- что подозрительным;
- какие настройки вы изменили.

## Частые ошибки

- **Проверять только логотип.**
- **Считать HTTPS гарантией.**
- **Делиться новостью без чтения.**
- **Игнорировать настройки приватности.**
