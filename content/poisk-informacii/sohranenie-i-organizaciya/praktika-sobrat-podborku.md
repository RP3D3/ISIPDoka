# Практика: собрать подборку

Выберите тему и соберите 5–7 источников.

## 1. Тема

Например:

> Как работает кэширование HTTP.

## 2. Источники

Соберите:

- официальную документацию;
- одну статью;
- один пример кода;
- один научный или технический обзор.

## 3. Для каждого источника

- автор;
- дата;
- ссылка;
- главная мысль;
- почему выбрали;
- статус проверки.

## 4. Заметки

Напишите 3–5 заметок своими словами. Не копируйте текст.

## 5. Теги

Используйте 2–3 тега:

```text
#http
#caching
#web
```

## 6. Резервная копия

Сохраните важные страницы в PDF или Markdown. Проверьте, что файлы
открываются.

## Что проверить

- [ ] У каждого источника есть ссылка.
- [ ] Есть дата.
- [ ] Есть заметка своими словами.
- [ ] Теги единые.
- [ ] Есть резервная копия.

## Частые ошибки

- **Собрать ссылки без заметок.**
- **Не указать дату.**
- **Использовать разные теги для одного.**
- **Не сделать копию.**
