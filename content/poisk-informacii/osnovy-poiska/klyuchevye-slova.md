# Ключевые слова и смысл запроса

Поисковик не понимает вопрос так же, как человек. Ему нужны слова,
которые встречаются в нужных источниках.

## Шаг 1. Сформулируйте вопрос

Не «как сделать сайт», а:

> Как подключить базу данных PostgreSQL к приложению на Python?

## Шаг 2. Выделите понятия

- PostgreSQL;
- Python;
- подключение;
- драйвер;
- пример.

## Шаг 3. Добавьте синонимы

- подключение → соединение, connection;
- драйвер → library, adapter;
- пример → example, tutorial.

## Шаг 4. Уберите лишнее

Слова «пожалуйста», «подскажите», «очень нужно» обычно не помогают
поиску.

## Шаг 5. Проверьте варианты

Сделайте 2–3 запроса:

```text
PostgreSQL Python connection example
psycopg2 подключение к PostgreSQL пример
python postgres connection string
```

## Частые ошибки

- **Писать целый вопрос разговорным языком.** Поисковик может понять, но
  ключевые слова работают точнее.
- **Использовать только один термин.** Синонимы расширяют охват.
- **Игнорировать английский.** Многие библиотеки документированы на нём.
- **Не проверять опечатки.** Иногда ошибка в слове ломает запрос.
