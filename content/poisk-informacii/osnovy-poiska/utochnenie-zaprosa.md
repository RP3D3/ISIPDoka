# Уточнение и сужение запроса

Первый запрос почти всегда неточный. Нормальный поиск — это несколько
итераций, а не один идеальный запрос.

## Если результатов слишком много

Добавьте контекст:

- язык или технологию;
- версию;
- тип источника;
- точную фразу;
- исключение лишнего.

```text
python asyncio timeout
python 3.12 asyncio timeout example
"asyncio.TimeoutError" python 3.12
```

## Если результатов слишком мало

- уберите лишние операторы;
- проверьте опечатки;
- замените термин синонимом;
- попробуйте английский;
- ищите по точной ошибке.

## Если ответ не тот

Спросите себя:

- правильно ли я понял задачу;
- тот ли это инструмент;
- не устарел ли ответ;
- не решаю ли я другую проблему.

## Частые ошибки

- **Сдаваться после одного запроса.**
- **Добавлять сразу десять операторов.**
- **Искать по общим словам без контекста.**
- **Не проверять версию.** Ответ для старой версии может не работать.
