# Практика: сформулировать запрос

Возьмите вопрос и сделайте для него несколько запросов.

## Вопрос

> Как в Python прочитать JSON-файл и обработать ошибку, если файл
> повреждён?

## Шаг 1. Ключевые слова

- Python;
- JSON;
- read file;
- decode error;
- exception.

## Шаг 2. Русский запрос

```text
Python чтение JSON файла обработка ошибки повреждённый файл
```

## Шаг 3. Английский запрос

```text
python read json file handle decode error
```

## Шаг 4. Точный запрос

```text
python json.JSONDecodeError read file example
```

## Шаг 5. Сравните

Для каждого запроса запишите:

- сколько результатов вы просмотрели;
- какие источники оказались полезными;
- где был официальный ответ;
- что пришлось уточнить.

## Что проверить

- [ ] Есть 3 разных запроса.
- [ ] Использованы синонимы.
- [ ] Есть русский и английский варианты.
- [ ] Вы открыли хотя бы 3 источника.
- [ ] Вы нашли официальную документацию.

## Частые ошибки

- **Сделать один запрос и остановиться.**
- **Не использовать английские термины.**
- **Смотреть только сниппеты.**
- **Не проверять версию Python.**
