# Поиск с ИИ vs обычный поиск

ИИ хорош для объяснений и черновиков. Поисковик — для свежих фактов и
ссылок. Часто нужен оба.

## Обычный поиск

- свежие данные;
- ссылки на источники;
- разные точки зрения;
- проверка факта;
- официальные документы.

## ИИ

- объяснение;
- структура;
- пример;
- переписывание;
- генерация вопросов.

## Гибрид

1. Спросите ИИ, как искать.
2. Найдите источники в поиске.
3. Проверьте ответ.
4. Попросите ИИ объяснить сложное.
5. Снова проверьте.

## Частые ошибки

- **Использовать ИИ для свежих фактов без проверки.**
- **Искать только в поисковике, когда нужно объяснение.**
- **Не просить источники.**
- **Не проверять ответ.**
