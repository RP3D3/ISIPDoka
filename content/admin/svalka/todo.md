## C#
- Асинхронность (async / await и Task): главный пробел. Современный C# в бэкенде и десктопе почти полностью асинхронный; без понимания задач и CancellationToken пройти техническое интервью крайне сложно.
- Устройство .NET и память: понимание работы сборщика мусора (Garbage Collector), интерфейса IDisposable (как его правильно реализовывать, а не только вызывать через using) и базового устройства CLR.   
- Прикладной фреймворк: «голый» C# в вакууме на рынке не востребован. После этой базы нужно выбрать направление — например, ASP.NET Core + Entity Framework Core + SQL (для бэкенда), Avalonia / WPF (для десктопа) или Unity (для геймдева).
- Инженерный минимум: работа с Git, понимание принципов SOLID, внедрение зависимостей (Dependency Injection) и написание простых модульных тестов (xUnit или NUnit).
