# Привет, мир!

Минимальная рабочая программа на C#, вывод текста в терминал и разница между современным синтаксисом в одну строчку и классическим методом `Main`.

## Кратко

В современном C# первая программа занимает ровно одну строчку без классов, пространств имён и шаблонных обёрток: [Интерактив: цикл for по шагам](content/csharp/osnovy/interactive-example.html)

```cs
Console.WriteLine("Привет, мир!");
```

Вызывается системный класс `Console`, запускается метод `WriteLine()`, и переданный в кавычках текст выводится в окно терминала. Всё остальное платформа делает сама.

## Анатомия одной строки

Даже в одной команде задействованы базовые правила синтаксиса языка:

- `Console` — встроенный статический класс платформы .NET, отвечающий за стандартный ввод и вывод.
- `.WriteLine(...)` — вызов метода, который отправляет строку в терминал и сразу переводит курсор на новую строку.
- `"Привет, мир!"` — строковый литерал. Текст всегда оборачивается в двойные кавычки.
  - `;` — обязательный разделитель. Каждая инструкция в C# завершается точкой с запятой.

1. 123
2. 3214
3. 4324

## Top-level statements против классики

До версии C# 9 даже для вывода одного слова требовалось строить громоздкий каркас. Сейчас этот механизм автоматизирован с помощью **инструкций верхнего уровня** (*Top-level statements*).

### Классический шаблон: как было раньше

```cs
using System;

namespace HelloWorldApp
{
    internal class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Привет, мир!");
        }
    }
}
```

### Современный подход: как устроено сейчас

Начиная с C# 9 и .NET 6, весь файл `Program.cs` может состоять только из рабочих команд. Компилятор сам «оборачивает» код в невидимый класс и синтезирует метод точки входа.

## Сравнение стилей точки входа

| Критерий | Top-level statements | Классический Program.Main |
|---|---|---|
| Размер кода | Только рабочие инструкции | Обязательны namespace, class и метод Main |
| Где создаётся точка входа | Синтезируется компилятором неявно | Пишется разработчиком явно |
| Лимит файлов | Строго один файл на весь проект | Метод Main в выбранном классе |
