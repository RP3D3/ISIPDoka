# Основы Python

Главная идея группы: Python прост снаружи, но требует дисциплины в
структуре, типах и обработке ошибок.

## Что запомнить

- отступы — часть синтаксиса;
- типы определяются значением;
- списки изменяемы, кортежи нет;
- словарь хранит пары ключ — значение;
- функция возвращает результат;
- ошибки ловят конкретно;
- логи важнее `print`.

## Чек-лист

- [ ] Я могу запустить `.py` файл.
- [ ] Я понимаю отступы.
- [ ] Я не путаю список и кортеж.
- [ ] Я умею читать словарь.
- [ ] Я пишу функции с `return`.
- [ ] Я не ловлю все ошибки подряд.

## Частые ошибки

- **Смешивать табы и пробелы.**
- **Путать `=` и `==`.**
- **Менять список во время итерации.**
- **Молча проглатывать исключения.**
