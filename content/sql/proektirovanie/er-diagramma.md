# ER-диаграмма

Как показать связи между таблицами на одной картинке, чтобы вся команда понимала схему одинаково?

ER-диаграмма (Entity-Relationship) — это схема сущностей и связей. Прямоугольники — таблицы, линии — связи, подписи на концах — кардинальность: один, много, ноль или один. Она помогает заметить пропущенную связь до того, как появится код.

## Простая диаграмма

```text
customers 1 ──── N orders 1 ──── N order_items N ──── 1 drinks
    │                                                      │
    │ 1                                                    │ N
    │                                                      │
    N reviews N ────────────────────────────────────────────┘
```

Читается так:

- у клиента много заказов;
- у заказа много позиций;
- каждая позиция ссылается на один напиток;
- клиент и напиток связаны через отзывы.

## Кардинальность

| Запись | Значение |
| --- | --- |
| `1 — 1` | один к одному |
| `1 — N` | один ко многим |
| `N — M` | многие ко многим |
| `0..1` | необязательная связь |

## Текстовая версия для документации

```text
customers(id, name, email, created_at)
  1:N orders(customer_id)
  1:N addresses(customer_id)
  1:N reviews(customer_id)

orders(id, customer_id, status, total, created_at)
  1:N order_items(order_id)

drinks(id, name, category, price, is_active)
  1:N order_items(drink_id)
  1:N reviews(drink_id)
  M:N ingredients через drink_ingredients
```

Такую запись удобно хранить рядом с миграциями: она не устаревает так быстро, как картинка.

## Что должно быть на диаграмме

- Все таблицы с первичными ключами.
- Внешние ключи и направления связей.
- Кардинальность.
- Промежуточные таблицы для M:N.
- Важные уникальные ограничения.

## Грабли

* **Диаграмма без кардинальности.** Линия без подписи не говорит, один это или много.
* **Забытая промежуточная таблица.** M:N нельзя нарисовать двумя стрелками.
* **Диаграмма устарела.** Если она не обновляется вместе с миграциями, ей перестают верить.
* **Слишком много деталей.** Все индексы и типы на одной картинке делают её нечитаемой.
* **Разные нотации.** Договорись о нотации в команде, иначе стрелки понимают по-разному.
