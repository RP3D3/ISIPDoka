# INSERT

Как добавить один напиток, сразу несколько или целую пачку из другого запроса?

`INSERT` добавляет строки в таблицу. Ты перечисляешь столбцы и значения. Всё, что не указано, получает `DEFAULT` или `NULL`, если ограничение позволяет. Если указать столбцы явно, вставка не сломается от нового столбца в таблице.

## Синтаксис

```sql
INSERT INTO таблица (столбец1, столбец2)
VALUES (значение1, значение2);
```

Несколько строк сразу:

```sql
INSERT INTO таблица (столбец1, столбец2)
VALUES
    (значение1, значение2),
    (значение3, значение4);
```

Из результата другого запроса:

```sql
INSERT INTO таблица (столбец1, столбец2)
SELECT столбец1, столбец2
FROM другая_таблица
WHERE условие;
```

## Пример

Добавим новый напиток:

```sql
INSERT INTO drinks (name, category, price)
VALUES ('Раф', 'кофе', 330.00)
RETURNING id, name, price;
```

| id | name | price |
| --- | --- | --- |
| 9 | Раф | 330.00 |

`id` база выдала сама через `IDENTITY`. `RETURNING` вернул строку, чтобы приложение сразу узнало номер.

Несколько напитков одной командой:

```sql
INSERT INTO drinks (name, category, price)
VALUES
    ('Флэт уайт', 'кофе', 300.00),
    ('Молочный улун', 'чай', 280.00)
RETURNING id, name;
```

| id | name |
| --- | --- |
| 10 | Флэт уайт |
| 11 | Молочный улун |

## INSERT ... SELECT

Скопируем все чаи под новым именем:

```sql
INSERT INTO drinks (name, category, price)
SELECT name || ' (новинка)', category, price
FROM drinks
WHERE category = 'чай';
```

Так наполняют таблицы из других таблиц или из результата сложного запроса. Главное — количество и типы столбцов должны совпадать.

## Грабли

* **Забыть список столбцов.** `INSERT INTO drinks VALUES (...)` зависит от порядка столбцов в таблице. Добавили новый столбец — вставка сломалась.
* **Нарушить `NOT NULL` или `UNIQUE`.** База откажет. Это хорошо: ограничения работают.
* **Явно вставлять `id` в `IDENTITY`.** Обычно не нужно. Если очень надо, используй `OVERRIDING SYSTEM VALUE`.
* **Перепутать порядок значений.** `VALUES (330.00, 'Раф')` при столбцах `(name, price)` даст ошибку типа или бессмыслицу.
* **Вставлять в неправильную схему.** Проверь `search_path` или указывай `shop.drinks` явно.
* **`INSERT ... SELECT` без `WHERE`.** Можно случайно скопировать всю таблицу.
