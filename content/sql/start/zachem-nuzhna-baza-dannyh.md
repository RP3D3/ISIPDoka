# Зачем нужна база данных

Почему хранение заказов в общем Excel рано или поздно заканчивается потерянными данными?

База данных — это программа, которая хранит данные, следит за правилами и даёт всем пользователям одновременный доступ без потерь. В отличие от файла на диске, она не просто хранит данные, а гарантирует, что два человека не перезапишут друг друга и что в заказе не появится товар с отрицательной ценой.

## Три способа хранения

| Способ | Одновременная работа | Проверка правил | Запросы |
| --- | --- | --- | --- |
| CSV / JSON | Последний записавший побеждает | Нет | Нужно писать код |
| Excel / Google Sheets | Конфликты при сохранении | Почти нет | Вручную |
| Реляционная база | Транзакции и блокировки | Ограничения на уровне схемы | SQL |

Файл удобен для отчёта на 20 строк. Excel — для таблицы, которую смотрит один человек. База нужна, когда данные меняются из приложения, у них есть связи и ошибка стоит денег.

## Что именно берёт на себя база

- **Целостность.** Внешний ключ не даст создать заказ для несуществующего клиента.
- **Одновременность.** Два официанта могут оформить заказы, и оба сохранятся.
- **Атомарность.** Заказ и его позиции записываются вместе или не записываются вовсе.
- **Запросы.** Вместо ручного пересчёта — `SELECT`, который сразу возвращает выручку.

```sql
SELECT COUNT(*) AS orders_count
FROM orders;
```

| orders_count |
| --- |
| 128 |

## Грабли

* **База — не Excel.** В ней нет «ячеек» с разными типами и формулами. Каждый столбец имеет один тип.
* **База — не файл.** Она работает как сервер: к ней подключаются приложение и клиенты.
* **База не заменяет приложение.** Она хранит факты и правила, а бизнес-логика остаётся в коде.
