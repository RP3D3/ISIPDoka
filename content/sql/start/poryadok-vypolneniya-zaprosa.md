# Порядок выполнения запроса

Почему `WHERE` не видит псевдоним из `SELECT`, а `ORDER BY` видит — и что вообще происходит после нажатия Enter?

SQL пишут сверху вниз, но база выполняет его в другом порядке. Если держать этот порядок в голове, половина ошибок новичка объясняется сама: «почему здесь нельзя агрегат», «почему псевдоним не найден», «почему фильтр сработал не там».

## Логический порядок

1. `FROM` — берём таблицы и соединяем их.
2. `WHERE` — отбрасываем строки.
3. `GROUP BY` — собираем строки в группы.
4. `HAVING` — отбрасываем группы.
5. `SELECT` — вычисляем столбцы и псевдонимы.
6. `DISTINCT` — убираем дубликаты.
7. `ORDER BY` — сортируем результат.
8. `LIMIT` / `OFFSET` — обрезаем строки.

## Пример

```sql
SELECT category, COUNT(*) AS drinks_count
FROM drinks
WHERE is_active = true
GROUP BY category
HAVING COUNT(*) >= 2
ORDER BY drinks_count DESC
LIMIT 3;
```

| category | drinks_count |
| --- | --- |
| кофе | 6 |
| чай | 4 |
| напиток | 2 |

Что происходит по шагам:

1. `FROM drinks` — база берёт таблицу напитков.
2. `WHERE is_active = true` — оставляет только активные.
3. `GROUP BY category` — складывает их в группы по категориям.
4. `HAVING COUNT(*) >= 2` — выкидывает категории с одной позицией.
5. `SELECT` — считает количество в каждой группе и даёт столбцу имя `drinks_count`.
6. `ORDER BY drinks_count DESC` — сортирует уже готовый результат.

## Почему это важно

- **Псевдоним из `SELECT` не работает в `WHERE`.** На шаге `WHERE` столбца `drinks_count` ещё не существует.
- **Агрегат нельзя фильтровать в `WHERE`.** `COUNT(*)` появляется только после `GROUP BY`, поэтому для групп есть `HAVING`.
- **`ORDER BY` может использовать псевдоним.** Сортировка выполняется после `SELECT`, когда имя уже известно.

## Грабли

* **`LIMIT` без `ORDER BY`** возвращает произвольные строки: база не обязана хранить порядок.
* **`WHERE` и `HAVING` — не взаимозаменяемы.** Фильтр по обычному столбцу лучше ставить в `WHERE`: он отсекает строки раньше и работает быстрее.
* **`SELECT` не первый.** Если думать, что база начинает с него, непонятно, откуда берутся таблицы и почему фильтр не видит псевдоним.
