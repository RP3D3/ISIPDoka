# Выражения, CAST и псевдонимы

Как посчитать цену с наценкой, округлить до копеек и подписать результат, не потеряв деньги на делении?

В `SELECT` можно не только перечислять столбцы, но и вычислять новые: умножать, складывать, склеивать текст, приводить типы. Выражение выполняется для каждой строки и возвращает новый столбец. Псевдоним `AS` даёт этому столбцу имя, а `CAST` объясняет базе, какого типа должен быть результат.

## Как это работает

Представь калькулятор, который считает не одно число, а сразу всю таблицу. Для каждой строки он берёт значения, подставляет в формулу и выдаёт результат. Формула может быть арифметической (`price * 1.15`), текстовой (`name || ' — ' || category`) или логической (`price > 300`).

Тип результата важен. `INTEGER / INTEGER` в PostgreSQL даёт целое число: `5 / 2 = 2`, а не `2.5`. Для точного деления хотя бы один операнд должен быть `NUMERIC` или `FLOAT`.

## Синтаксис

```sql
SELECT
    столбец,
    выражение AS псевдоним,
    CAST(выражение AS тип) AS другой_псевдоним
FROM таблица;
```

| Приём | Пример | Результат |
| --- | --- | --- |
| Арифметика | `price * 1.15` | `322.00` для 280 |
| Округление | `ROUND(price * 1.15, 2)` | `322.00` |
| Конкатенация | `name \|\| ' ₽'` | `'Капучино ₽'` |
| Приведение | `price::text` | `'280.00'` |
| `CAST` | `CAST(price AS TEXT)` | `'280.00'` |
| Псевдоним | `price AS base_price` | заголовок `base_price` |

`::` — короткая форма `CAST`, принятая в PostgreSQL.

## Пример

```sql
SELECT
    name,
    price AS base,
    ROUND(price * 1.15, 2) AS with_vat,
    price::text || ' ₽' AS label
FROM drinks
WHERE is_active
ORDER BY with_vat DESC
LIMIT 3;
```

| name | base | with_vat | label |
| --- | --- | --- | --- |
| Матча-латте | 320.00 | 368.00 | 320.00 ₽ |
| Латте | 310.00 | 356.50 | 310.00 ₽ |
| Капучино | 280.00 | 322.00 | 280.00 ₽ |

Столбцы `base`, `with_vat` и `label` существуют только в результате запроса. В таблице `drinks` их нет, и после запроса они никуда не сохраняются.

## Где работает псевдоним

| Место | Виден ли псевдоним |
| --- | --- |
| `ORDER BY` | да, выполняется после `SELECT` |
| `GROUP BY` | да, в PostgreSQL |
| `WHERE` | нет, выполняется до `SELECT` |
| `HAVING` | да, в PostgreSQL |

Если псевдоним нужен в `WHERE`, повтори выражение или оберни запрос в подзапрос.

## Грабли

* **Целочисленное деление.** `5 / 2` вернёт `2`. Для дробного результата пиши `5::numeric / 2` или `5.0 / 2`.
* **`FLOAT` для денег.** Двоичная дробь не хранит копейки точно. Для цен — `NUMERIC`.
* **Конкатенация с `NULL`.** `name || NULL` даёт `NULL`, а не имя. Если пустое значение нужно заменить, используй `COALESCE(name, '')`.
* **`CAST` не всесилен.** `'двадцать'::int` вызовет ошибку. Приведение текста к числу требует, чтобы текст действительно был числом.
* **Псевдоним в `WHERE`.** `WHERE with_vat > 300` не сработает: на момент фильтрации псевдонима ещё нет.
* **Форматирование — не вычисление.** `ROUND` меняет число, а `to_char` — только его отображение. Для отчётов чаще нужен `to_char`.
