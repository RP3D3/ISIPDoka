# Чек-лист продакшена

Что проверить перед тем, как выпустить базу кофейни в реальную работу?

Продакшен — это не только «запросы работают». Нужны резервные копии, миграции, права, мониторинг и план на случай сбоя. Чек-лист помогает не забыть то, что не видно на демо.

## Схема и данные

- [ ] Первичные и внешние ключи на месте.
- [ ] `NOT NULL`, `UNIQUE` и `CHECK` покрывают важные правила.
- [ ] Индексы по внешним ключам созданы.
- [ ] Деньги хранятся в `NUMERIC`, время — в `TIMESTAMPTZ`.
- [ ] Есть `created_at` и `updated_at` у изменяемых сущностей.
- [ ] Тестовые данные не попали в продакшен.

## Миграции

- [ ] Все изменения схемы — в версионированных файлах.
- [ ] Применённые миграции не редактируются.
- [ ] Опасные изменения проверены на копии.
- [ ] Есть план отката или резервная копия.
- [ ] Миграции не выполняют долгих блокировок без окна обслуживания.

## Безопасность

- [ ] Приложение работает не под владельцем базы.
- [ ] Роли имеют минимальные права.
- [ ] Пароли и токены не лежат в репозитории.
- [ ] Запросы параметризованы, нет склейки пользовательского ввода.
- [ ] Резервные копии защищены и проверены на восстановление.

## Производительность

- [ ] Медленные запросы найдены через `pg_stat_statements` или логи.
- [ ] Планы проверены через `EXPLAIN ANALYZE`.
- [ ] Нет `N+1` в основных страницах.
- [ ] Тяжёлые отчёты не блокируют запись.
- [ ] Материализованные представления обновляются по расписанию.

## Наблюдаемость

- [ ] Есть мониторинг подключений, диска, медленных запросов и ошибок.
- [ ] Настроены оповещения о сбоях.
- [ ] Логи не содержат персональных данных и секретов.
- [ ] Есть регламент восстановления после сбоя.

## Грабли

* **«Потом добавим бэкапы».** Потом может не наступить.
* **`GRANT ALL`.** Приложение получает лишние права.
* **Ручные правки на продакшене.** Схема расходится с миграциями.
* **Индексы без анализа.** Замедляют запись и не помогают чтению.
* **Нет мониторинга.** О проблеме узнают пользователи.
* **Забыть про восстановление.** Бэкап, который не проверяли, — не бэкап.
