# Кодировка консоли (UTF-8)

Почему в консоли вместо русских букв появляются знаки вопроса `????` и как это исправить?

По умолчанию некоторые терминалы используют устаревшие однобайтовые кодировки, из-за чего кириллица, спецсимволы или эмодзи превращаются в «кракозябры» и знаки вопроса. Чтобы переключить консоль на современный стандарт **UTF-8**, используют два свойства из пространства имён `System.Text`.

### Основные свойства

* **`Console.OutputEncoding = Encoding.UTF8;`** — отвечает за правильное отображение русских букв, символов псевдографики и значков при выводе текста на экран.
* **`Console.InputEncoding = Encoding.UTF8;`** — отвечает за корректное чтение кириллицы, которую пользователь вводит с клавиатуры через `Console.ReadLine()`.

### Пример кода

```csharp
using System;
using System.Text; // Обязательно подключаем для работы с Encoding

class Program
{
    static void Main()
    {
        // Настраиваем кодировку в самом начале программы
        Console.OutputEncoding = Encoding.UTF8;
        Console.InputEncoding = Encoding.UTF8;

        Console.Write("Введите ваше имя на русском: ");
        string name = Console.ReadLine();

        Console.WriteLine($"Привет, {name}! Кириллица и символы ★ ₽ работают корректно.");
    }
}

```

### Важные нюансы

* **Пространство имён `System.Text`:** без строчки `using System.Text;` в самом верху файла компилятор не узнает слово `Encoding` и выдаст ошибку.
* **Ставьте в начало `Main()`:** кодировку нужно задавать до любых команд `WriteLine` и `ReadLine`, иначе первые сообщения всё равно выведутся некорректно.
* **Поддержка псевдографики:** включение `Encoding.UTF8` также необходимо для рисования красивых таблиц и рамок с помощью символов вроде `╔`, `═`, `║`, `╚`.
