# Свойство Console.Title

Как поменять надпись в верхней рамке окна программы и вывести туда название игры или текущий статус?

`Console.Title` — это статическое свойство класса `System.Console`, которое позволяет задать или прочитать текст заголовка в верхней строке окна консоли (вместо стандартного длинного пути к `.exe` файлу).

### Зачем использовать

* **Оформление программы:** вместо технического пути `C:\Projects\...\App.exe` пользователь видит аккуратное название приложения или текстовой игры.
* **Динамический индикатор состояния:** заголовок можно обновлять прямо во время работы программы — например, показывать прогресс загрузки в процентах, счёт игрока или текущее время.
* **Чтение и запись:** свойство работает в обе стороны — можно не только записать новый заголовок, но и сохранить старый в переменную `string`, чтобы вернуть его позже.

### Пример кода

```csharp
using System;
using System.Threading;

class Program
{
    static void Main()
    {
        // Задаём название приложения при запуске
        Console.Title = "Калькулятор v1.0";
        Console.WriteLine("Программа запущена. Посмотрите на верхнюю рамку окна!");

        // Динамически меняем заголовок, показывая прогресс загрузки
        for (int i = 0; i <= 100; i += 25)
        {
            Console.Title = $"Загрузка данных: {i}%";
            Thread.Sleep(500); // Пауза полсекунды
        }

        Console.Title = "Калькулятор v1.0 — Готово";
        Console.WriteLine("Загрузка завершена!");
    }
}

```

### Важные нюансы

* **Возврат к стандарту после выхода:** изменение заголовка действует только пока запущена ваша программа. После её закрытия терминал сам вернёт исходный заголовок.
* **Ограничение длины и среды:** слишком длинный текст обрезается по ширине окна, а при запуске во встроенных панелях вывода некоторых редакторов кода изменение заголовка может игнорироваться.
