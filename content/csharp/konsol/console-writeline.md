# Метод Console.WriteLine()
Как напечатать сообщение в консоли и автоматически начать следующий вывод с новой строки?

`Console.WriteLine()` — это статический метод класса `System.Console`, который выводит переданные данные в консоль и **автоматически переводит курсор на новую строку**. Каждый следующий вызов печати начнётся уже с новой строки.

### Когда использовать

* **Построчный вывод:** печать сообщений, логов, заголовков или пунктов меню друг под другом.
* **Разделение блоков текста:** вызов `Console.WriteLine()` без аргументов вставляет пустую строку для визуального отступа.
* **Вывод значений переменных:** быстрая проверка результатов вычислений в процессе отладки.

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        string user = "Алексей";
        int level = 5;

        // Каждый вызов выводится с новой строки
        Console.WriteLine("Статистика игрока:");
        Console.WriteLine($"Имя: {user}");
        Console.WriteLine($"Уровень: {level}");

        // Вызов без параметров создаёт пустую строку
        Console.WriteLine();
        Console.WriteLine("Нажмите Enter для выхода...");
    }
}

```

Результат работы в консоли:

```text
Статистика игрока:
Имя: Алексей
Уровень: 5

Нажмите Enter для выхода...

```

### Особенности и нюансы

* **Вызов без параметров:** в отличие от `Console.Write()`, метод `Console.WriteLine()` можно вызвать с пустыми скобками — он просто выведет символ конца строки (`Environment.NewLine`).
* **Автоматическое приведение к строке:** метод имеет 18 перегрузок. Он умеет напрямую печатать числа (`int`, `double`), логические значения (`bool`), символы (`char`), массивы символов и любые объекты (вызывая у них метод `ToString()`).
* **Форматирование вывода:** поддерживает интерполяцию строк (`$"Результат: {result}"`) и составное форматирование с индексами (`Console.WriteLine("Точка ({0}; {1})", x, y);`).
* **Разница между ОС:** метод сам подставляет правильный перевод строки для текущей операционной системы (`\r\n` в Windows и `\n` в Linux/macOS).
