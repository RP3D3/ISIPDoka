# Метод Console.WriteLine()
Как напечатать сообщение в консоли и автоматически начать следующий вывод с новой строки?

`Console.BackgroundColor` — это статическое свойство класса `System.Console`, которое задаёт **цвет фона** непосредственно под выводимыми символами. Значение выбирается из перечисления `ConsoleColor` (те же 16 цветов, что и для текста).

### Особенности работы

* **Красит только область под символами:** при обычном изменении свойства цветным становится только прямоугольник позади новых букв и пробелов, а не всё окно программы.
* **Заливка всего экрана:** чтобы перекрасить фон всей консоли целиком, нужно сначала задать `Console.BackgroundColor`, а затем сразу вызвать `Console.Clear()`.
* **Сохраняется до сброса:** новый цвет фона применяется ко всем последующим строкам, пока его не изменят вручную или не вызовут `Console.ResetColor()`.
* **Читаемость текста:** при выборе яркого фона (например, `White` или `Yellow`) стоит одновременно поменять `Console.ForegroundColor` на тёмный цвет (`Black`), иначе текст сольётся с фоном.

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // Задаём тёмно-синий фон и белый цвет букв для выделения строки
        Console.BackgroundColor = ConsoleColor.DarkBlue;
        Console.ForegroundColor = ConsoleColor.White;
        Console.WriteLine(" Внимание: идёт сохранение данных... ");

        // Сбрасываем фон и цвет текста к стандартным настройкам
        Console.ResetColor();
        Console.WriteLine("Обычный вывод после сброса фона.");
    }
}

```

Результат работы в консоли:

```text
 Внимание: идёт сохранение данных...   <-- строка на тёмно-синем фоне
Обычный вывод после сброса фона.      <-- строка на стандартном фоне

```
