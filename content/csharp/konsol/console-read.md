# Метод Console.Read()
Как прочитать один первый символ из ввода и узнать его числовой код?

`Console.Read()` — это статический метод класса `System.Console`, который считывает **один следующий символ** из стандартного потока ввода и возвращает его целочисленный код в таблице Юникод (`int`).

### Особенности работы

* **Ожидание нажатия Enter:** в отличие от `Console.ReadKey()`, метод не срабатывает мгновенно при нажатии клавиши. Программа ждёт, пока пользователь введёт данные и нажмёт **Enter**, после чего забирает из буфера только первый символ.
* **Возвращает число (`int`):** метод отдаёт не сам символ, а его числовой код (например, `65` для `'A'` или `48` для `'0'`). Чтобы получить символ, результат нужно явно привести к типу `char`: `(char)code`.
* **Конец потока (`-1`):** если поток ввода закрыт (например, комбинацией `Ctrl + Z` в Windows или `Ctrl + D` в Linux/macOS), метод вернёт `-1`.

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Введите символ или слово: ");

        // Считываем код первого символа после нажатия Enter
        int code = Console.Read();

        if (code != -1)
        {
            char symbol = (char)code; // Преобразуем числовой код в символ
            Console.WriteLine($"Первый символ: '{symbol}', код Юникод: {code}");
        }
    }
}

```

Результат работы в консоли:

```text
Введите символ или слово: Привет
Первый символ: 'П', код Юникод: 1055

```

### Важный нюанс с буфером

Когда пользователь вводит один символ (например, `A`) и нажимает **Enter**, в буфер ввода попадают сразу три символа: `'A'`, возврат каретки `\r` (код `13`) и перевод строки `\n` (код `10`). Если сразу вызвать `Console.Read()` повторно, он без остановки считает из буфера оставшиеся `\r` и `\n`, не дожидаясь нового ввода с клавиатуры.
