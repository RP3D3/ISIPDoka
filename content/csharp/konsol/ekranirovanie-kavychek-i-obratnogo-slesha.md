# Экранирование символов (" и \)
Как вывести внутри строки двойные кавычки или путь к файлу Windows без ошибки компиляции?

В C# двойные кавычки `"` обозначают начало и конец строки, а обратный слэш `\` запускает управляющую последовательность (например, `\n` или `\t`). Чтобы вывести эти символы как обычный текст и не вызвать ошибку компиляции, их нужно **экранировать** — поставить перед ними дополнительный обратный слэш `\`.

### Основные комбинации

* **`\"` (двойная кавычка):** позволяет вставить кавычки внутрь строки (например, для прямой речи или названий), чтобы компилятор не принял их за досрочное окончание текста.
* **`\\` (обратный слэш):** выводит одиночный символ `\`. Чаще всего используется при записи путей к файлам и папкам в Windows (`C:\Users\Admin`), иначе компилятор попытается прочитать `\U` или `\A` как спецсимвол.
* **`\'` (одинарная кавычка):** нужна внутри символьного типа `char` (например, `char quote = '\'';`), чтобы не перепутать её с границами символа. В обычных двойных строках `"` одинарную кавычку можно писать свободно без слэша.

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // Экранируем двойные кавычки внутри текста
        Console.WriteLine("Он сказал: \"Привет, мир!\"");

        // Экранируем каждый обратный слэш в пути к файлу
        string path = "C:\\Users\\Student\\Desktop\\notes.txt";
        Console.WriteLine($"Путь к файлу: {path}");

        // Экранируем одинарную кавычку внутри типа char
        char singleQuote = '\'';
        Console.WriteLine($"Символ кавычки: {singleQuote}");
    }
}

```

Результат работы в консоли:

```text
Он сказал: "Привет, мир!"
Путь к файлу: C:\Users\Student\Desktop\notes.txt
Символ кавычки: '

```

### Полезный нюанс: `@`-строки для путей

Чтобы не удваивать каждый слэш в длинных путях к файлам, перед открывающей кавычкой можно поставить символ `@` (буквальная строка) — тогда экранирование полностью отключается: `string path = @"C:\Users\Student\Desktop\notes.txt";`. Внутри таких строк двойная кавычка при необходимости пишется дважды (`""`).
