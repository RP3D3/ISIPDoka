## Управляющий символ \t (табуляция) в C#

`\t` — это управляющая последовательность (escape-символ), которая вставляет в строку **горизонтальную табуляцию** — широкий отступ, аналогичный нажатию клавиши `Tab` на клавиатуре.

### Когда использовать и нюансы

* **Выравнивание столбцов:** помогает быстро оформить ровные колонки, прайс-листы или мини-таблицы в консоли без ручного подбора десятков пробелов.
* **Визуальные отступы:** используется для создания «красной строки» или сдвига вложенных пунктов меню вправо.
* **Привязка к невидимой сетке:** `\t` добавляет не фиксированное количество пробелов, а сдвигает курсор до следующей позиции, кратной шагу табуляции в консоли (обычно каждые 8 символов). Если слово перед `\t` длиннее 7 символов, одного `\t` может не хватить — тогда ставят два `\t\t` подряд.
* **Отключение в `@`-строках:** если перед строкой стоит символ `@` (например, `@"C:\temp\notes.txt"`), комбинация `\t` не сработает как отступ и выведется как обычный текст.

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // Выравниваем колонки таблицы с помощью \t
        Console.WriteLine("Товар\t\tЦена\tОстаток");
        Console.WriteLine("Клавиатура\t2500\t12 шт.");
        Console.WriteLine("Мышь\t\t1200\t34 шт.");
        Console.WriteLine("Монитор\t\t18900\t5 шт.");
    }
}

```

Результат работы в консоли:

```text
Товар           Цена    Остаток
Клавиатура      2500    12 шт.
Мышь            1200    34 шт.
Монитор         18900   5 шт.

```
