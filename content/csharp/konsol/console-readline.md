# Метод Console.ReadLine()
Как получить строку текста или число, которое пользователь ввёл с клавиатуры?

`Console.ReadLine()` — это статический метод класса `System.Console`, который считывает всю введённую пользователем строку до нажатия клавиши **Enter** и возвращает её в виде текста (`string` или `string?`).

### Как работает метод

* **Приостановка программы:** при вызове `Console.ReadLine()` выполнение кода ставится на паузу, пока пользователь не введёт данные и не нажмёт Enter.
* **Всегда возвращает строку:** даже если ввести число `25`, метод вернёт строку `"25"`. Чтобы использовать ввод в вычислениях, его нужно преобразовать через `int.Parse()`, `int.TryParse()` или класс `Convert`.
* **Возврат `null`:** если поток ввода закрыт (например, комбинацией `Ctrl + Z` в Windows, `Ctrl + D` в Linux/macOS или при достижении конца файла), метод вернёт `null`. Сам символ переноса строки в результат не включается.

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Введите ваше имя: ");
        string name = Console.ReadLine();

        Console.Write("Введите ваш возраст: ");
        string ageInput = Console.ReadLine();
        int age = int.Parse(ageInput); // Преобразуем строку в целое число

        Console.WriteLine($"Привет, {name}! Через год вам будет {age + 1}.");
    }
}

```

Результат работы в консоли:

```text
Введите ваше имя: Дмитрий
Введите ваш возраст: 20
Привет, Дмитрий! Через год вам будет 21.

```

### Отличия от других методов ввода

| Метод | Что считывает | Возвращаемый тип | Требует нажатия Enter |
| --- | --- | --- | --- |
| `Console.ReadLine()` | Всю строку целиком | `string?` | Да |
| `Console.Read()` | Один следующий символ | `int` (код символа в Юникоде) | Да |
| `Console.ReadKey()` | Одно нажатие любой клавиши | `ConsoleKeyInfo` (структура с данными о клавише) | Нет (срабатывает сразу) |
