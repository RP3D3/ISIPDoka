# Интерполяция строк ($"...")
Как вставлять переменные и математические вычисления прямо внутрь текста без громоздкого склеивания?

Символ `$` перед открывающей кавычкой превращает обычную строку в **интерполированную**. Это позволяет встраивать значения переменных, вычисления и результаты методов прямо внутрь текста с помощью фигурных скобок `{...}`.

### Зачем использовать

* **Удобство вместо склеивания:** заменяет громоздкое сложение строк через `+` (`"Привет, " + name + "!"`) на чистый и читаемый шаблон.
* **Вычисления прямо в тексте:** внутри фигурных скобок можно писать математические выражения (например, `{age + 1}`) или вызывать методы (`{name.ToUpper()}`).
* **Быстрое форматирование чисел:** после имени переменной через двоеточие `:` можно задать формат вывода (например, `{price:F2}` округлит дробное число до двух знаков после запятой).

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        string user = "Максим";
        int level = 4;
        double balance = 1250.5;

        // Подставляем переменные и вычисления прямо в строку
        Console.WriteLine($"Игрок: {user}, следующий уровень: {level + 1}");

        // Форматируем дробное число до 2 знаков после запятой
        Console.WriteLine($"Баланс счёта: {balance:F2} руб.");

        // Чтобы вывести сами фигурные скобки как текст, их удваивают
        Console.WriteLine($"Формат шаблона: {{имя}} = {user}");
    }
}

```

Результат работы в консоли:

```text
Игрок: Максим, следующий уровень: 5
Баланс счёта: 1250,50 руб.
Формат шаблона: {имя} = Максим

```

### Важные нюансы

* **Вывод самих скобок:** так как `{` и `}` зарезервированы для подстановки значений, одиночная скобка вызовет ошибку компиляции. Чтобы напечатать скобку как обычный символ, напишите её дважды: `{{` или `}}`.
* **Совмещение с `@`-строками:** знак `$` можно комбинировать с `@` для записи путей к файлам с переменными: `$@"C:\Users\{user}\docs.txt"`.
* **Без пробела:** символ `$` должен стоять вплотную к открывающей кавычке (`$"..."`), пробел между ними недопустим.
