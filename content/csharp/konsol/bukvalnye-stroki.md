# Буквальные строки (@"...")

Как записывать длинные пути к файлам и многострочный текст без удвоения слэшей и символов `\n`?

Символ `@` перед открывающей кавычкой превращает обычную строку в **буквальную** (verbatim). Компилятор воспринимает всё её содержимое «как есть» и полностью отключает обработку управляющих последовательностей вроде `\n`, `\t` или `\\`.

### Зачем использовать

* **Пути к файлам и папкам:** не нужно удваивать каждый обратный слэш (`\\`) в путях Windows — код остаётся чистым и понятным.
* **Многострочный текст:** обычный перенос строки (нажатие Enter в редакторе) сохраняется при выводе без вставки `\n`.
* **Шаблоны и разметка:** удобно хранить SQL-запросы, JSON, регулярные выражения и текстовую графику.

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // Путь к файлу записывается без двойных слэшей
        string filePath = @"C:\Users\Admin\Documents\report.txt";
        Console.WriteLine(filePath);

        // Многострочный текст сохраняет все переносы и пробелы
        string menu = @"=== Главное меню ===
1. Новая игра
2. Загрузить
3. Выход";
        Console.WriteLine(menu);

        // Чтобы вставить кавычку внутри @-строки, её пишут дважды
        string quote = @"Он сказал: ""Привет!""";
        Console.WriteLine(quote);
    }
}

```

### Важные нюансы

* **Двойные кавычки вместо слэша:** поскольку экранирование через `\` отключено, комбинация `\"` не сработает. Чтобы вывести кавычку внутри `@`-строки, её нужно продублировать (`""`).
* **Сохранение отступов:** при переносе строки внутри `@"..."` в итоговый текст попадают все пробелы и табуляции слева, которыми вы выравниваете код в редакторе.
* **Совмещение с интерполяцией:** символ `@` можно объединять с `$` в любом порядке (`$@"..."` или `@$"..."`), чтобы подставлять переменные прямо в пути к файлам: `$@"C:\Users\{userName}\data.json"`.
