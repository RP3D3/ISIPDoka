# Позиционирование и скрытие курсора

Как вывести текст в любое место экрана по координатам и убрать раздражающее мигание курсора?

Окно консоли устроено как сетка из символов, где отсчёт координат начинается с **верхнего левого угла `(0, 0)**`: ось `X` (`left`) идёт слева направо, а ось `Y` (`top`) — сверху вниз.

### Основные инструменты

* **`Console.SetCursorPosition(left, top)`** — мгновенно перемещает курсор в указанный столбец (`left`) и строку (`top`). Весь последующий вывод через `Write` или `WriteLine` начнётся именно с этой точки.
* **`Console.CursorVisible`** — логическое свойство (`true` или `false`), которое включает или полностью скрывает мигающую чёрточку курсора.

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // Скрываем мигающий курсор для аккуратного интерфейса
        Console.CursorVisible = false;

        // Выводим заголовок по координатам (X = 10, Y = 2)
        Console.SetCursorPosition(10, 2);
        Console.Write("=== ИГРОВОЕ ПОЛЕ ===");

        // Рисуем персонажа в другой точке экрана
        Console.SetCursorPosition(15, 5);
        Console.ForegroundColor = ConsoleColor.Green;
        Console.Write("@");
        Console.ResetColor();

        // Переводим курсор вниз и возвращаем его видимость перед выходом
        Console.SetCursorPosition(0, 8);
        Console.CursorVisible = true;
        Console.WriteLine("Нажмите любую клавишу для выхода...");
        Console.ReadKey(true);
    }
}

```

### Важные нюансы

* **Обновление экрана без мерцания:** в играх, таймерах и прогресс-барах вместо `Console.Clear()` используют `Console.SetCursorPosition(0, 0)` (или точечные координаты) и перезаписывают старые символы новыми — так картинка не мигает.
* **Запрет на отрицательные координаты:** передача чисел меньше `0` или координат, выходящих за пределы буфера окна, вызовет ошибку `ArgumentOutOfRangeException`.
* **Возврат курсора:** если вы скрыли курсор через `Console.CursorVisible = false`, обязательно верните `true` перед вызовом `Console.ReadLine()`, иначе пользователь не увидит место ввода текста.
