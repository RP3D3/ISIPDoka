# Метод Console.ResetColor()
Как одним вызовом вернуть стандартные цвета консоли и не испортить оформление терминала?

`Console.ResetColor()` — это статический метод класса `System.Console`, который сбрасывает цвет текста и фона обратно к стандартным настройкам окна консоли.

### Зачем нужен метод

* **Возврат к обычному виду:** позволяет быстро вернуть стандартное оформление после вывода цветных ошибок, предупреждений или заголовков.
* **Сброс сразу двух параметров:** заменяет ручное восстановление `ForegroundColor` и `BackgroundColor` по отдельности.
* **Защита от «утечки» цвета:** если не сбросить настройки перед выходом из программы, в некоторых терминалах (особенно в Linux и macOS) командная строка пользователя останется перекрашенной даже после завершения работы приложения.

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.BackgroundColor = ConsoleColor.DarkGreen;
        Console.ForegroundColor = ConsoleColor.White;
        Console.WriteLine(" Успешно: данные сохранены! ");

        // Сбрасываем одновременно и цвет фона, и цвет текста
        Console.ResetColor();

        Console.WriteLine("Обычный текст со стандартными цветами консоли.");
    }
}

```

Результат работы в консоли:

```text
 Успешно: данные сохранены!                      <-- белый текст на тёмно-зелёном фоне
Обычный текст со стандартными цветами консоли.  <-- стандартные цвета терминала

```

### Важные нюансы

* **Не меняет уже выведенный текст:** метод влияет только на те символы, которые будут напечатаны *после* его вызова.
* **Нельзя сбросить цвета по отдельности:** `Console.ResetColor()` всегда возвращает к заводским значениям и текст, и фон одновременно. Если нужно вернуть только один из параметров, его исходное значение придётся заранее сохранить в переменную типа `ConsoleColor`.
