# Метод Console.Write()
Как вывести текст в консоль так, чтобы пользователь вводил ответ прямо на той же строке?

`Console.Write()` — это статический метод класса `System.Console`, который выводит текст или значение переменной в консоль, **не переводя курсор на новую строку**. Весь последующий вывод продолжит печататься вплотную на той же самой строке.

### Когда использовать

* **Приглашение ко вводу:** пользователь вводит данные сразу после текста вопроса, а не строкой ниже.
* **Сборка строки по частям:** вывод элементов массива, таблицы или индикатора прогресса в цикле в одну линию.

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // Курсор остаётся сразу после двоеточия и пробела
        Console.Write("Введите ваше имя: ");
        string name = Console.ReadLine();

        // Несколько вызовов Write() склеиваются в одну строку
        Console.Write("Привет, ");
        Console.Write(name);
        Console.Write("! Добро пожаловать.");
    }
}

```

Результат работы в консоли (если ввести `Роман`):

```text
Введите ваше имя: Роман
Привет, Роман! Добро пожаловать.

```

### Отличия от Console.WriteLine() и нюансы

| Характеристика | `Console.Write()` | `Console.WriteLine()` |
| --- | --- | --- |
| **Перенос строки в конце** | Нет (курсор остаётся на текущей строке) | Да (добавляет символ новой строки) |
| **Вызов без параметров** | Ошибка компиляции | Выводит пустую строку |
| **Поддержка типов** | Все базовые типы (`int`, `double`, `bool`, `char`), строки и объекты | Все базовые типы, строки и объекты |

* **Форматирование:** метод поддерживает интерполяцию строк (`Console.Write($"Счёт: {score}");`) и составное форматирование (`Console.Write("X = {0}, Y = {1}", x, y);`).
* **Принудительный перенос:** если внутри `Console.Write()` нужно сделать разрыв строки вручную, используется управляющий символ `\n` или `Environment.NewLine`.\
