## Управляющий символ \n (перенос строки) в C#

`\n` — это управляющая последовательность (escape-символ), которая вставляет **разрыв строки** прямо внутри обычного текста. При выводе на экран или записи в файл весь текст после `\n` автоматически начинается с новой строки.

### Когда использовать и нюансы

* **Многострочный текст в одном вызове:** позволяет оформить меню, список или анкету внутри одного `Console.Write()` или `Console.WriteLine()` без десятка лишних команд печати.
* **Пустая строка между абзацами:** два символа подряд (`\n\n`) создают визуальный отступ в одну пустую строку.
* **Особенности в разных ОС:** `\n` — это стандартный перенос строки (LF) в Linux и macOS. В Windows классический перенос состоит из пары `\r\n`, но консоль корректно понимает и одиночный `\n`. Для строгой привязки к текущей операционной системе в C# также используют свойство `Environment.NewLine`.
* **Отключение в `@`-строках:** если перед кавычками поставить символ `@` (например, `@"C:\new\test.txt"`), `\n` перестаёт работать как перенос и выводится как обычный текст.

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // Оформляем список пунктов в одном методе с помощью \n
        Console.WriteLine("Выберите действие:\n1. Старт\n2. Настройки\n3. Выход");

        // Двойной \n добавляет пустую строку между фразами
        Console.Write("Загрузка завершена.\n\nНажмите любую клавишу...\n");
    }
}

```

Результат работы в консоли:

```text
Выберите действие:
1. Старт
2. Настройки
3. Выход
Загрузка завершена.

Нажмите любую клавишу...

```
