# Управляющие последовательности в строках

Как управлять переносами, отступами и кавычками внутри текста, не ломая структуру строки?

Управляющие последовательности (escape-символы) начинаются с обратного слэша `\` и передают компилятору специальную команду вместо обычного текста.

### Таблица-шпаргалка

| Символ | Название | Что делает |
| --- | --- | --- |
| `\n` | Перенос строки | Переводит вывод на новую строку |
| `\t` | Табуляция | Добавляет широкий отступ (как клавиша Tab) |
| `\"` | Двойная кавычка | Позволяет написать `"` внутри строки |
| `\'` | Одинарная кавычка | Позволяет написать `'` внутри символьного типа `char` |
| `\\` | Обратный слэш | Выводит обычный символ `\` (нужно для путей к файлам) |
| `\r` | Возврат каретки | Перемещает курсор в самое начало текущей строки |
| `\a` | Звуковой сигнал | Воспроизводит системный звук динамика |

### Спецпрефиксы для работы со строками

* **`$"..."` (интерполяция):** разрешает вставлять переменные и вычисления прямо внутрь текста в фигурных скобках `{...}`.
* **`@"..."` (буквальная строка):** полностью отключает экранирование через `\` — удобно для путей к файлам и многострочного текста.
* **`$@"..."` (комбинация):** позволяет одновременно писать пути без двойных слэшей и подставлять в них переменные.

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        string user = "Иван";

        // Комбинируем перенос строки (\n), табуляцию (\t) и кавычки (\")
        Console.WriteLine("Чек покупки:\n\tТовар:\t\"Книга по программированию\"\n\tПуть:\tC:\\Books\\guide.pdf");

        // Совмещаем буквальную строку (@) и интерполяцию ($)
        string savePath = $@"C:\Users\{user}\Documents\note.txt";
        Console.WriteLine($"Файл сохранён: {savePath}");
    }
}

```

Результат работы в консоли:

```text
Чек покупки:
        Товар:  "Книга по программированию"
        Путь:   C:\Books\guide.pdf
Файл сохранён: C:\Users\Иван\Documents\note.txt

```
