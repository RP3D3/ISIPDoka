# Переменные: объявление, присваивание и типы

Как сохранить значение в памяти и обращаться к нему по имени?

Переменная — это именованная область памяти с фиксированным типом. Тип определяет, какие значения можно хранить (целые числа, текст, деньги) и сколько места займёт значение, а имя позволяет обращаться к этой области из кода. Компилятор запоминает пару «имя + тип» и проверяет, что вы не запишете в счётчик строку.

## Объявление и присваивание

| Действие | Запись | Что происходит |
| --- | --- | --- |
| **Объявление** | `int age;` | Резервируется место под `int`, значения пока нет |
| **Инициализация** | `int age = 25;` | Объявление и первое значение одной строкой |
| **Присваивание** | `age = 26;` | В существующую переменную записывается новое значение |
| **Чтение** | `Console.WriteLine(age);` | Значение копируется в место использования |

## Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        string product = "Кофе";
        int cups = 2;
        decimal price = 149.90m; // суффикс m делает литерал типом decimal

        decimal total = cups * price;

        Console.WriteLine($"Товар: {product}");
        Console.WriteLine($"Количество: {cups}");
        Console.WriteLine($"Итого: {total} руб.");
    }
}
```

Результат работы в консоли:

```text
Товар: Кофе
Количество: 2
Итого: 299.80 руб.
```

## Правила именования

* **camelCase для локальных переменных:** `totalPrice`, а не `TotalPrice` — так принято в C#, и код читается единообразно.
* **Имя описывает смысл:** `total` и `price` понятны без комментариев, `a` и `b` — нет.
* **Регистр важен:** `total` и `Total` — две разные переменные, и это частый источник ошибок.
* **Нельзя начинать с цифры**, использовать пробелы и ключевые слова (`class`, `int`). Для совпадения с ключевым словом есть префикс `@`: `@class`.
* **Одна буква допустима только для счётчика цикла** (`i`, `j`) — там короткое имя не мешает пониманию.

## Тип задаётся один раз

После объявления тип менять нельзя: `age = "двадцать пять";` — ошибка компиляции, а не «превращение» числа в текст. Для чисел важна точность: `int` подходит для количества, `decimal` — для денег, `double` — для измерений. Подробнее о числовых типах — в группе 30 *Численные типы*, о тексте и логике — в группе 40 *Базовые нечисловые типы*.

## Частые ошибки

* **Использование до присваивания** — компилятор не пропустит `int age; Console.WriteLine(age);` (ошибка CS0165).
* **Целочисленное деление** — `5 / 2` даёт `2`, а не `2.5`: тип результата определяется типами операндов.
* **Выход за область видимости** — переменная, объявленная внутри `{ }`, не видна снаружи блока.

Если тип очевиден из правой части выражения, его можно не писать: `var count = 10;`. Как это работает и когда лучше указать тип явно — в следующей карточке.
