# Перечисления (enum): отказ от магических чисел

Как заменить загадочные числовые коды и опечатки в строках на понятный и безопасный набор фиксированных вариантов?

**Перечисление** (`enum`) — это пользовательский тип значений, который задаёт ограниченный набор именованных констант. Вместо того чтобы хранить статус заказа в виде непонятного числа `2` или строки `"shipped"`, где легко допустить опечатку, программист создаёт тип `OrderStatus` с чётким списком вариантов. Под капотом каждый элемент перечисления остаётся обычным целым числом, но на уровне кода компилятор строго следит за тем, чтобы в переменную попадали только допустимые значения.

## Сравнение хранения вариантов

| Критерий | Обычные числа или строки (`int` / `string`) | Перечисление (`enum`) |
| --- | --- | --- |
| **Читаемость кода** | Непонятно, что означает статус `10`, приходится искать расшифровку в комментариях | Значение читается как обычный текст: `OrderStatus.Shipped` |
| **Защита от ошибок** | Можно случайно передать несуществующий код `99` или строку с опечаткой | Компилятор разрешает использовать только описанные в `enum` варианты |
| **Подсказки в редакторе** | Приходится помнить все возможные коды или строки наизусть | Среда разработки сразу показывает список всех доступных значений |
| **Память и скорость** | Строки выделяются в куче и медленно сравниваются посимвольно | Является типом значений (*Stack*) и работает так же быстро, как `int` |

## Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // Выбираем статус из строго ограниченного списка — опечататься невозможно
        OrderStatus currentStatus = OrderStatus.Shipped;
        PrintStatusMessage(currentStatus);

        // Под капотом каждый элемент хранит целое число
        int numericCode = (int)currentStatus;
        Console.WriteLine($"Числовой код статуса {currentStatus}: {numericCode}");

        // Безопасное преобразование строки (например, из ввода пользователя) в enum
        if (Enum.TryParse("Delivered", out OrderStatus parsedStatus))
        {
            Console.WriteLine($"Распознан статус: {parsedStatus}");
        }
    }

    static void PrintStatusMessage(OrderStatus status)
    {
        switch (status)
        {
            case OrderStatus.New:
                Console.WriteLine("Заказ создан и ждёт оплаты.");
                break;
            case OrderStatus.Shipped:
                Console.WriteLine("Заказ передан в доставку.");
                break;
            case OrderStatus.Delivered:
                Console.WriteLine("Заказ успешно вручён.");
                break;
            default:
                Console.WriteLine($"Текущий этап: {status}");
                break;
        }
    }
}

// Объявление перечисления: по умолчанию New = 0, Processing = 1...
enum OrderStatus
{
    New,
    Processing,
    Shipped = 10, // Можно задать своё число; следующие пойдут от него (11, 12...)
    Delivered,
    Cancelled
}

```

## Важные нюансы

* **Нумерация и базовый тип:** по умолчанию элементы перечисления имеют тип `int` и нумеруются автоматически с нуля (`0, 1, 2...`). При необходимости можно явно указать другой целочисленный тип (`enum ErrorCode : byte`) и назначить свои числа, например, под коды ответов или записи из базы данных.
* **Ловушка явного приведения чисел:** компилятор защищает от неверных имён, но позволяет принудительно превратить любое число в `enum` через `(OrderStatus)999`, даже если такого элемента нет в списке — при получении чисел извне всегда проверяйте их существование через `Enum.IsDefined()`.
* **Комбинация нескольких значений (`[Flags]`):** если объекту нужно назначить сразу несколько состояний одновременно (например, права доступа `Read | Write`), перечисление помечают атрибутом `[Flags]`, а элементам задают степени двойки (`1, 2, 4, 8`).
* **Связь с другими темами:** отказ от разбросанных по коду чисел и строк напрямую поддерживает принципы *KISS* и *SSOT* (единый источник истины для списка состояний), а сам `enum` является типом значений и размещается в стеке (*Память программы: стек и куча*).
