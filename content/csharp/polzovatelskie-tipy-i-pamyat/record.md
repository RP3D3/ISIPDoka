# Записи (record): неизменяемые модели данных

Как быстро описать модель данных, которая сравнивается по содержимому полей, запрещает случайную перезапись и позволяет удобно создавать обновлённые копии?

**Запись** (`record`) — это специальный вид типа в C#, созданный для хранения неизменяемых данных: ответов от сервера (DTO), настроек, событий или строк из базы данных. В отличие от обычного класса (`class`), где два разных объекта с одинаковыми полями считаются неравными из-за разных адресов в куче (*Heap*), тип `record` автоматически реализует **сравнение по значению** (проверяет равенство всех свойств), красиво выводит содержимое через `ToString()` и поддерживает неразрушающее копирование через оператор `with`.

## Сравнение class, record и record struct

| Критерий | Обычный класс (`class`) | Ссылочная запись (`record` / `record class`) | Значимая запись (`record struct`) |
| --- | --- | --- | --- |
| **Где хранится** | В управляемой куче (*Heap*), передаётся по ссылке | В управляемой куче (*Heap*), передаётся по ссылке | В стеке (*Stack*), передаётся копированием значения |
| **Как сравнивается (`==`)** | По ссылке (один ли это объект в памяти) | По значению всех полей и свойств внутри | По значению всех полей и свойств внутри |
| **Изменяемость по умолчанию** | Поля и свойства обычно изменяемые (`set`) | Неизменяемая (`init`) при позиционном объявлении | Изменяемая (`get; set;`), если не указано `readonly record struct` |
| **Копирование с правками** | Нужно вручную писать метод клонирования | Встроенный оператор `with` (`user with { Age = 25 }`) | Встроенный оператор `with` (`point with { X = 10 }`) |

## Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // Создаём две разные записи в памяти с одинаковыми данными
        UserDto first = new UserDto("roman_dev", 1);
        UserDto second = new UserDto("roman_dev", 1);

        // Сравнение происходит по содержимому полей, а не по адресу в куче
        Console.WriteLine($"Равны по значению (==): {first == second}"); // True
        Console.WriteLine($"Один ли это объект в памяти: {ReferenceEquals(first, second)}"); // False

        // Неразрушающее копирование (with): создаём новый объект с одним изменённым полем
        UserDto promoted = first with { RoleId = 2 };

        // Встроенный читаемый вывод всех свойств через ToString()
        Console.WriteLine(first);    // UserDto { Login = roman_dev, RoleId = 1 }
        Console.WriteLine(promoted); // UserDto { Login = roman_dev, RoleId = 2 }

        // Встроенная деконструкция: раскладываем свойства записи в отдельные переменные
        var (login, roleId) = promoted;
        Console.WriteLine($"Логин: {login}, новая роль: {roleId}");

        // ❌ Ошибка компиляции: свойства позиционного record имеют доступ init (менять нельзя)
        // first.RoleId = 5;
    }
}

// Позиционное объявление record: компилятор сам создаст свойства { get; init; }, Equals и ToString
record UserDto(string Login, int RoleId);

```

## Важные нюансы

* **Под капотом это обычный класс или структура:** компилятор сам генерирует для `record` методы `Equals`, `GetHashCode`, перегружает операторы `==` и `!=`, создаёт информативный `ToString()` и конструктор копирования. При этом `record` (или `record class`) остаётся ссылочным типом в куче, а `record struct` (C# 10+) — типом значений в стеке.
* **Оператор `with` делает поверхностную копию (*shallow copy*):** при вызове `order with { Status = "Paid" }` создаётся новый экземпляр, куда копируются значения всех полей. Если внутри записи хранится ссылка на изменяемый список `List<string>`, обе записи будут ссылаться на один и тот же список в куче.
* **Позиционный и классический синтаксис:** компактная запись `record Book(string Title, int Year);` автоматически создаёт публичные свойства с аксессором `init`, но при необходимости внутри фигурных скобок `{ ... }` можно добавлять свои методы, вычисляемые свойства и проверки.
* **Связь с теорией и соседними темами:** благодаря автоматической генерации неизменяемых свойств и согласованных `Equals` и `GetHashCode`, записи идеально подходят на роль ключей в хеш-таблицах (см. теоретический раздел: *Хеш-таблицы* и карточки *Свойства* и *class против struct*).
