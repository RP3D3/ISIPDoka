# Область видимости переменных

В какой части программы существует объявленная переменная и почему код внутри одного метода или цикла не видит переменные из другого?

Область видимости (scope) — это участок программы, в котором переменная доступна для чтения и изменения. Главное правило простое: переменная «живёт» только внутри тех фигурных скобок `{ ... }`, в которых она была создана, и исчезает сразу после закрывающей скобки.

### Уровни видимости переменных

| Уровень видимости | Где объявляется переменная | Где доступна | Когда уничтожается |
| --- | --- | --- | --- |
| **Локальная (метод)** | Внутри тела метода или в его параметрах | Во всём этом методе и во вложенных в него блоках | После завершения работы метода |
| **Блочная (`if`, `else`)** | Внутри фигурных скобок условия | Только внутри конкретного блока `{ ... }` | На закрывающей скобке `}` этого блока |
| **Циклическая (`for`, `while`)** | В заголовке `for (...)` или внутри тела цикла | Только внутри своего цикла (или одной его итерации) | После завершения цикла (или шага) |

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // 1. Локальная переменная метода видна во всём Main и вложенных блоках
        int score = 85;
        string rank = "Новичок"; // Объявляем ДО if, чтобы использовать ПОСЛЕ

        if (score >= 80)
        {
            // Блочная переменная: существует только внутри этого if
            int bonus = 15;
            rank = "Профи";
            Console.WriteLine($"Итог с бонусом: {score + bonus}");
        }

        // Ошибка: переменная bonus здесь уже не существует
        // Console.WriteLine(bonus);
        Console.WriteLine($"Статус игрока: {rank}");

        // 2. Счётчик i виден только внутри своего цикла for
        for (int i = 0; i < 3; i++)
        {
            Console.Write($"{i} ");
        }
        // Ошибка: переменная i исчезла после закрывающей скобки цикла

        // Зато можно спокойно создать новый цикл с тем же именем i
        for (int i = 0; i < 2; i++)
        {
            Console.Write($"[{i}] ");
        }

        PrintReport();
    }

    static void PrintReport()
    {
        // Ошибка: метод PrintReport не видит переменную score из Main
        // Console.WriteLine(score);
        int score = 100; // Это совсем другая независимая переменная
        Console.WriteLine($"\nОтчёт: {score}");
    }
}

```

### Важные нюансы

* **Изоляция методов друг от друга:** методы не видят локальные переменные соседей — обмениваться данными между ними можно только через параметры и `return`.
* **Объявление до блока `if` или цикла:** если значение вычисляется внутри условия, но понадобится после него, создайте переменную заранее перед открывающей скобкой `{`.
* **Запрет на дублирование имён во вложенных блоках:** внутри одного метода нельзя объявить две переменные с одинаковым именем, даже если одна создана в теле метода, а вторая — внутри вложенного `if` или `for`.
* **Переменная цикла пересоздаётся на каждом шаге:** переменная, объявленная внутри тела цикла (`while` или `for`), на каждой новой итерации создаётся заново и не помнит значение с прошлого шага.
