# Возврат результата из метода

Как получить расчётный ответ от метода обратно в основную программу и использовать его в дальнейших вычислениях?

Чтобы метод не просто выводил текст на экран, а отдавал готовое значение (число, строку или логический результат), вместо `void` в его заголовке указывают конкретный тип данных. Оператор `return` завершает работу метода и передаёт вычисленный ответ в то место, откуда этот метод был вызван.

### Как устроен возврат значения

| Элемент | Назначение | Пример |
| --- | --- | --- |
| **Тип результата в заголовке** | Указывает, данные какого типа метод обязан вернуть вместо `void` | `static int Add(int a, int b)` |
| **Оператор `return значение;**` | Передаёт ответ наружу и немедленно останавливает работу метода | `return a + b;` |
| **Приём результата при вызове** | Сохранение ответа в переменную или подстановка сразу в выражение | `int sum = Add(5, 3);` |

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // 1. Сохраняем возвращённое число в переменную для дальнейших расчётов
        double priceWithTax = CalculatePrice(1000, 20);
        Console.WriteLine($"Итоговая цена с налогом: {priceWithTax}");

        // 2. Используем метод, возвращающий bool, прямо в условии if
        int age = 19;
        if (IsAdult(age))
        {
            Console.WriteLine("Доступ разрешён.");
        }

        // 3. Проверка досрочного выхода через return
        Console.WriteLine($"Деление 10 на 2: {SafeDivide(10, 2)}");
        Console.WriteLine($"Деление 10 на 0: {SafeDivide(10, 0)}");
    }

    // Метод возвращает дробное число (double)
    static double CalculatePrice(double basePrice, double taxPercent)
    {
        double result = basePrice + (basePrice * taxPercent / 100);
        return result;
    }

    // Метод возвращает логическое значение (bool)
    static bool IsAdult(int userAge)
    {
        return userAge >= 18;
    }

    // Досрочный выход из метода при некорректных данных
    static double SafeDivide(double a, double b)
    {
        if (b == 0)
        {
            return 0; // Метод сразу завершается здесь, не доходя до деления
        }
        return a / b;
    }
}

```

### Важные нюансы

* **Не путайте `return` с `Console.WriteLine`:** вывод на экран только показывает текст пользователю, но программа не может сохранить это число в переменную. Оператор `return` передаёт само значение внутрь кода.
* **Возврат обязателен на всех путях:** если внутри метода есть ветвление `if-else`, команда `return` должна срабатывать в каждой ветке, иначе компилятор выдаст ошибку («не все пути к коду возвращают значение»).
* **Мгновенная остановка метода:** как только программа встречает `return`, выполнение метода сразу прекращается, а строки кода ниже него не запускаются.
* **Строгое совпадение типов:** тип значения после `return` должен соответствовать типу, указанному перед именем метода (если обещан `int`, вернуть `string` нельзя).
