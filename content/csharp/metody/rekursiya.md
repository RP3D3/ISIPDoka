# Рекурсия: вызов методом самого себя

Как заставить метод вызывать самого себя для решения задачи по частям и вовремя остановить этот процесс?

Рекурсия — это приём программирования, при котором метод внутри своего тела вызывает сам себя. Такой подход позволяет разбить одну большую задачу на цепочку одинаковых, но более простых подзадач, пока не будет достигнут элементарный случай с готовым ответом.

### Из чего состоит рекурсия

| Элемент рекурсии | Роль в работе метода | Пример (факториал числа `n`) |
| --- | --- | --- |
| **Базовый случай** | Условие остановки, при котором метод возвращает готовый ответ без нового вызова | `if (n == 1) return 1;` |
| **Рекурсивный шаг** | Упрощение задачи и повторный вызов того же метода с изменённым параметром | `return n * Factorial(n - 1);` |
| **Стек вызовов** | Временная память, где программа хранит незавершённые вызовы до получения ответа | Цепочка от `Factorial(4)` до `Factorial(1)` |

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // 1. Простой обратный отсчёт с помощью рекурсии
        Console.WriteLine("Обратный отсчёт:");
        Countdown(3);

        // 2. Вычисление факториала числа 5 (5 * 4 * 3 * 2 * 1 = 120)
        int number = 5;
        int result = Factorial(number);
        Console.WriteLine($"\nФакториал числа {number} равен {result}");
    }

    // Рекурсивный вывод чисел от n до 1
    static void Countdown(int n)
    {
        // Базовый случай: когда дошли до нуля, прекращаем вызовы
        if (n <= 0)
        {
            Console.WriteLine("Старт!");
            return;
        }

        Console.WriteLine(n);
        Countdown(n - 1); // Рекурсивный шаг: уменьшаем число на 1
    }

    // Рекурсивный расчёт факториала
    static int Factorial(int n)
    {
        // Базовый случай: факториал 1 (и 0) равен 1
        if (n <= 1)
        {
            return 1;
        }

        // Рекурсивный шаг: умножаем текущее число на факториал предыдущего
        return n * Factorial(n - 1);
    }
}

```

### Важные нюансы

* **Обязательный базовый случай:** без условия выхода метод будет вызывать сам себя бесконечно, пока не переполнится память стека вызовов, что приведёт к аварийному завершению программы (`StackOverflowException`).
* **Движение к точке остановки:** на каждом новом вызове аргумент обязан изменяться в сторону базового случая (например, уменьшаться `n - 1`), иначе программа зациклится.
* **Прямой и обратный ход:** сначала программа «спускается» по цепочке вызовов до базового случая, а затем на обратном пути поочерёдно подставляет полученные ответы снизу вверх.
* **Рекурсия или цикл:** любую рекурсивную задачу можно решить обычным циклом — циклы работают быстрее и тратят меньше памяти, а рекурсию выбирают там, где она делает логику заметно проще (например, при обходе вложенных папок или древовидных структур).
