# Перегрузка методов

Как создать несколько версий метода с одним и тем же именем для работы с разными типами или количеством данных?

Перегрузка методов (method overloading) — это возможность объявить в одном классе несколько методов с одинаковым именем, но разным набором параметров. Компилятор сам определяет, какую именно версию запустить, ориентируясь на переданные при вызове аргументы. Яркий пример из стандартной библиотеки — `Console.WriteLine()`, который одинаково легко принимает и числа, и строки, и логические значения.

### Правила отличия перегруженных методов

| Чем отличаются методы | Пример заголовков | Результат |
| --- | --- | --- |
| **Разное количество параметров** | `Add(int a, int b)` и `Add(int a, int b, int c)` | Разрешено |
| **Разные типы параметров** | `Print(int x)` и `Print(string text)` | Разрешено |
| **Разный порядок типов параметров** | `Show(string s, int n)` и `Show(int n, string s)` | Разрешено |
| **Только тип возвращаемого значения** | `int Get()` и `double Get()` | Ошибка компиляции |
| **Только имена параметров** | `Calc(int a)` и `Calc(int b)` | Ошибка компиляции |

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // Компилятор сам выбирает нужную версию метода по переданным аргументам
        Console.WriteLine($"Сумма двух целых: {Add(5, 10)}");
        Console.WriteLine($"Сумма трёх целых: {Add(5, 10, 15)}");
        Console.WriteLine($"Сумма двух дробных: {Add(2.5, 3.7)}");

        PrintInfo("Анна", 21);
        PrintInfo(21, "Анна");
    }

    // 1. Базовая версия: два целых числа
    static int Add(int a, int b)
    {
        return a + b;
    }

    // 2. Отличие по количеству параметров: три целых числа
    static int Add(int a, int b, int c)
    {
        return a + b + c;
    }

    // 3. Отличие по типу параметров: два дробных числа
    static double Add(double a, double b)
    {
        return a + b;
    }

    // 4. Отличие по порядку следования разных типов
    static void PrintInfo(string name, int age)
    {
        Console.WriteLine($"Имя: {name}, возраст: {age}");
    }

    static void PrintInfo(int age, string name)
    {
        Console.WriteLine($"Возраст: {age}, имя: {name}");
    }
}

```

### Важные нюансы

* **Уникальность определяет сигнатура метода:** при перегрузке учитываются только имя метода, количество параметров, их типы и порядок (а также модификаторы `ref`, `out`, `in`). Имена самих параметров и тип возвращаемого значения в сигнатуру не входят.
* **Нельзя перегрузить только по возвращаемому типу:** если объявить два метода `int GetValue()` и `double GetValue()`, компилятор не поймёт, какой из них запустить, когда метод вызывают без сохранения ответа в переменную.
* **Единый смысл для одного имени:** перегружайте методы только тогда, когда они выполняют одно и то же по смыслу действие (например, сложение или вывод данных), но для разных входных аргументов.
* **Приоритет точного совпадения типов:** если существуют версии `Print(int x)` и `Print(double x)`, вызов `Print(5)` запустит вариант с `int`, а если варианта с `int` нет — автоматически приведёт число к `double`.
