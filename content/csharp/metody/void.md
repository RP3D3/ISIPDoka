# Объявление и вызов методов

Как оформить повторяющийся блок команд в отдельную подпрограмму, передать в неё данные и вызвать из любого места?

Метод — это именованный блок кода, который решает одну конкретную задачу. Вместо того чтобы копировать одинаковые строки по всей программе (принцип DRY — *не повторяйся*), код выносят в метод и запускают его по имени. Если метод просто выполняет действие и не возвращает расчётный ответ, перед его именем ставят ключевое слово `void`.

### Из чего состоит метод

| Элемент | Назначение | Пример |
| --- | --- | --- |
| `static void Name()` | Заголовок (сигнатура) метода без возврата значения | `static void ShowBanner()` |
| **Параметры** | Переменные в скобках при *создании* метода, через которые он принимает данные | `(string text, int count)` |
| **Аргументы** | Конкретные значения, которые передаются в скобках при *вызове* метода | `PrintMessage("Привет", 2);` |
| **Тело метода `{ ... }**` | Команды, которые выполняются при каждом вызове подпрограммы | Вывод текста, расчёты, циклы |

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // 1. Вызов метода без параметров
        ShowBanner();

        // 2. Вызов метода с передачей аргументов (порядок и типы должны совпадать)
        PrintMessage("Загрузка завершена", 2);
        PrintMessage("Добро пожаловать!", 1);
    }

    // Объявление метода без параметров (void — метод ничего не возвращает)
    static void ShowBanner()
    {
        Console.WriteLine("=== СИСТЕМА ГОТОВА ===");
    }

    // Объявление метода с двумя параметрами: text и repeatCount
    static void PrintMessage(string text, int repeatCount)
    {
        // Локальная переменная существует только внутри этого метода
        string prefix = "[Инфо]";

        for (int i = 0; i < repeatCount; i++)
        {
            Console.WriteLine($"{prefix} {text}");
        }
    }
}

```

### Важные нюансы

* **Зачем нужно слово `static`:** главный метод `Main` является статическим, поэтому другие методы в классе `Program`, которые вызываются из него напрямую, тоже должны иметь модификатор `static`.
* **Строгое соответствие аргументов:** при вызове метода нужно передавать ровно столько значений, сколько указано параметров, в том же порядке и совместимых типов.
* **Изоляция локальных переменных:** переменные, созданные внутри метода (включая его параметры), видны только внутри его фигурных скобок. Другие методы о них не знают, поэтому в разных методах можно спокойно использовать одинаковые имена.
* **Вызов только со скобками:** само по себе объявление метода не запускает код — команды внутри сработают только в момент вызова по имени с круглыми скобками `ShowBanner();`.
