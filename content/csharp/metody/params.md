# Переменное число параметров: модификатор params

Как написать метод, который принимает любое количество аргументов через запятую без ручного создания массива при вызове?

Модификатор `params` ставится перед одномерным массивом в списке параметров метода и позволяет передавать в него произвольное количество значений через запятую. Компилятор автоматически упаковывает все переданные аргументы в массив, с которым внутри метода работают как с обычным набором элементов.

### Варианты вызова метода с params

| Способ вызова | Пример вызова | Что получит метод внутри |
| --- | --- | --- |
| **Несколько аргументов через запятую** | `CalculateSum(10, 20, 30)` | Массив `int[] { 10, 20, 30 }` |
| **Один аргумент** | `CalculateSum(42)` | Массив `int[] { 42 }` |
| **Без аргументов (пустые скобки)** | `CalculateSum()` | Пустой массив длиной `0` |
| **Готовый массив** | `CalculateSum(values)` | Ссылку на переданный массив `values` |

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // 1. Передаём любое количество чисел через запятую
        Console.WriteLine($"Сумма трёх чисел: {CalculateSum(10, 20, 30)}");
        Console.WriteLine($"Сумма пяти чисел: {CalculateSum(1, 2, 3, 4, 5)}");

        // 2. Вызов вообще без аргументов (внутри получится пустой массив длиной 0)
        Console.WriteLine($"Сумма без чисел: {CalculateSum()}");

        // 3. Можно передать и уже готовый массив
        int[] values = { 100, 200 };
        Console.WriteLine($"Сумма из массива: {CalculateSum(values)}");

        // 4. Сочетание обычного параметра и params
        PrintTeam("Альфа", "Иван", "Мария", "Олег");
    }

    // params превращает переданные через запятую числа в одномерный массив numbers
    static int CalculateSum(params int[] numbers)
    {
        int total = 0;
        foreach (int num in numbers)
        {
            total += num;
        }
        return total;
    }

    // Обычные параметры всегда ставятся ДО параметра с params
    static void PrintTeam(string teamName, params string[] members)
    {
        Console.WriteLine($"Команда «{teamName}» ({members.Length} чел.): {string.Join(", ", members)}");
    }
}

```

### Важные нюансы

* **Строго в самом конце списка параметров:** параметр с модификатором `params` обязан быть последним в заголовке метода — поставить после него ещё один обычный или необязательный параметр нельзя.
* **Только один `params` на метод:** в одном методе не может быть двух параметров с модификатором `params`, иначе компилятор не поймёт, где заканчивается первый набор аргументов и начинается второй.
* **Только одномерный массив:** модификатор `params` работает исключительно с одномерными массивами (`int[]`, `string[]`), но не с двумерными матрицами `[,]`.
* **Нельзя сочетать с `ref`, `out` и `in`:** перед параметром с `params` не разрешается указывать модификаторы передачи по ссылке или значения по умолчанию.
