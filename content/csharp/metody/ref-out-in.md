# Передача данных в метод: по значению и по ссылке

Почему изменение числа внутри метода не меняет исходную переменную, и как вернуть из одного метода сразу несколько результатов?

По умолчанию простые данные (числа, символы, логические значения) передаются в метод **по значению** — метод получает лишь копию переменной, поэтому оригинал остаётся нетронутым. Чтобы разрешить методу напрямую менять внешнюю переменную или возвращать несколько ответов сразу, используют модификаторы передачи по ссылке: `ref`, `out` и `in`.

### Сравнение способов передачи данных

| Способ передачи | Инициализация до вызова | Изменение внутри метода | Когда применять |
| --- | --- | --- | --- |
| **Обычный (по значению)** | Обязательна | Меняется только копия | Стандартная безопасная передача данных без изменения оригинала |
| **`ref` (по ссылке)** | Обязательна | Может читать и менять оригинал | Когда методу нужно обновить уже существующую переменную |
| **`out` (выходной)** | Не обязательна | **Обязан** присвоить значение | Когда нужно вернуть из метода несколько результатов (как в `int.TryParse`) |
| **`in` (только для чтения)** | Обязательна | Запрещено (ошибка компиляции) | Передача крупных структур без копирования в памяти с защитой от правок |

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // 1. Обычная передача по значению: оригинал не изменится
        int number = 10;
        TryChangeValue(number);
        Console.WriteLine($"После обычного вызова: {number}"); // 10

        // 2. Передача по ссылке с ref: оригинал изменится
        ChangeWithRef(ref number);
        Console.WriteLine($"После вызова с ref: {number}"); // 25

        // 3. Возврат нескольких значений через out (переменные можно не инициализировать)
        int[] data = { 8, 3, 15, 6 };
        GetMinMax(data, out int minVal, out int maxVal);
        Console.WriteLine($"Минимум: {minVal}, максимум: {maxVal}");

        // 4. Передача с защитой от изменений через in
        PrintReadOnly(in number);
    }

    static void TryChangeValue(int x)
    {
        x = 99; // Меняется только локальная копия
    }

    static void ChangeWithRef(ref int x)
    {
        x += 15; // Меняется исходная переменная из Main
    }

    static void GetMinMax(int[] items, out int min, out int max)
    {
        // Метод обязан присвоить значения всем out-параметрам до выхода
        min = items[0];
        max = items[0];

        foreach (int item in items)
        {
            if (item < min) min = item;
            if (item > max) max = item;
        }
    }

    static void PrintReadOnly(in int x)
    {
        // x = 50; // Ошибка: параметр с модификатором in нельзя изменять
        Console.WriteLine($"Чтение параметра in: {x}");
    }
}

```

### Важные нюансы

* **Модификатор пишется дважды:** слова `ref` и `out` нужно указывать и в заголовке метода, и при его вызове — это страхует от случайного изменения переменных (для `in` слово при вызове указывать необязательно).
* **Массивы и так передаются по ссылке:** если передать массив в метод без всяких модификаторов и изменить его ячейку (`items[0] = 5`), правка сохранится в оригинале, так как массив относится к ссылочным типам.
* **Обязанность `out`-параметра:** программа не скомпилируется, если внутри метода забыли записать значение в переменную с модификатором `out` до завершения работы метода.
* **Нельзя передавать константы в `ref` и `out`:** написать `ChangeWithRef(ref 10)` нельзя — модификаторам нужна реальная переменная в памяти, в которую можно записать результат.
