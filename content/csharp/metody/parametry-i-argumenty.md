# Необязательные параметры и именованные аргументы

Как сделать часть параметров метода необязательными, задать им стандартные значения и передавать аргументы в произвольном порядке?

Необязательные параметры позволяют вызывать метод, не указывая каждый аргумент вручную — если значение не передано, программа автоматически подставит заготовленное значение по умолчанию. Именованные аргументы позволяют при вызове явно указать имя параметра перед значением, что повышает читаемость кода и позволяет пропускать ненужные необязательные параметры.

### Способы работы с параметрами

| Механизм | Синтаксис | Что даёт на практике |
| --- | --- | --- |
| **Параметр по умолчанию** | `int sugar = 1` в заголовке метода | Делает аргумент необязательным при вызове |
| **Именованный аргумент** | `withMilk: true` при вызове метода | Позволяет менять порядок аргументов и пропускать средние параметры |
| **Смешанный вызов** | `OrderCoffee("Латте", withMilk: true)` | Передаёт обязательные данные по позиции, а нужный необязательный — по имени |

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // 1. Передаём только обязательный параметр (sugar = 1, withMilk = false подставятся сами)
        OrderCoffee("Эспрессо");

        // 2. Переопределяем первый необязательный параметр по позиции
        OrderCoffee("Американо", 2);

        // 3. Пропускаем sugar и задаём только withMilk с помощью именованного аргумента
        OrderCoffee("Латте", withMilk: true);

        // 4. Передаём все аргументы по именам в любом удобном порядке
        OrderCoffee(withMilk: true, sugar: 0, drink: "Капучино");
    }

    // drink — обязательный параметр; sugar и withMilk — необязательные со значениями по умолчанию
    static void OrderCoffee(string drink, int sugar = 1, bool withMilk = false)
    {
        string milkText = withMilk ? "с молоком" : "без молока";
        Console.WriteLine($"Заказ: {drink}, сахара: {sugar} лож., {milkText}.");
    }
}

```

### Важные нюансы

* **Обязательные параметры всегда идут первыми:** в заголовке метода нельзя поставить обязательный параметр *после* необязательного — компилятор выдаст ошибку. Все параметры со значениями по умолчанию располагаются строго в конце списка.
* **Пропуск средних параметров:** если у метода два или больше необязательных параметров, пропустить первый из них и задать только второй можно исключительно через именованный аргумент (`withMilk: true`).
* **Позиционные аргументы ставятся до именованных:** при смешанном вызове обычные аргументы без имени указывают в начале на своих местах, а именованные — после них.
* **Только постоянные значения по умолчанию:** после знака `=` в заголовке метода разрешено писать только константы (числа, строки, `true`, `false`, `null`), но нельзя подставлять переменные или вызовы других методов.
