# Одномерные массивы: создание, индексы и длина

Как хранить набор однотипных значений под одним именем, обращаться к нужному элементу по номеру и узнать размер списка?

Одномерный массив — это контейнер фиксированного размера, который хранит множество элементов одного типа в соседних ячейках памяти. У каждого элемента есть свой порядковый номер — **индекс**, по которому его можно прочитать или перезаписать.

### Способы создания массива

| Способ записи | Что делает | Когда применять |
| --- | --- | --- |
| `int[] nums = new int[5];` | Создаёт массив на 5 ячеек, заполненный значениями по умолчанию (`0`) | Когда размер известен заранее, а данные появятся позже |
| `int[] nums = { 10, 20, 30 };` | Создаёт массив и сразу заполняет его готовыми значениями | Когда стартовый набор данных известен сразу при создании |
| `var nums = new[] { 10, 20 };` | Создаёт массив с автоматическим определением типа через `var` | Для сокращения записи при очевидном типе элементов |

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // 1. Создание пустого массива на 4 элемента (по умолчанию заполнены нулями)
        int[] temperatures = new int[4];
        temperatures[0] = 18; // Запись в самый первый элемент (индекс 0)
        temperatures[1] = 21;
        temperatures[3] = 15; // Запись в последний элемент (индекс 3)

        // 2. Создание массива сразу с готовыми значениями
        string[] cities = { "Москва", "Казань", "Сочи" };

        // 3. Чтение элементов по индексу и получение размера через свойство Length
        Console.WriteLine($"Первый город: {cities[0]}");
        Console.WriteLine($"Всего городов: {cities.Length}");

        // Получение последнего элемента через Length - 1
        string lastCity = cities[cities.Length - 1];
        Console.WriteLine($"Последний город: {lastCity}");
    }
}

```

### Важные нюансы

* **Нумерация всегда начинается с нуля:** в массиве из 4 элементов доступны только индексы `0, 1, 2, 3`. Попытка обратиться к индексу `4` или `-1` вызовет аварийную ошибку программы (`IndexOutOfRangeException`).
* **Последний индекс равен `Length - 1`:** свойство `Length` возвращает общее количество ячеек, поэтому последний элемент всегда находится на одну позицию левее этого числа.
* **Фиксированный размер после создания:** изменить длину уже созданного массива нельзя — чтобы добавить новые ячейки, придётся создать новый массив большего размера или использовать список `List<T>`.
* **Строго один тип данных:** массив `int[]` принимает только целые числа — положить в одну из его ячеек строку или дробь не получится.
