# Перебор и изменение элементов массива

Как обойти все ячейки массива, изменить значения внутри них и удобно обратиться к элементам с конца?

Для работы с набором данных в массиве почти всегда используют циклы. Выбор между ними зависит от задачи: если значения нужно перезаписать или важен номер ячейки — берут цикл `for`, а для простого чтения всех элементов подряд идеально подходит `foreach`.

### Сравнение циклов при работе с массивом

| Инструмент | Изменение элементов | Доступ к индексу | Направление обхода | Когда применять |
| --- | --- | --- | --- | --- |
| Цикл `for` | Да | Да (`i`) | Вперёд, назад, с любым шагом | Заполнение массива, перезапись значений, обратный проход |
| Цикл `foreach` | Нет (только чтение) | Нет | Строго от начала к концу | Вывод на экран, подсчёт суммы, поиск совпадений |

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        int[] prices = { 100, 250, 400, 150 };

        // 1. Изменение элементов через цикл for (увеличиваем каждую цену на 10%)
        for (int i = 0; i < prices.Length; i++)
        {
            prices[i] = (int)(prices[i] * 1.1);
        }

        // 2. Безопасное чтение всех элементов через foreach
        Console.Write("Обновлённые цены: ");
        foreach (int price in prices)
        {
            Console.Write($"{price} ");
        }
        Console.WriteLine();

        // 3. Обращение к элементам с конца (через Length и оператор ^)
        int lastClassic = prices[prices.Length - 1]; // Классический способ: 165
        int lastModern = prices[^1];                 // Современный способ: 165
        int secondFromEnd = prices[^2];              // Предпоследний элемент: 440

        Console.WriteLine($"Последняя цена: {lastModern}, предпоследняя: {secondFromEnd}");

        // 4. Перебор массива в обратном порядке (от конца к началу)
        Console.Write("В обратном порядке: ");
        for (int i = prices.Length - 1; i >= 0; i--)
        {
            Console.Write($"{prices[i]} ");
        }
    }
}

```

### Важные нюансы

* **`foreach` работает только на чтение:** попытка присвоить новое значение переменной цикла внутри `foreach` вызовет ошибку компиляции. Чтобы изменить ячейку, обращайтесь к ней по индексу через `for` (`prices[i] = ...`).
* **Строгое условие `i < array.Length`:** при переборе слева направо всегда используйте знак строго меньше (`<`), а не меньше или равно (`<=`), иначе на последнем шаге программа выйдет за границы массива.
* **Индекс с конца `^1`, но не `^0`:** оператор `^` отсчитывает позиции с конца начиная с единицы (`^1` — последний элемент, `^2` — предпоследний). Запись `array[^0]` эквивалентна `array[array.Length]` и вызовет ошибку выхода за границы.
* **Обратный цикл начинается с `Length - 1`:** при движении справа налево счётчик стартует с последнего существующего индекса (`prices.Length - 1`) и идёт до нуля включительно (`i >= 0`).
