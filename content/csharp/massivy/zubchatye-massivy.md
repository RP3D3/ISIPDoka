# Зубчатые массивы: массив массивов

Как создать таблицу со строками разной длины и не тратить лишнюю память на пустые ячейки?

Зубчатый массив (массив массивов) — это одномерный массив, каждый элемент которого сам является отдельным одномерным массивом. В отличие от прямоугольной матрицы `[,]`, здесь каждая строка может иметь собственную длину, образуя «лесенку».

### Отличия от прямоугольной матрицы

| Критерий | Зубчатый массив (`[][]`) | Двумерная матрица (`[,]`) |
| --- | --- | --- |
| Объявление | `int[][] jagged = new int[3][];` | `int[,] matrix = new int[3, 4];` |
| Длина строк | У каждой строки может быть своя длина | Все строки строго одинаковой длины |
| Обращение к ячейке | Двойные скобки: `jagged[row][col]` | Через запятую: `matrix[row, col]` |
| Количество строк | `jagged.Length` | `matrix.GetLength(0)` |
| Длина конкретной строки | `jagged[row].Length` | `matrix.GetLength(1)` |

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // 1. Пошаговое создание: сначала задаём количество строк (3 строки)
        int[][] groups = new int[3][];

        // Затем создаём внутренний массив для каждой строки со своей длиной
        groups[0] = new int[] { 10, 20 };             // 2 элемента
        groups[1] = new int[] { 30, 40, 50, 60 };     // 4 элемента
        groups[2] = new int[] { 70 };                 // 1 элемент

        // 2. Обращение к элементу: 2-я строка (индекс 1), 3-й элемент (индекс 2)
        Console.WriteLine($"Элемент [1][2]: {groups[1][2]}"); // Выведет 50

        // 3. Обход зубчатого массива вложенными циклами
        for (int i = 0; i < groups.Length; i++)
        {
            Console.Write($"Строка {i} (длина {groups[i].Length}): ");
            for (int j = 0; j < groups[i].Length; j++)
            {
                Console.Write($"{groups[i][j]} ");
            }
            Console.WriteLine();
        }
    }
}

```

### Важные нюансы

* **Двухэтапная инициализация:** команда `new int[3][]` выделяет память только под ссылки на будущие строки, но сами внутренние массивы ещё не созданы (они равны `null`). Попытка записать значение в `groups[0][0]` до создания внутреннего массива вызовет ошибку `NullReferenceException`.
* **Обычное свойство `Length` на обоих уровнях:** для зубчатого массива не нужен метод `GetLength` — свойство `groups.Length` возвращает количество строк, а `groups[i].Length` даёт точную длину конкретной `i`-й строки.
* **Двойные квадратные скобки:** индексы всегда записываются раздельно (`groups[i][j]`), а не через запятую в одних скобках.
* **Когда применять:** идеально подходит для неравномерных структур данных — например, для хранения оценок учеников по разным предметам или списков участников в командах разного размера.
