# Методы класса Array и копирование массивов

Как отсортировать элементы массива, развернуть их в обратном порядке и создать независимую копию без ручных циклов?

Встроенный класс `Array` предоставляет готовые статические методы для частых операций над массивами: сортировки, разворота, поиска, очистки и копирования. Они избавляют от необходимости каждый раз писать циклы вручную.

### Основные методы класса Array

| Метод | Что делает | Особенность работы |
| --- | --- | --- |
| `Array.Sort(arr)` | Сортирует элементы по возрастанию | Меняет исходный массив на месте |
| `Array.Reverse(arr)` | Переворачивает порядок элементов задом наперёд | Меняет исходный массив на месте |
| `Array.IndexOf(arr, val)` | Ищет первое вхождение значения `val` | Возвращает индекс или `-1`, если не найдено |
| `Array.Clear(arr)` | Сбрасывает все ячейки в значение по умолчанию (`0`, `false`, `null`) | Длина массива остаётся прежней |
| `Array.Copy(src, dst, len)` | Копирует указанное число элементов из одного массива в другой | Требует заранее созданный целевой массив |

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        int[] numbers = { 40, 10, 50, 20, 30 };

        // 1. Правильное копирование (создаём отдельный массив и копируем данные)
        int[] copy = new int[numbers.Length];
        Array.Copy(numbers, copy, numbers.Length);

        // 2. Сортировка по возрастанию и разворот (меняют массив copy на месте)
        Array.Sort(copy);    // { 10, 20, 30, 40, 50 }
        Array.Reverse(copy); // { 50, 40, 30, 20, 10 }

        // 3. Поиск индекса элемента в исходном массиве
        int index = Array.IndexOf(numbers, 50); // Вернёт 2 (или -1, если элемента нет)

        // 4. Очистка массива (заполняет ячейки нулями, не меняя длину)
        Array.Clear(numbers);

        Console.WriteLine($"Исходный после Clear: {string.Join(", ", numbers)}");
        Console.WriteLine($"Копия после Sort и Reverse: {string.Join(", ", copy)}");
        Console.WriteLine($"Индекс числа 50 до очистки: {index}");
    }
}

```

### Важные нюансы

* **Обычное присваивание `b = a` не копирует массив:** массив — это ссылочный тип, поэтому запись `int[] b = a;` просто создаёт вторую ссылку на те же самые ячейки памяти. Изменив `b[0]`, вы измените и `a[0]`. Для независимой копии используйте `Array.Copy(...)` или метод `(int[])a.Clone()`.
* **`Sort` и `Reverse` изменяют исходный массив:** эти методы не создают новый массив, а переставляют элементы прямо внутри переданного набора данных.
* **`Array.Clear` не удаляет ячейки:** размер массива остаётся неизменным, а ячейки просто заполняются значениями по умолчанию (`0` для чисел, `false` для логического типа, `null` для строк).
* **Сортировка по убыванию в два шага:** сначала массив сортируют по возрастанию через `Array.Sort(arr)`, а затем переворачивают через `Array.Reverse(arr)`.
