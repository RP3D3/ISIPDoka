# Базовые алгоритмы на массивах

Как посчитать сумму всех чисел в массиве, найти самое маленькое или большое значение и проверить, есть ли в наборе нужный элемент?

Работа с массивами почти всегда сводится к четырём классическим задачам: накоплению суммы, поиску рекордов (минимума и максимума), подсчёту совпадений и поиску конкретного значения. Все они решаются одним проходом цикла по элементам.

### Схема решения типовых задач

| Задача | Стартовое значение | Действие на каждом шаге цикла |
| --- | --- | --- |
| Сумма и среднее | `int sum = 0;` | Прибавляем каждый элемент: `sum += item;` |
| Минимум и максимум | Первый элемент: `int min = arr[0];` | Сравниваем: если `item < min`, обновляем `min = item;` |
| Подсчёт по условию | `int count = 0;` | Если условие верно (`item > 50`), делаем `count++;` |
| Линейный поиск | `int foundIndex = -1;` | Если `arr[i] == target`, запоминаем `i` и выходим через `break` |

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        int[] scores = { 45, 82, 19, 94, 60, 82 };

        // 1. Подсчёт суммы и среднего арифметического
        int sum = 0;
        foreach (int score in scores)
        {
            sum += score;
        }
        double average = (double)sum / scores.Length;

        // 2. Поиск минимума и максимума (стартуем с нулевого элемента)
        int min = scores[0];
        int max = scores[0];
        for (int i = 1; i < scores.Length; i++)
        {
            if (scores[i] < min) min = scores[i];
            if (scores[i] > max) max = scores[i];
        }

        // 3. Поиск индекса нужного элемента (например, числа 94)
        int target = 94;
        int foundIndex = -1; // -1 означает, что элемент пока не найден
        for (int i = 0; i < scores.Length; i++)
        {
            if (scores[i] == target)
            {
                foundIndex = i;
                break; // Нашли первое совпадение — дальше искать не нужно
            }
        }

        Console.WriteLine($"Сумма: {sum}, среднее: {average:F1}");
        Console.WriteLine($"Минимум: {min}, максимум: {max}");
        Console.WriteLine(foundIndex != -1
            ? $"Элемент {target} найден на позиции {foundIndex}"
            : $"Элемент {target} не найден");
    }
}

```

### Важные нюансы

* **Не берите `0` за стартовый минимум или максимум:** если задать `int min = 0;`, а в массиве лежат только положительные числа (`15, 20, 40`), программа ошибочно вернёт `0`. Всегда начинайте сравнение с первого элемента массива (`scores[0]`).
* **Защита от пустого массива:** перед обращением к `scores[0]` или делением на `scores.Length` в реальных задачах проверяют `if (scores.Length > 0)`, чтобы избежать ошибки выхода за границы или деления на ноль.
* **Точность среднего арифметического:** при делении целой суммы `sum` на целую длину `Length` дробная часть отбросится — обязательно приведите сумму к типу `double`: `(double)sum / scores.Length`.
* **Значение `-1` как признак отсутствия:** при поиске позиции элемента начальный индекс принято задавать равным `-1`, так как реальные индексы в массиве всегда начинаются с нуля.
