Переменные

Именованные контейнеры для хранения данных в памяти: способы объявления, разница между явными типами и ключевым словом var, константы и правила именования.

Кратко

Переменная — это именованная ячейка в оперативной памяти компьютера, куда программа сохраняет значение определённого типа. У каждой переменной есть тип данных, имя (идентификатор) и значение. 

int score = 100;
string playerName = "Алекс";
bool isGameOver = false;

C# — строго типизированный язык. Тип переменной фиксируется один раз при создании: записать строку текста в числовую переменную компилятор не разрешит.

Анатомия создания переменной

Работа с переменной состоит из двух ключевых шагов, которые можно разделить или выполнить в одну строчку:

  • Объявление (declaration) — выделение места в памяти и закрепление типа с именем: int count;.
  • Инициализация (initialization) — первое присваивание значения: count = 5;.
// Раздельное объявление и запись значения:
int speed;
speed = 60;

// Объявление с одновременной инициализацией (рекомендуется):
int health = 100;

// Переприсваивание (изменение значения со временем):
health = 85;

Неизменяемые переменные (константы)

Если значение не должно меняться во время работы программы, перед типом указывается модификатор const. Константу обязаны инициализировать сразу при объявлении: 

const double Pi = 3.14159;
const int MaxPlayers = 4;

// MaxPlayers = 8; // Ошибка компиляции CS0131: константу нельзя изменить

Явный тип или ключевое слово var

Тип переменной можно указать напрямую (int, string) либо доверить его вывод компилятору через ключевое слово var.

Как работает var

var — это не динамическая типизация как в JavaScript или Python. Компилятор смотрит на значение справа от знака равенства и сам подставляет точный тип на этапе сборки: 

var age = 18;          // компилятор видит число -> тип int
var title = "Персонаж"; // компилятор видит текст -> тип string

// age = "двадцать";   // Ошибка CS0029: age навсегда остался int

Главное ограничение var: переменную с var нельзя объявить без одновременного присваивания значения, иначе компилятор не сможет определить её тип: 

// var total; // Ошибка CS0818: неявная переменная требует инициализации

Сравнение: явный тип против var

Критерий Явная типизация (int x = 10) Неявная типизация (var x = 10)
Определение типа Задаётся разработчиком вручную Вычисляется компилятором по правому значению
Типизация в рантайме Строгая статическая Строгая статическая (идентична явной)
Раздельное объявление Разрешено (int x; x = 5;) Запрещено (значение обязательно сразу)
Влияние на скорость работы Нулевое Нулевое (в скомпилированном IL-коде разницы нет)
Когда применять Когда тип не очевиден из правой части выражения Когда тип справа ясен (конструкторы, вызовы с понятным именем)

Базовые типы данных

Чаще всего при объявлении локальных переменных используются следующие встроенные типы:

  • int — целые числа со знаком (от -2 млрд до +2 млрд, 4 байта): int level = 12;.
  • double — вещественные (дробные) числа с двойной точностью (8 байт): double price = 99.99;.
  • bool — логический тип, принимает только true или false: bool isReady = true;.
  • char — один символ Unicode в одинарных кавычках (2 байта): char rank = 'A';.
  • string — последовательность символов (текст) в двойных кавычках: string name = "Бот";.

Правила и конвенции именования

В C# действуют строгие технические ограничения и общепринятые стандарты чистого кода:

  • Технические правила: имя может содержать латинские буквы, цифры и символ подчеркивания _. Имя не может начинаться с цифры и не должно совпадать с зарезервированными ключевыми словами языка (class, int, for).
  • Регистр (camelCase): для локальных переменных в методах всегда используется стиль camelCase — первая буква строчная, каждое следующее слово с заглавной (playerHealth, maxSpeedLimit).
  • Смысловая нагрузка: избегайте имён вида a, temp2, xyz. Имя должно отвечать на вопрос «что именно хранится внутри».

Частые грабли

  • Чтение неинициализированной переменной: C# защищает от мусора в памяти. Если объявить переменную и попытаться прочитать её значение до присваивания, сборка завершится ошибкой CS0165: Use of unassigned local variable.
  • var без инициализации: компилятор не может угадать тип «из воздуха». Строка var x; всегда приводит к ошибке CS0818.
  • Попытка сменить тип у var: var фиксирует тип намертво. Команда var item = 10; item = "hello"; вызовет ошибку несовместимости типов CS0029.
  • Путаница кавычек для char и string: одинарные кавычки 'A' — строго один символ, двойные кавычки "A" — строка. Запись char c = "A"; не скомпилируется.
  • Повторное объявление: нельзя в одной области видимости объявить две переменные с одинаковым именем, даже если у них разные типы (например, int count; и рядом string count;).

В сухом остатке

  • Переменная связывает имя, тип и значение с участком в оперативной памяти.
  • C# требует строгого соответствия типов: значение должно отвечать заявленному типу переменной.
  • Ключевое слово var сокращает код, но оставляет типизацию статической и строгой.
  • Константы (const) защищают значения от случайных изменений во время выполнения.
  • Локальные переменные именуются в стиле camelCase понятными английскими словами.
