Привет, мир!

Минимальная рабочая программа на C#, вывод текста в терминал и разница между современным синтаксисом в одну строчку и классическим методом Main.

Кратко

В современном C# первая программа занимает ровно одну строчку без классов, пространств имён и шаблонных обёрток: 

Console.WriteLine("Привет, мир!");

Вызывается системный класс Console, запускается метод WriteLine(), и переданный в кавычках текст выводится в окно терминала. Всё остальное платформа делает сама.

Анатомия одной строки

Даже в одной команде задействованы базовые правила синтаксиса языка:

  • Console — встроенный статический класс платформы .NET, отвечающий за стандартный ввод и вывод.
  • .WriteLine(...) — вызов метода, который отправляет строку в терминал и сразу переводит курсор на новую строку.
  • "Привет, мир!" — строковый литерал. Текст всегда оборачивается в двойные кавычки.
  • ; — обязательный разделитель. Каждая инструкция в C# завершается точкой с запятой.

Top-level statements против классики

До версии C# 9 даже для вывода одного слова требовалось строить громоздкий каркас. Сейчас этот механизм автоматизирован с помощью инструкций верхнего уровня (Top-level statements).

Классический шаблон: как было раньше

В старых версиях языка и легаси-проектах точка входа объявляется явно через класс и метод: 

using System;

namespace HelloWorldApp
{
    internal class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Привет, мир!");
        }
    }
}

Здесь разработчик вручную подключает пространство имён через using System;, создаёт контейнер class Program и точку входа static void Main с массивом аргументов командной строки string[] args.

Современный подход: как устроено сейчас

Начиная с C# 9 и .NET 6, весь файл Program.cs может состоять только из рабочих команд. Компилятор сам «оборачивает» код в невидимый класс и синтезирует метод точки входа.

Важное правило: писать инструкции верхнего уровня разрешено только в одном файле проекта. Если добавить такой же код во второй файл, компилятор выдаст ошибку CS8802, так как точек входа не может быть две.

WriteLine против Write

Для печати текста используются два метода класса Console. Разница — в позиции курсора после вывода.

Console.WriteLine

Печатает текст и переносит курсор на следующую строку: 

Console.WriteLine("Строка 1");
Console.WriteLine("Строка 2");

Вывод:

Строка 1
Строка 2

Console.Write

Печатает текст и оставляет курсор на том же месте. Следующий вызов продолжит печать встык: 

Console.Write("Привет, ");
Console.Write("мир!");
Console.WriteLine(); // перенос строки без вывода текста

Вывод:

Привет, мир!

Частые грабли

  • Регистр букв: C# чувствителен к регистру. console.writeline или Console.writeline не скомпилируются. Имена типов и методов пишутся в PascalCase: Console.WriteLine.
  • Одинарные кавычки: запись 'Привет' вызовет ошибку. Одинарные кавычки зарезервированы под единичный символ char (например, 'A'), а строки всегда берутся в двойные кавычки "...".
  • Точка с запятой: пропуск ; в конце строки — самая частая синтаксическая ошибка у новичков.
  • Два файла с Top-level statements: свободный код вне классов допускается строго в одном файле. Все остальные файлы проекта обязаны содержать классы, структуры или интерфейсы.
  • Порядок объявлений: если в файле верхнего уровня объявляются функции или классы, они обязаны располагаться ниже выполняемых инструкций, а не перед ними.

В сухом остатке

  • Для первой программы на современном C# достаточно одной строчки: Console.WriteLine("...");.
  • Классический static void Main по-прежнему валиден, но обязателен только в легаси-проектах.
  • WriteLine() делает перенос на следующую строку, а Write() оставляет курсор на месте.
  • Инструкции верхнего уровня могут находиться только в одном .cs файле внутри проекта.
