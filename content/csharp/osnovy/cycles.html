Циклы

Повторение кода: while, do…while, for, foreach — и как прерывать итерации через break и continue.

while — пока условие истинно

Цикл с предусловием: условие проверяется перед каждой итерацией. Если оно ложно с самого начала — тело не выполнится ни разу.

int attempts = 0;
while (attempts < 3)
{
    Console.WriteLine($"Попытка {attempts + 1}");
    attempts++;
}
Попробуй: посчитай до N (while)

do…while — сначала действие, потом проверка

Цикл с постусловием: тело гарантированно выполняется хотя бы один раз, условие проверяется после:

int value;
do
{
    Console.Write("Введи число больше 0: ");
    value = int.Parse(Console.ReadLine());
} while (value <= 0);

Идеально для ввода данных с проверкой — спрашиваем пока пользователь не введёт корректное значение.

for — когда заранее известно, сколько раз

Классический счётный цикл: инициализация, условие, шаг — в одной строке заголовка:

for (int i = 0; i < 5; i++)
{
    Console.WriteLine($"i = {i}");
}
// Выведет: 0, 1, 2, 3, 4

Все три части опциональны — можно писать for (;;) (бесконечный цикл), но тогда выход организуется через break.

foreach — перебор коллекций

Для массивов, списков и всего, что можно перечислить. Читаемее, когда индекс не нужен:

string[] tools = { "IDE", "Git", "Отладчик" };
foreach (string tool in tools)
{
    Console.WriteLine($"Инструмент: {tool}");
}

Нельзя менять элементы через переменную цикла и нельзя добавлять/удалять элементы коллекции внутри foreach — для этого есть for с индексом.

break и continue

break полностью прерывает цикл. continue пропускает оставшуюся часть текущей итерации и переходит к следующей:

for (int i = 0; i < 10; i++)
{
    if (i == 3) continue;   // пропускаем 3
    if (i == 7) break;      // останавливаемся на 7
    Console.WriteLine(i);
}
// Выведет: 0, 1, 2, 4, 5, 6

Применяй осторожно — слишком много break/continue вложенных циклов делает код трудночитаемым.
