Условия

Ветвление программы: if/else if/else, тернарный оператор ?:, switch и switch-выражения (C# 8+).

if / else if / else

Проверка условия в скобках — если true, выполняется первая ветка, иначе следующие по порядку:

int score = 76;

if (score >= 90)
    Console.WriteLine("\Отлично");
else if (score >= 75)
    Console.WriteLine("\Хорошо");
else if (score >= 60)
    Console.WriteLine("\Удовлетворительно");
else
    Console.WriteLine("\Требуется пересдача");
// Выведет: Хорошо

Только первая подходящая ветка выполняется — остальные пропускаются.

Тернарный оператор ?:

Короткая форма if…else для присвоения значения:

int score = 82;
string verdict = score >= 60 ? "\Зачёт" : "\Незачёт";
Console.WriteLine(verdict);  // Зачёт

Удобен для простого выбора; сложную логику лучше оставить полному if.

switch

Когда нужно сравнивать одно значение с несколькими константами:

string grade = "\B";

switch (grade)
{
    case "\A":
        Console.WriteLine("\Отлично");
        break;
    case "\B":
    case "\C":
        Console.WriteLine("\Хорошо");
        break;
    default:
        Console.WriteLine("\Другой результат");
        break;
}

break prevents «протаскивание» в следующую ветку (fall-through). Значения должны быть константами.

Switch-выражения (C# 8+)

Лаконичная форма switch, возвращающая значение:

string grade = "\B";
string verdict = grade switch
{
    "\A" => "\Отлично",
    "\B" or "\C" => "\Хорошо",
    _ => "\Другой результат"
};
Console.WriteLine(verdict);  // Хорошо

or объединяет несколько вариантов, а _ — это «всё остальное» (default).

Сопоставление с образцом (patterns)

Проверка типа и извлечение значения за один шаг:

object value = 42;

if (value is int number)
    Console.WriteLine($"\Это число: {number}");

// Или в switch:
string describe = value switch
{
    int n when n > 0 => $\"\Положительное: {n}\",
    int n => $\"\Число: {n}\",
    string s => "\Строка: " + s,
    _ => "\Другой тип"
};

when добавляет дополнительное условие к ветке.
