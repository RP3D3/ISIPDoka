# Класс и объект: чертёж и экземпляр

Как описать собственный тип данных в C#, создать на его основе независимые объекты в памяти и заставить их выполнять действия?

**Класс** (`class`) — это пользовательский тип данных, который описывает устройство и поведение будущих сущностей: какие характеристики они будут хранить (поля) и какие действия выполнять (методы). **Объект** (или экземпляр класса) — это конкретная сущность, созданная в памяти по чертежу класса с помощью оператора `new`. По одному и тому же классу можно создать сколько угодно независимых объектов со своими собственными значениями.

## Сравнение класса и объекта

| Критерий | Класс (`class`) | Объект (экземпляр через `new`) |
| --- | --- | --- |
| **Роль в программе** | Чертёж, шаблон или описание нового типа данных | Конкретный экземпляр, созданный по этому чертежу |
| **Место в памяти** | Описывается в коде программы (метаданные типа) | Выделяется в управляемой куче (*Heap*) при вызове `new` |
| **Хранение значений** | Задаёт только названия и типы полей (например, `string Name`) | Хранит реальные данные (например, `"Алексей"`, `"Мария"`) |
| **Количество** | Описывается в программе один раз | Можно создать любое количество независимых копий |

## Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // Создание двух независимых объектов (экземпляров) по чертежу класса Student
        Student firstStudent = new Student();
        firstStudent.Name = "Алексей";
        firstStudent.Course = 2;

        // Сокращённый синтаксис создания с инициализатором объекта
        Student secondStudent = new Student
        {
            Name = "Мария",
            Course = 3
        };

        // Каждый объект хранит собственные данные и выполняет общие методы класса
        firstStudent.Introduce();
        secondStudent.Introduce();
    }
}

// Объявление класса: объединяем данные (поля) и поведение (методы)
class Student
{
    public string Name;
    public int Course;

    public void Introduce()
    {
        Console.WriteLine($"Студент: {Name}, курс: {Course}");
    }
}

```

## Важные нюансы

* **Оператор `new` обязателен для выделения памяти:** объявление переменной `Student s;` создаёт только пустую ссылку (`null`), но не сам объект. Попытка обратиться к полям или методам до вызова `new Student()` приведёт к ошибке `NullReferenceException`.
* **Классы являются ссылочными типами:** при вызове `new` объект размещается в куче (*Heap*), а в переменной хранится только ссылка на него. Если присвоить одну переменную другой (`Student s2 = firstStudent;`), обе будут указывать на один и тот же объект в памяти.
* **Упрощённый синтаксис `target-typed new`:** в современном C# (начиная с версии 9.0) название типа справа можно не дублировать, если оно уже указано слева: `Student s = new();`.
* **Связь с другими темами:** проектирование класса — это прямое применение *абстракции* и *инкапсуляции*, а работа ссылок в памяти разобрана в разделе *Принципы, паттерны и архитектура* (*Stack & Heap*).
