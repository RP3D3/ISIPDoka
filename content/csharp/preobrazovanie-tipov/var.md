# Неявная типизация: ключевое слово var

Как не дублировать длинные названия типов при создании переменных и почему `var` остаётся строго типизированным?

Ключевое слово `var` позволяет поручить определение типа переменной компилятору. Вместо явного указания типа слева от имени переменной (`int`, `string`, `double`) вы пишете `var`, а компилятор сам вычисляет точный тип по значению справа от знака `=`.

### Примеры вывода типов

| Явная запись | Запись с `var` | Выведенный тип |
| --- | --- | --- |
| `int count = 10;` | `var count = 10;` | `int` |
| `double price = 99.5;` | `var price = 99.5;` | `double` |
| `string title = "Меню";` | `var title = "Меню";` | `string` |
| `bool isReady = true;` | `var isReady = true;` | `bool` |

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // Компилятор сам определяет строгий тип по значению справа от знака =
        var age = 25;              // int
        var temperature = 36.6;    // double
        var playerName = "Алекс";  // string
        var isOnline = false;      // bool

        // Ошибка: нельзя записать строку в переменную, которая уже стала int
        // age = "двадцать пять";

        // Удобно применять в цикле foreach и при создании массивов
        var items = new[] { "Ключ", "Карта", "Компас" };
        foreach (var item in items)
        {
            Console.WriteLine($"Предмет: {item}");
        }

        Console.WriteLine($"{playerName}, возраст: {age}, в сети: {isOnline}");
    }
}

```

### Важные нюансы

* **`var` — это не динамический тип:** компилятор подставляет конкретный жёсткий тип ещё на этапе сборки программы. Поменять тип переменной позже (например, записать текст в числовую переменную) нельзя.
* **Обязательная инициализация сразу:** нельзя написать просто `var x;` без значения — компилятору не от чего оттолкнуться, чтобы определить тип.
* **Запрет на `var x = null;`:** значение `null` не относится ни к одному конкретному типу, поэтому такая запись вызовет ошибку компиляции.
* **Когда лучше писать тип явно:** если по правой части выражения сразу непонятно, какой именно тип вернётся (например, результат вызова незнакомого метода), лучше указать тип явно (`int`, `decimal`, `string`), чтобы код легко читался.
