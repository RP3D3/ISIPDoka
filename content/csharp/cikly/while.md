# Цикл с предусловием while

Как заставить программу повторять блок команд до тех пор, пока выполняется условие, если количество шагов заранее неизвестно?

Цикл `while` («пока») проверяет логическое условие перед каждым запуском своего тела. Если условие истинно (`true`), код внутри фигурных скобок выполняется, после чего проверка повторяется снова — и так до тех пор, пока условие не станет ложным (`false`).

### Как устроен цикл

* **`while (условие) { ... }`** — сначала вычисляет выражение в круглых скобках, и только при результате `true` запускает команды внутри блока.
* **Возможность нуля повторений:** если условие ложно уже при самой первой проверке, тело цикла не выполнится ни разу, и программа сразу пойдёт дальше.
* **Когда применять:** идеально подходит для задач, где число шагов заранее неизвестно — например, ожидание правильного пароля, чтение данных до конца или игровой цикл, пока у персонажа есть здоровье.

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // 1. Обратный отсчёт с изменением переменной внутри цикла
        int fuel = 3;
        while (fuel > 0)
        {
            Console.WriteLine($"Полёт продолжается. Осталось топлива: {fuel}");
            fuel--; // Обязательно меняем переменную, чтобы цикл завершился
        }
        Console.WriteLine("Топливо закончилось, посадка!");

        // 2. Ожидание правильного ввода (число попыток заранее неизвестно)
        string secret = "1234";
        string input = "";

        while (input != secret)
        {
            Console.Write("Введите пин-код: ");
            input = Console.ReadLine();
        }

        Console.WriteLine("Доступ разрешён!");
    }
}

```

### Важные нюансы

* **Ловушка бесконечного цикла:** если внутри тела `while` забыть изменить переменную, от которой зависит условие (например, убрать строку `fuel--`), условие навсегда останется `true` и программа зависнет.
* **Никакой точки с запятой после `while (...)`:** запись `while (fuel > 0);` создаёт пустой бесконечный цикл на месте, из-за чего программа застрянет на этой строке и не дойдёт до фигурных скобок.
* **Подготовка переменных заранее:** все переменные, участвующие в проверке условия, должны быть объявлены и иметь начальное значение ещё до строки с `while`.
