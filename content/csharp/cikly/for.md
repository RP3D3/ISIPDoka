# Цикл со счётчиком for

Как повторить блок кода строго заданное количество раз, управлять шагом счёта и пройтись по числам в обратном порядке?

Цикл `for` («для») предназначен для ситуаций, когда количество повторений известно заранее или легко вычисляется. Он объединяет создание счётчика, условие остановки и изменение шага в одной компактной строке заголовка.

### Три части заголовка цикла

Синтаксис записи выглядит так: `for (инициализация; условие; шаг) { ... }`

* **Инициализация (`int i = 0`):** выполняется всего **один** раз перед самым запуском цикла — здесь обычно создают переменную-счётчик.
* **Условие (`i < 5`):** проверяется **перед каждым** шагом. Пока оно возвращает `true`, тело цикла выполняется; при `false` цикл завершается.
* **Шаг (`i++`):** срабатывает **после каждого** прохода тела цикла и обновляет счётчик (увеличивает или уменьшает его).

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // 1. Классический прямой отсчёт от 1 до 5 (ровно 5 повторений)
        for (int i = 1; i <= 5; i++)
        {
            Console.WriteLine($"Шаг номер {i}");
        }

        // 2. Обратный отсчёт от 3 до 1
        for (int i = 3; i >= 1; i--)
        {
            Console.WriteLine($"Обратный отсчёт: {i}");
        }

        // 3. Произвольный шаг: перебор только чётных чисел и подсчёт суммы
        int sum = 0;
        for (int i = 2; i <= 10; i += 2)
        {
            sum += i;
        }
        Console.WriteLine($"Сумма чётных чисел от 2 до 10: {sum}");
    }
}

```

### Важные нюансы

* **Область видимости счётчика:** переменная `i`, объявленная внутри скобок `for (int i = 0; ...)`, существует только внутри этого цикла. После его завершения обратиться к `i` нельзя, зато можно спокойно завести следующий цикл с таким же именем `i`.
* **Разделители — только точки с запятой `;`:** три части в заголовке всегда разделяются точкой с запятой, а не запятыми. В конце закрывающей круглой скобки `for (...)` точка с запятой не ставится.
* **Ошибка на единицу (`<` против `<=`):** при счёте с нуля `for (int i = 0; i < 5; i++)` выполнится ровно 5 раз (значения `0, 1, 2, 3, 4`). Если случайно написать `i <= 5`, проходов станет 6.
* **Не меняйте счётчик внутри тела:** избегайте ручного изменения переменной `i` внутри фигурных скобок, если за её обновление уже отвечает третья часть заголовка — иначе легко сбить логику или получить бесконечный цикл.
