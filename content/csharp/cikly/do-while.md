# Цикл с постусловием do-while

Как гарантировать, что блок кода выполнится хотя бы один раз, даже если условие с самого начала ложно?

Цикл `do-while` («делай, пока») сначала выполняет команды внутри фигурных скобок, а уже затем проверяет условие. В отличие от обычного `while`, проверка здесь стоит в самом конце, поэтому тело цикла всегда срабатывает минимум один раз.

### Как устроен цикл

* **`do { ... } while (условие);`** — сначала запускает тело цикла, потом вычисляет выражение в круглых скобках: если оно истинно (`true`), цикл повторяется; если ложно (`false`), программа идёт дальше.
* **Минимум одно выполнение:** даже если условие изначально равно `false`, код внутри `do` всё равно успеет отработать один раз до первой проверки.
* **Когда применять:** идеально подходит для интерактивного консольного меню, запроса ввода у пользователя или повторения действия до получения нужного результата.

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // 1. Консольное меню: сначала показываем пункты, потом проверяем выбор
        string command;
        do
        {
            Console.WriteLine("Меню: 1 — Новая игра, 0 — Выход");
            Console.Write("Выберите действие: ");
            command = Console.ReadLine();
        }
        while (command != "0");

        Console.WriteLine("Программа завершена.");

        // 2. Гарантированный первый запуск при ложном условии
        int energy = 0;
        do
        {
            Console.WriteLine("Этот код выполнится ровно 1 раз, хотя энергии уже 0.");
        }
        while (energy > 0);
    }
}

```

### Важные нюансы

* **Обязательная точка с запятой `;` в конце:** после закрывающей скобки `while (условие);` всегда ставится точка с запятой — без неё программа не скомпилируется.
* **Объявление переменной до блока `do`:** переменную, которая проверяется в условии `while (...)`, нужно объявить *перед* словом `do`. Если объявить её внутри фигурных скобок `{ ... }`, в условии внизу она будет не видна.
* **Контроль выхода:** как и в обычном `while`, внутри тела цикла необходимо менять данные, влияющие на условие, иначе цикл станет бесконечным.
