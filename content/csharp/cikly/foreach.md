# Цикл перебора foreach

Как пройтись по всем элементам массива, списка или символам строки без ручного управления счётчиками и индексами?

Цикл `foreach` («для каждого») последовательно берёт каждый элемент из набора данных от начала до конца и помещает его во временную переменную. Он избавляет от необходимости следить за границами и полностью защищает от случайного выхода за пределы коллекции.

### Как устроен цикл

Синтаксис записи выглядит так: `foreach (тип переменная in коллекция) { ... }`

* **`тип переменная`** — локальная переменная, в которую на каждом шаге копируется очередной элемент (можно указать точный тип, например `string`, или доверить выбор компилятору через `var`).
* **`in коллекция`** — источник данных, по которому идёт проход (массив, список или обычная строка `string`).
* **Автоматическая остановка:** цикл сам знает длину набора данных и завершится ровно тогда, когда закончатся все элементы.

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // 1. Перебор элементов массива строк
        string[] inventory = { "Меч", "Щит", "Зелье" };
        foreach (string item in inventory)
        {
            Console.WriteLine($"В рюкзаке лежит: {item}");
        }

        // 2. Перебор всех символов в строке с ключевым словом var
        string word = "Код";
        foreach (var letter in word)
        {
            Console.WriteLine($"Буква: {letter}");
        }

        // 3. Подсчёт суммы всех чисел в массиве
        int[] scores = { 10, 25, 15, 30 };
        int total = 0;
        foreach (int score in scores)
        {
            total += score;
        }
        Console.WriteLine($"Итоговый счёт: {total}");
    }
}

```

### Важные нюансы

* **Работа только на чтение:** переменную цикла (например, `item` или `score`) нельзя перезаписать внутри тела `foreach` — попытка написать `score = 0;` вызовет ошибку компиляции. Если элементы нужно изменять, используют цикл `for`.
* **Запрет на изменение состава коллекции:** добавление новых или удаление существующих элементов из списка прямо во время работы `foreach` приведёт к аварийной ошибке программы (`InvalidOperationException`).
* **Нет информации о номере элемента:** `foreach` отдаёт само значение, но не сообщает его порядковый индекс. Если нужно знать позицию элемента или двигаться с конца в начало, лучше выбрать `for`.
* **Удобство ключевого слова `var`:** вместо ручного указания типа часто пишут `foreach (var item in inventory)` — компилятор сам определит тип переменной на основе типа элементов коллекции.
