# Вложенные циклы

Как заставить один цикл работать внутри другого, чтобы обрабатывать таблицы, сетки и двумерные координаты?

Вложенный цикл — это конструкция, когда внутри тела одного цикла (внешнего) размещается другой цикл (внутренний). На каждый **один** шаг внешнего цикла внутренний цикл прокручивается **полностью** от начала до конца.

### Принцип работы

* **Аналогия с часами:** внешний цикл работает как часовая стрелка, а внутренний — как минутная. Пока часовая стрелка делает 1 шаг, минутная успевает пробежать полный круг.
* **Строки и столбцы:** при работе с таблицами и сетками внешний цикл обычно перебирает **строки** (сверху вниз), а внутренний — **столбцы** внутри текущей строки (слева направо).
* **Общее число срабатываний:** равно произведению шагов внешнего и внутреннего циклов (например, 3 строки по 5 столбцов дадут 15 повторений внутреннего кода).

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        // 1. Рисуем прямоугольник из звёздочек (3 строки по 5 столбцов)
        for (int row = 1; row <= 3; row++)
        {
            for (int col = 1; col <= 5; col++)
            {
                Console.Write("* ");
            }
            Console.WriteLine(); // Переход на новую строку после завершения внутреннего цикла
        }

        Console.WriteLine();

        // 2. Мини-таблица умножения (числа от 1 до 3)
        for (int i = 1; i <= 3; i++)
        {
            for (int j = 1; j <= 3; j++)
            {
                Console.Write($"{i}x{j}={i * j}\t");
            }
            Console.WriteLine();
        }
    }
}

```

### Важные нюансы

* **Разные имена счётчиков:** если внешний цикл использует переменную `i`, внутренний обязан иметь другое имя — обычно `j` (для третьего уровня — `k`). Одинаковое имя вызовет ошибку компиляции.
* **Сброс внутреннего счётчика:** при каждом новом шаге внешнего цикла внутренний цикл запускается заново с самого начала, а его счётчик сбрасывается в исходное значение.
* **Действие `break` и `continue`:** эти операторы управляют только тем циклом, в котором они вызваны. Команда `break` во внутреннем цикле прервёт только его, а внешний цикл продолжит работу.
* **Контроль глубины:** число операций растёт при перемножении (100 шагов снаружи и 100 внутри дадут 10 000 повторений). Старайтесь не делать глубже 2–3 уровней вложенности, чтобы код оставался быстрым и понятным.
