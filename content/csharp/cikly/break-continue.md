# Операторы управления циклом break и continue

Как досрочно прервать выполнение цикла при нахождении нужного результата или пропустить один неподходящий шаг?

Операторы `break` и `continue` позволяют гибко управлять ходом любого цикла (`while`, `do-while`, `for`, `foreach`), меняя стандартный порядок повторений по дополнительному условию внутри тела.

### Разница между операторами

| Оператор | Что делает | Куда переходит программа | Типичный пример |
| --- | --- | --- | --- |
| `break` | Полностью прерывает и завершает цикл | На первую строку кода **после** закрывающей скобки цикла | Поиск нужного элемента: нашли — дальше искать незачем |
| `continue` | Досрочно завершает **текущий** шаг (итерацию) | К проверке условия или шагу следующего повторения цикла | Фильтрация данных: пропуск пустых строк или отрицательных чисел |

### Пример кода

```csharp
using System;

class Program
{
    static void Main()
    {
        int[] numbers = { 12, -5, 8, 0, 19, 4 };

        // 1. Оператор continue — пропускаем отрицательные числа и ноль
        Console.WriteLine("Только положительные числа:");
        foreach (int num in numbers)
        {
            if (num <= 0)
            {
                continue; // Пропускаем остаток шага и берём следующее число
            }
            Console.WriteLine($"Число: {num}");
        }

        // 2. Оператор break — останавливаем поиск, как только нашли число 19
        for (int i = 0; i < numbers.Length; i++)
        {
            if (numbers[i] == 19)
            {
                Console.WriteLine($"Число 19 найдено на позиции {i}. Поиск остановлен.");
                break; // Немедленный выход из цикла for
            }
        }
    }
}

```

### Важные нюансы

* **Ловушка `continue` в цикле `while`:** если поставить `continue` *до* строки, которая обновляет переменную-счётчик (например, `i++`), условие перестанет меняться и цикл станет бесконечным. В цикле `for` такой проблемы нет, так как третья секция заголовка сработает в любом случае.
* **Выход только из одного уровня:** во вложенных циклах `break` прерывает только тот внутренний цикл, в котором он вызван, а внешний цикл продолжает работу.
* **Недостижимый код:** любые команды, записанные в том же блоке сразу после `break` или `continue`, никогда не выполнятся — компилятор предупредит об этом.
* **Не путайте `break` и `return`:** `break` завершает только текущий цикл (или конструкцию `switch`), тогда как `return` полностью прерывает работу всего метода.
