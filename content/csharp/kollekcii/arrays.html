Массивы

Фиксированный набор однотипных значений в непрерывной памяти: объявление, доступ по индексу, перебор for/foreach, многомерные и зубчатые массивы.

Создание массива

Массив — набор элементов одного типа фиксированной длины. Размер задаётся один раз и не меняется:

// Пустой массив на 3 элемента (по умолчанию все нули)
int[] buffer = new int[3];

// Сразу с значениями — длина вычисляется сама
string[] students = { "Анна", "Борис", "Вера" };

// Компактная запись с var и new()
var days = new int[] { 1, 2, 3, 4, 5 };

Индексы и Length

Нумерация начинается с нуля. Последний элемент имеет индекс Length − 1:

int[] scores = { 22, 34, 40, 25, 50 };

int first = scores[0];        // 22
int last = scores[scores.Length - 1];   // 50
scores[2] = 41;               // заменили третий элемент

// Индекс с конца — оператор ^ (C# 8+):
int last2 = scores[^1];       // тоже 50

Свойство Length — количество элементов, оно неизменяемо у созданного массива.

Перебор: for или foreach

for нужен, когда важен индекс (например, идём с шагом 2). foreach — когда пробегаем все элементы и менять их не требуется:

string[] students = { "Анна", "Борис", "Вера" };

// классический перебор с индексом
for (int i = 0; i < students.Length; i++)
{
    Console.WriteLine($"{i}. {students[i]}");
}

// когда нужен только элемент
foreach (string name in students)
{
    Console.WriteLine($"Привет, {name}!");
}

У переменной foreach нельзя присваивать новое значение элементу массива — для изменений используй for.

Многомерные и зубчатые

Прямоугольный массив — таблица [rows, cols]. Зубчатый — «массив массивов», строки могут быть разной длины:

// прямоугольная таблица оценок 2 × 3
int[,] marks = new int[2, 3];
marks[0, 0] = 5;
marks[1, 2] = 4;

// зубчатый массив: у каждой строки своя длина
int[][] pyramid = new int[3][];
pyramid[0] = new[] { 5 };
pyramid[1] = new[] { 5, 4 };
pyramid[2] = new[] { 5, 4, 3 };

foreach (int[] row in pyramid)
    Console.WriteLine(string.Join(", ", row));

Частые ошибки

Выход за границы массива — классика runtime-ошибок:

int[] arr = { 1, 2, 3 };

// arr[3] — IndexOutOfRangeException!
// Правильно: последний элемент — arr[arr.Length - 1] == arr[2]

Полезные утилиты класса Array: Array.Sort(arr), Array.Reverse(arr), Array.IndexOf(arr, value), а отличие копий — arr.Clone() делает поверхностную копию.
