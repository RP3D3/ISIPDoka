# Очередь и стек: принципы FIFO и LIFO

Как обрабатывать задачи строго в порядке их поступления или возвращаться к последним действиям, как при нажатии кнопки «Отмена»?

Очередь (`Queue<T>`) и стек (`Stack<T>`) — это коллекции со строгим порядком доступа к элементам. В отличие от списка, здесь нельзя достать произвольный элемент из середины по индексу: очередь работает по принципу живой очереди в кассу (первым пришёл — первым ушёл), а стек напоминает стопку тарелок (последним положили — первым забрали).

### Сравнение очереди и стека

| Характеристика | Очередь (`Queue<T>`) | Стек (`Stack<T>`) |
| --- | --- | --- |
| **Принцип работы** | **FIFO** (First-In, First-Out — первым вошёл, первым вышел) | **LIFO** (Last-In, First-Out — последним вошёл, первым вышел) |
| **Добавить элемент** | `queue.Enqueue(item)` — в конец очереди | `stack.Push(item)` — на вершину стека |
| **Извлечь с удалением** | `queue.Dequeue()` — забирает первый (самый старый) элемент | `stack.Pop()` — забирает верхний (самый новый) элемент |
| **Посмотреть без удаления** | `queue.Peek()` — показывает первый элемент | `stack.Peek()` — показывает верхний элемент |
| **Типичные задачи** | Очередь печати, обработка заказов, запросы на сервер | История отмены действий (Ctrl+Z), история переходов в браузере |

### Пример кода

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        // 1. Очередь (FIFO): первым пришёл — первым обслужен
        Queue<string> printQueue = new Queue<string>();
        printQueue.Enqueue("Документ_1.pdf");
        printQueue.Enqueue("Отчёт_2.docx");
        printQueue.Enqueue("Чек_3.png");

        Console.WriteLine($"Следующий на печать: {printQueue.Peek()}"); // Документ_1.pdf (не удаляется)

        while (printQueue.Count > 0)
        {
            string currentDoc = printQueue.Dequeue(); // Извлекает и удаляет из начала
            Console.WriteLine($"Печатается: {currentDoc}");
        }

        // 2. Стек (LIFO): последним добавлен — первым извлечён
        Stack<string> history = new Stack<string>();
        history.Push("Открыта главная страница");
        history.Push("Переход в каталог");
        history.Push("Открыта карточка товара");

        Console.WriteLine($"\nТекущий шаг: {history.Peek()}"); // Открыта карточка товара

        // Имитация нажатия кнопки «Назад» (извлекаем в обратном порядке)
        while (history.Count > 0)
        {
            string lastAction = history.Pop(); // Извлекает и удаляет с вершины
            Console.WriteLine($"Откат действия: {lastAction}");
        }
    }
}

```

### Важные нюансы

* **Ошибка при пустой коллекции:** вызов `Dequeue()`, `Pop()` или `Peek()` на пустой очереди или стеке приведёт к аварийной ошибке (`InvalidOperationException`). Перед извлечением всегда проверяйте `Count > 0` или используйте безопасные методы `TryDequeue(out item)` и `TryPop(out item)`.
* **Разница между извлечением и просмотром:** методы `Dequeue` и `Pop` забирают элемент и уменьшают размер коллекции (`Count`), а метод `Peek` позволяет только подсмотреть крайний элемент, оставляя его на месте.
* **Нет доступа по индексу:** обратиться к элементу в середине через квадратные скобки (`queue[1]` или `stack[1]`) невозможно — коллекции разрешают работать только с крайними элементами.
* **Перебор через `foreach` не удаляет элементы:** цикл `foreach` позволяет просто просмотреть содержимое очереди (от начала к концу) или стека (от вершины к основанию), не очищая саму коллекцию.
