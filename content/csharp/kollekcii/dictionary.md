# Словарь: хранение пар «ключ — значение»

Как находить нужные данные не по порядковому номеру индекса, а по уникальному имени, артикулу или логину?

Словарь (`Dictionary<TKey, TValue>`) — это коллекция, которая хранит данные в виде связанных пар **«ключ — значение»**. Вместо числового индекса для быстрого доступа к элементу здесь используется уникальный ключ (например, строка, артикул товара или код страны), по которому программа мгновенно находит соответствующее значение.

### Основные операции со словарём

| Элемент | Что делает | Особенность работы |
| --- | --- | --- |
| `new Dictionary<TKey, TValue>()` | Создаёт пустой словарь с заданными типами ключа и значения | `var ages = new Dictionary<string, int>();` |
| `dict.Add(key, value)` | Добавляет новую пару «ключ — значение» | Вызовет ошибку, если такой ключ уже существует |
| `dict[key] = value` | Записывает или обновляет значение по ключу | Если ключа нет — создаст запись; если есть — перезапишет |
| `dict[key]` | Читает значение по указанному ключу | Вызовет ошибку, если ключ отсутствует в словаре |
| `dict.Remove(key)` | Удаляет запись из словаря по её ключу | Возвращает `true`, если запись найдена и удалена |
| `dict.Count` | Возвращает общее количество пар в словаре | Аналог свойства `Count` у списка |

### Пример кода

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        // 1. Создание словаря: ключ — артикул (string), значение — цена (int)
        Dictionary<string, int> prices = new Dictionary<string, int>();

        // 2. Добавление новых записей через метод Add
        prices.Add("A-101", 1500);
        prices.Add("B-205", 3200);

        // 3. Добавление и обновление через квадратные скобки [ключ]
        prices["C-309"] = 850;  // Ключа "C-309" не было — создастся новая запись
        prices["A-101"] = 1750; // Ключ "A-101" уже был — цена обновится на 1750

        // 4. Чтение значения по ключу и проверка размера
        Console.WriteLine($"Цена товара A-101: {prices["A-101"]} руб.");
        Console.WriteLine($"Всего товаров в каталоге: {prices.Count}");

        // 5. Удаление записи по ключу
        prices.Remove("B-205");
        Console.WriteLine($"После удаления осталось записей: {prices.Count}");
    }
}

```

### Важные нюансы

* **Все ключи обязаны быть уникальными:** в одном словаре не может быть двух одинаковых ключей, а вот значения могут свободно повторяться у разных ключей.
* **Разница между `Add` и квадратными скобками:** метод `prices.Add("A-101", 2000)` выбросит аварийную ошибку (`ArgumentException`), если такой ключ уже занят. Присваивание `prices["A-101"] = 2000` работает мягче — оно просто перезапишет старое значение новым.
* **Ключ не может быть `null`:** в отличие от значения, ключ используется для мгновенного поиска внутри памяти словаря, поэтому передать `null` в качестве ключа нельзя.
* **Нет привычной нумерации по порядку:** элементы в словаре не предназначены для обращения по номеру позиции вроде «первый» или «второй» — доступ идёт только по смысловому ключу.
