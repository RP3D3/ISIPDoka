# Динамический список: создание, добавление и удаление

Как хранить набор однотипных элементов, который может свободно расти и уменьшаться во время работы программы?

Динамический список (`List<T>`) — это «резиновый» аналог обычного массива. В отличие от массива с жёстко заданным размером, список сам выделяет дополнительную память при добавлении новых данных и сжимается при их удалении, сохраняя привычный доступ к элементам по индексу `[i]`.

### Основные свойства и методы списка

| Элемент | Что делает | Особенность работы |
| --- | --- | --- |
| `list.Count` | Возвращает текущее количество элементов в списке | Аналог свойства `Length` у обычного массива |
| `list[i]` | Читает или перезаписывает элемент по его номеру | Индексы идут от `0` до `Count - 1` |
| `list.Add(item)` | Добавляет новый элемент в самый конец списка | Увеличивает `Count` на единицу |
| `list.Insert(index, item)` | Вставляет элемент на указанную позицию | Сдвигает все следующие элементы вправо |
| `list.Remove(item)` | Удаляет первое совпадение по значению | Возвращает `true`, если элемент найден и удалён |
| `list.RemoveAt(index)` | Удаляет элемент по его номеру индекса | Сдвигает оставшиеся элементы влево |
| `list.Clear()` | Удаляет все элементы из списка сразу | Сбрасывает `Count` в `0` |

### Пример кода

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        // 1. Создание пустого списка и добавление элементов в конец
        List<string> tasks = new List<string>();
        tasks.Add("Проверить почту");
        tasks.Add("Написать код");
        tasks.Add("Сделать резервную копию");

        // 2. Вставка элемента на конкретную позицию (индекс 1 — вторым по счёту)
        tasks.Insert(1, "Созвон с командой");

        // 3. Чтение по индексу и получение размера через Count
        Console.WriteLine($"Первая задача: {tasks[0]}");
        Console.WriteLine($"Всего задач: {tasks.Count}");

        // 4. Удаление по значению и по индексу
        tasks.Remove("Написать код"); // Удалит по тексту задачи
        tasks.RemoveAt(0);            // Удалит первый элемент ("Проверить почту")

        Console.WriteLine($"Осталось задач: {tasks.Count}");
        foreach (string task in tasks)
        {
            Console.WriteLine($"- {task}");
        }

        // 5. Полная очистка списка
        tasks.Clear();
        Console.WriteLine($"После очистки элементов: {tasks.Count}");
    }
}

```

### Важные нюансы

* **`Count` вместо `Length`:** у массивов количество ячеек хранится в свойстве `Length`, а у динамических коллекций — в свойстве `Count`. Последний доступный индекс списка всегда равен `Count - 1`.
* **`Remove` удаляет только первое совпадение:** если в списке лежат два одинаковых значения, вызов `Remove` уберёт только первое из них слева и вернёт `true` (или `false`, если значение не найдено).
* **Автоматический сдвиг индексов:** после `Insert` или `RemoveAt` список сам пересчитывает номера всех последующих элементов — пустых «дырок» внутри него не остаётся.
* **Подключение библиотеки коллекций:** для работы со списком `List<T>` в самом верху файла должна быть подключена директива `using System.Collections.Generic;`.
