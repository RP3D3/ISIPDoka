# Безопасное чтение и перебор словаря

Как проверить наличие нужного ключа в словаре без риска аварийной ошибки и обойти все пары «ключ — значение» в цикле?

Прямое обращение к словарю по несуществующему ключу через квадратные скобки (`dict[key]`) приводит к аварийной остановке программы (`KeyNotFoundException`). Чтобы работать со словарём безопасно, используют предварительную проверку ключа или метод извлечения с выходным параметром `out`, а для просмотра всех записей применяют цикл `foreach`.

### Способы безопасного чтения и обхода

| Инструмент | Что делает | Особенность работы |
| --- | --- | --- |
| `dict.ContainsKey(key)` | Проверяет, существует ли указанный ключ в словаре | Возвращает `true` или `false` без извлечения значения |
| `dict.TryGetValue(key, out val)` | Пытается найти ключ и сразу записать значение в переменную `val` | Возвращает `true` при успехе и `false`, если ключа нет (один поиск вместо двух) |
| `dict.ContainsValue(val)` | Проверяет, есть ли хотя бы одна запись с таким значением | Работает медленнее поиска по ключу (проверяет все записи подряд) |
| `foreach (var pair in dict)` | Перебирает все пары «ключ — значение» в словаре | Даёт доступ к свойствам `pair.Key` и `pair.Value` |
| `dict.Keys` и `dict.Values` | Возвращают отдельные коллекции только ключей или только значений | Удобны, когда нужна только одна половина каждой записи |

### Пример кода

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        Dictionary<string, int> stock = new Dictionary<string, int>
        {
            { "Клавиатура", 12 },
            { "Мышь", 25 },
            { "Монитор", 4 }
        };

        // 1. Проверка наличия ключа перед чтением (ContainsKey)
        string item = "Мышь";
        if (stock.ContainsKey(item))
        {
            Console.WriteLine($"Товар «{item}» в наличии: {stock[item]} шт.");
        }

        // 2. Безопасное получение значения за один шаг (TryGetValue + out)
        if (stock.TryGetValue("Ноутбук", out int laptopCount))
        {
            Console.WriteLine($"Ноутбуков на складе: {laptopCount} шт.");
        }
        else
        {
            // Если ключа нет, ошибки не будет, а laptopCount получит значение по умолчанию (0)
            Console.WriteLine($"Товар «Ноутбук» не найден (остаток: {laptopCount}).");
        }

        // 3. Перебор всех пар «ключ — значение» через цикл foreach
        Console.WriteLine("\nВесь склад:");
        foreach (KeyValuePair<string, int> pair in stock)
        {
            Console.WriteLine($"- {pair.Key}: {pair.Value} шт.");
        }

        // 4. Перебор только ключей через свойство Keys
        Console.WriteLine($"Список позиций: {string.Join(", ", stock.Keys)}");
    }
}

```

### Важные нюансы

* **`TryGetValue` быстрее связки `ContainsKey` + `dict[key]`:** при использовании `ContainsKey` с последующим чтением `dict[key]` словарь ищет один и тот же ключ дважды. Метод `TryGetValue` находит ключ и сразу достаёт значение за один проход.
* **Безопасность при отсутствии ключа:** если ключа нет в словаре, `TryGetValue` не выбрасывает ошибку, а возвращает `false` и записывает в `out`-переменную значение по умолчанию (`0` для чисел, `false` для `bool`, `null` для строк).
* **Короткая запись `var` в цикле `foreach`:** вместо длинного типа `KeyValuePair<string, int>` в цикле обычно пишут `foreach (var pair in stock)` — компилятор сам определит тип пары.
* **Нельзя менять состав словаря внутри `foreach`:** добавление или удаление записей во время обхода словаря в `foreach` вызовет аварийную ошибку (`InvalidOperationException`).
