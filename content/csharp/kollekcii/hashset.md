# Множество: хранение уникальных элементов

Как автоматически избавиться от дубликатов в наборе данных, мгновенно проверять наличие элемента и находить пересечения двух списков?

Множество (`HashSet<T>`) — это коллекция, которая хранит исключительно уникальные элементы без повторов. При попытке добавить уже существующее значение оно просто игнорируется без ошибки, а поиск элемента работает практически мгновенно даже на десятках тысяч записей.

### Основные методы и операции над множествами

| Метод | Что делает | Особенность работы |
| --- | --- | --- |
| `set.Add(item)` | Добавляет элемент, если его ещё нет в наборе | Возвращает `true` при добавлении и `false`, если это дубликат |
| `set.Contains(item)` | Проверяет, есть ли элемент во множестве | Работает намного быстрее, чем в обычном списке `List` |
| `set.Remove(item)` | Удаляет указанный элемент из множества | Возвращает `true`, если элемент был найден и удалён |
| `set.UnionWith(other)` | Объединяет два множества (все уникальные из обоих) | Изменяет текущее множество, добавляя недостающие элементы |
| `set.IntersectWith(other)` | Оставляет только общие элементы (пересечение) | Удаляет всё, чего нет во втором наборе |
| `set.ExceptWith(other)` | Вычитает элементы второго множества (разность) | Удаляет элементы, которые встречаются в `other` |

### Пример кода

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        // 1. Создание множества и автоматическое отсеивание дубликатов
        HashSet<string> tags = new HashSet<string>();
        tags.Add("код");
        tags.Add("учёба");
        bool added = tags.Add("код"); // Вернёт false — дубликат не добавится

        Console.WriteLine($"Добавлен ли повторный тег: {added}");
        Console.WriteLine($"Уникальных тегов: {tags.Count}"); // Выведет 2

        // 2. Быстрая проверка наличия элемента
        if (tags.Contains("учёба"))
        {
            Console.WriteLine("Тег «учёба» найден в наборе.");
        }

        // 3. Операции над двумя множествами (пересечение и объединение)
        HashSet<int> groupA = new HashSet<int> { 1, 2, 3, 4 };
        HashSet<int> groupB = new HashSet<int> { 3, 4, 5, 6 };

        // Находим общие элементы (пересечение)
        HashSet<int> common = new HashSet<int>(groupA);
        common.IntersectWith(groupB); // Останутся { 3, 4 }

        // Объединяем оба набора без повторов
        HashSet<int> all = new HashSet<int>(groupA);
        all.UnionWith(groupB); // Получится { 1, 2, 3, 4, 5, 6 }

        Console.WriteLine($"Общие элементы: {string.Join(", ", common)}");
        Console.WriteLine($"Все уникальные: {string.Join(", ", all)}");
    }
}

```

### Важные нюансы

* **Нет доступа по индексу:** во множестве нельзя написать `tags[0]` — элементы хранятся в специальном порядке для сверхбыстрого поиска, поэтому перебирать их можно только в цикле `foreach`.
* **Мгновенный поиск `Contains`:** в обычном списке `List` поиск перебирает элементы по очереди, а `HashSet` вычисляет адрес элемента напрямую и находит его за одно действие независимо от размера коллекции.
* **Простой способ убрать дубликаты из списка:** чтобы очистить обычный список или массив от повторов, достаточно передать его в конструктор нового множества: `var unique = new HashSet<int>(numbers);`.
* **Операции меняют исходное множество:** методы `UnionWith`, `IntersectWith` и `ExceptWith` перезаписывают ту коллекцию, у которой они вызваны — если исходный набор нужно сохранить, заранее создайте его копию.
