List<T>

Динамический список вместо массива: растёт и ужимается сам, умеет Add/Remove/Sort/Contains и хранит Count отдельно от Capacity.

Зачем нужен, если есть массив

У массива длина фиксирована: семь элементов — значит семь навсегда. List<T> добавляет и удаляет элементы на ходу, перевыделяя память под капотом:

int[] fixedBuffer = new int[5];    // ровно 5, навсегда
var journal = new List();  // пусто, но может стать хоть чем
Редактор списка: Count меняется сам
Count = 0

    Создание

    using System.Collections.Generic;   // где живут коллекции

var empty = new List();

// сразу с значениями (коллекционный инициализатор)
var defaultApps = new List { "Edge", "Калькулятор", "Блокнот" };

// список из массива
int[] buffer = { 1, 2, 3 };
var copy = new List(buffer);

// пустой список с запасом ёмкости (без лишних перевыделений)
var preallocated = new List(1000);

    T в List<T> — обобщение (generics): тип элементов фиксируется один раз. Один и тот же класс служит и для списка строк, и для списка студенческих структур — компилятор следит за типом.

    Основные методы

    var journal = new List { "Лаба 1", "Лаба 2" };

journal.Add("Лаба 3");            // добавить в конец
journal.AddRange(new[] { "Л4", "Л5" }); // несколько сразу
journal.Insert(1, "Лаба 1.5");    // вставить на позицию
journal.Remove("Лаба 2");         // удалить по значению
journal.RemoveAt(0);              // удалить по индексу
bool has = journal.Contains("Л5"); // есть ли такой
int where = journal.IndexOf("Л5"); // под каким индексом (или −1)
journal.Sort();                   // отсортировать
journal.Reverse();                // развернуть
journal.Clear();                  // вычистить всё

    Для поиска по условию обычно используют LINQ: journal.Where(s => s.StartsWith("Л")), journal.FirstOrDefault(...) — теме LINQ посвятим отдельный раздел.

    Count и Capacity

    Count — сколько элементов реально лежит. Capacity — под сколько места выделено. Когда Count догоняет Capacity, список удваивает Capacity:

    var nums = new List();
Console.WriteLine(nums.Capacity);    // 0

nums.Add(10);
Console.WriteLine(nums.Capacity);    // 4   — запас «на вырост»

nums.Add(1); nums.Add(2); nums.Add(3); nums.Add(4); nums.Add(5);
Console.WriteLine(nums.Count);       // 5
Console.WriteLine(nums.Capacity);    // 8   — вырос вдвое

    Если знаешь итоговый размер заранее — передай подсказку в конструктор (new List(1000)), чтобы не терять производительность на перевыделениях.

    Массив или список

    Правило простое: по умолчанию бери List, а массив — когда размер строго известен и неизменен или нужна максимальная скорость доступа с минимальным расходом памяти:

    Критерийint[]List<int>
    Размерфиксированныйдинамический
    Add / Removeвручную копироватьAdd(), RemoveAt()
    Скорость чтения [i]максимумпочти так же
    Скорость вставки в серединунужно сдвигать рукамисам сдвигает (O(n))
    LINQ-удобствачерез обёрткинативно

    Из списка легко вернуть массив обратно: int[] result = journal.ToArray();. А однотипный перебор любого из них умеет foreach.
