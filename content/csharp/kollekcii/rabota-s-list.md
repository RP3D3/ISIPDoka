# Поиск, сортировка и работа со списком

Как проверить наличие нужного значения в списке, упорядочить элементы и безопасно удалить лишние записи во время перебора?

Динамический список содержит готовые методы для быстрого поиска данных, сортировки и преобразования в обычный массив. Они избавляют от необходимости писать ручные циклы для типовых операций, но при изменении списка во время обхода требуют соблюдения важного правила.

### Основные методы поиска, сортировки и преобразования

| Метод | Что делает | Особенность работы |
| --- | --- | --- |
| `list.Contains(item)` | Проверяет, есть ли элемент в списке | Возвращает `true` или `false` |
| `list.IndexOf(item)` | Ищет позицию первого совпадения | Возвращает индекс или `-1`, если элемент не найден |
| `list.Sort()` | Сортирует элементы по возрастанию | Меняет исходный список на месте |
| `list.Reverse()` | Разворачивает порядок элементов задом наперёд | Меняет исходный список на месте |
| `list.ToArray()` | Копирует все элементы в новый обычный массив | Размер полученного массива становится фиксированным |

### Пример кода

```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        List<int> scores = new List<int> { 75, 40, 95, 30, 85 };

        // 1. Проверка наличия элемента и поиск его индекса
        if (scores.Contains(95))
        {
            int pos = scores.IndexOf(95);
            Console.WriteLine($"Балл 95 найден на позиции {pos}");
        }

        // 2. Сортировка по возрастанию и разворот (получаем порядок по убыванию)
        scores.Sort();    // { 30, 40, 75, 85, 95 }
        scores.Reverse(); // { 95, 85, 75, 40, 30 }

        // 3. Безопасное удаление элементов меньше 50 при переборе (обратный цикл for)
        for (int i = scores.Count - 1; i >= 0; i--)
        {
            if (scores[i] < 50)
            {
                scores.RemoveAt(i);
            }
        }

        // 4. Преобразование итогового списка в обычный массив
        int[] finalArray = scores.ToArray();
        Console.WriteLine($"Итоговый массив: {string.Join(", ", finalArray)}");
    }
}

```

### Важные нюансы

* **Нельзя удалять элементы внутри цикла `foreach`:** изменение размера списка во время обхода через `foreach` приводит к аварийной ошибке (`InvalidOperationException`). Для удаления по условию используйте обратный цикл `for` от `Count - 1` до `0` или метод `RemoveAll`.
* **Почему при удалении идут с конца к началу:** при удалении элемента с конца сдвигаются только уже проверенные ячейки, поэтому ни один непроверенный элемент не будет случайно пропущен.
* **`Sort` и `Reverse` меняют сам список:** эти методы не создают копию, а переставляют элементы прямо внутри текущего списка (для сортировки по убыванию сначала вызывают `Sort()`, а затем `Reverse()`).
* **Обратное преобразование из массива в список:** если нужно снова сделать массив динамическим, достаточно передать его в конструктор нового списка: `List<int> list = new List<int>(array);`.
