# Взвешенный случайный выбор

Обычный `rand()` даёт равные шансы. Но в игре меч должен выпадать реже зелья.
Для этого используют **веса**: у каждого варианта есть число, пропорциональное
его шансу.

## Простой алгоритм

1. Сложите все веса.
2. Возьмите случайное число от 0 до суммы.
3. Идите по списку, вычитая веса.
4. Когда число стало меньше веса — выбирайте этот вариант.

```text
items = [
  { name: "зелье", weight: 60 },
  { name: "меч",   weight: 30 },
  { name: "щит",   weight: 10 },
]

total = 100
roll = rand(0, total)

for item in items:
    if roll < item.weight:
        return item
    roll -= item.weight
```

## Вероятности

Вероятность варианта:

```text
p = weight / сумма_весов
```

В примере выше:

- зелье — 60%;
- меч — 30%;
- щит — 10%.

Сумма не обязана быть 100. Веса 6, 3, 1 дают те же шансы.

## Таблицы дропа

Взвешенный выбор часто оформляют как таблицу:

| Предмет | Вес | Редкость |
|---|---:|---|
| Зелье | 60 | обычный |
| Меч | 30 | редкий |
| Щит | 10 | эпический |

Таблицу удобно вынести в данные, а не хардкодить в коде. Тогда дизайнер может
менять шансы без пересборки.

## Ошибки

- **Отрицательные веса.** Ломают алгоритм.
- **Нулевые веса.** Вариант никогда не выпадет; это нормально, но проверяйте.
- **Сумма весов равна нулю.** Нужен fallback.
- **Забыли обновить таблицу.** Старые шансы остаются в коде.
- **Слишком много редких предметов.** Игрок получает всё сразу или ничего.

## Улучшения

- **Pity-система** — гарантия после N неудач.
- **Условные веса** — шанс зависит от уровня или прогресса.
- **Без повторов** — выбранный предмет убирается из пула.
- **Группы** — сначала выбирается категория, потом предмет внутри.
