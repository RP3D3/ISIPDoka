# AI: патруль и поведение

Врагу не нужен сложный интеллект, чтобы казаться живым. Часто достаточно
нескольких понятных состояний и честных правил.

## Состояния

Типичный набор:

- **Patrol** — ходит по точкам.
- **Alert** — заметил что-то, проверяет.
- **Chase** — преследует игрока.
- **Attack** — атакует.
- **Search** — ищет после потери цели.
- **Return** — возвращается на пост.

Переходы должны быть явными:

```text
Patrol -> Alert: услышал шум
Alert -> Chase: увидел игрока
Chase -> Attack: игрок в радиусе атаки
Chase -> Search: потерял игрока
Search -> Return: не нашёл
Return -> Patrol: дошёл до точки
```

## Восприятие

Враг не должен «видеть» сквозь стены. Простые проверки:

- расстояние;
- угол обзора;
- линия видимости (raycast);
- шум;
- память о последней позиции.

Это делает поведение читаемым.

## Патруль

Патруль — это набор точек или маршрут. Полезно:

- делать паузы;
- менять направление;
- иногда осматриваться;
- не ходить идеально одинаково.

Но предсказуемость тоже важна: игрок должен понимать маршрут.

## Погоня

При погоне нужны ограничения:

- максимальная дистанция;
- скорость;
- зона, за которую враг не выходит;
- таймер поиска;
- возврат домой.

Иначе враг может утащить игрока через полкарты.

## Отладка

- рисуйте состояние над врагом;
- показывайте радиусы;
- логируйте переходы;
- проверяйте, не застревает ли враг;
- смотрите, не теряет ли он игрока на ровном месте.

## Частые ошибки

- **Слишком много состояний сразу.**
- **Враг видит сквозь стены.**
- **Нет возврата домой.**
- **Погоня без ограничений.**
- **Переходы размазаны по коду.**
