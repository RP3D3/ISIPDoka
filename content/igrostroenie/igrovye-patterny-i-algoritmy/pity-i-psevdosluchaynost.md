# Pity-система и псевдослучайность

Чистый случайный выбор иногда даёт странные серии: десять зелий подряд или
редкий предмет с первого раза. Игрок воспринимает это как несправедливость.
Pity-система и псевдослучайность помогают сгладить такие ощущения.

## Pity-система

Pity — это счётчик неудач. После определённого числа попыток шанс повышается или
награда гарантируется.

```text
pity = 0
chance = 0.05

on_open():
    if pity >= 20:
        give_rare()
        pity = 0
        return

    if rand() < chance:
        give_rare()
        pity = 0
    else:
        pity += 1
```

Варианты:

- **жёсткая гарантия** — на N-й попытке предмет точно выпадает;
- **мягкая гарантия** — шанс растёт с каждой неудачей;
- **комбинированная** — рост шанса, затем гарантия.

## Псевдослучайное распределение

Pseudo-random distribution (PRD) повышает шанс после каждой неудачи и сбрасывает
его после успеха. Так реже случаются длинные серии неудач, но средний шанс
остаётся заданным.

```text
baseChance = 0.10
attempts = 0

chance = baseChance * (attempts + 1)
if rand() < chance:
    success()
    attempts = 0
else:
    attempts += 1
```

Это не «честнее» математически, но часто **ощущается** честнее.

## Где применять

- лут в RPG;
- критические удары;
- открытие карт;
- редкие события;
- награды за повторные попытки.

## Где не применять

- соревновательные игры, где скрытая подкрутка ломает доверие;
- головоломки с точным расчётом;
- ситуации, где игрок должен планировать на вероятностях.

Если система скрытая, игрок может почувствовать подыгрывание. Иногда лучше
показать счётчик гарантии.

## Ошибки

- **Слишком ранняя гарантия.** Редкость исчезает.
- **Слишком поздняя гарантия.** Игрок успевает уйти.
- **Скрытая система без объяснения.** Возникает недоверие.
- **Pity для всего.** Экономика становится предсказуемой и скучной.
- **Забыли сбросить счётчик.** Награды выдаются слишком часто.
