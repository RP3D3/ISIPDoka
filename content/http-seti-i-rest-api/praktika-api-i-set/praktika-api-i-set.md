# Практика: API и сеть

Главная идея области: API — это путь от требований к контракту, затем к
реализации и проверке.

## Маршрут

1. Требования.
2. Контракт.
3. Реализация.
4. Auth и CORS.
5. Проверка.
6. Тесты.
7. Итог.

## Что должно быть

- работающий API;
- понятные ошибки;
- проверка из браузера;
- тесты ключевых сценариев;
- README с запуском.

## Частые ошибки

- **Начать с кода.**
- **Забыть про роли.**
- **Не проверить CORS.**
- **Не описать ошибки.**
