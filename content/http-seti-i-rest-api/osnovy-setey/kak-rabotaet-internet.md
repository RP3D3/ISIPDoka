# Как работает интернет

Интернет — это сеть сетей. Клиент отправляет запрос, сервер отвечает.
Данные идут пакетами через несколько промежуточных узлов.

## Кто участвует

- клиент: браузер, мобильное приложение, `curl`;
- сервер: принимает соединение и отвечает;
- DNS: переводит домен в IP-адрес;
- маршрутизаторы: передают пакеты между сетями;
- провайдер: соединяет домашнюю сеть с интернетом.

## Путь запроса

1. Браузер разбирает URL.
2. DNS находит IP-адрес.
3. Устанавливается TCP-соединение.
4. Для HTTPS выполняется TLS.
5. Отправляется HTTP-запрос.
6. Сервер возвращает ответ.

## Пакеты

Данные делятся на пакеты. Они могут идти разными маршрутами и собираться
на стороне получателя. Поэтому важны порядок, подтверждения и повторная
отправка — этим занимается TCP.

## Частые ошибки

- **Думать, что интернет — это «облако».** Это физические сети и узлы.
- **Путать домен и IP.** Домен — имя, IP — адрес.
- **Игнорировать задержку.** Даже быстрый сервер зависит от сети.
- **Считать, что HTTPS заменяет авторизацию.** Это только защита канала.
