# Ошибки TLS

Браузер показывает ошибку TLS, когда не может проверить сертификат или
договориться о шифровании.

## Частые причины

- сертификат просрочен;
- сертификат выдан на другой домен;
- цепочка неполная;
- самоподписанный сертификат;
- старый TLS или шифр;
- неверное время на устройстве;
- корпоративный прокси подменяет сертификат.

## Что проверить

```bash
openssl s_client -connect example.com:443 -servername example.com
```

Смотрите:

- срок действия;
- SAN;
- издателя;
- цепочку;
- версию TLS.

## Частые ошибки

- **Нажимать «всё равно продолжить».** Это опасно.
- **Отключать проверку сертификата в коде.**
- **Игнорировать дату истечения.**
- **Использовать самоподписанный сертификат в продакшене.**
