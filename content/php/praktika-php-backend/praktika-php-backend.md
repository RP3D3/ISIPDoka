# Практика: PHP-бэкенд

Главная идея области: бэкенд — это не набор файлов, а контракт между
фронтендом, API и базой данных.

## Маршрут

1. Требования.
2. Схема базы.
3. Эндпоинты.
4. Валидация.
5. Реализация.
6. Связка с фронтендом.
7. Тесты.
8. Деплой.

## Что должно быть в результате

- работающий API;
- схема базы;
- единый формат ошибок;
- проверка через фронтенд;
- тесты;
- README с запуском.

## Частые ошибки

- **Начать с кода без плана.**
- **Забыть про роли и доступ.**
- **Не проверить API из браузера.**
- **Деплой без тестов.**
