# Основы PHP

Главная идея группы: PHP — серверный язык, который принимает запрос,
обрабатывает данные и возвращает ответ.

## Что запомнить

- PHP выполняется на сервере;
- файл начинается с `<?php`;
- переменные начинаются с `$`;
- типы динамические, но `strict_types` полезен;
- для сравнения лучше `===`;
- массивы бывают индексированные и ассоциативные;
- данные формы приходят через `$_GET` и `$_POST`;
- ввод нужно проверять и экранировать;
- ошибки пишут в лог, а не показывают пользователю.

## Частые ошибки

- **Забыть `<?php`.**
- **Доверять данным из формы.**
- **Показывать ошибки в продакшене.**
- **Путать массивы и объекты.**
