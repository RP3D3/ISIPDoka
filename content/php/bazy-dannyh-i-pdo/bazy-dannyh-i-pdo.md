# Базы данных и PDO

Главная идея группы: PHP не должен склеивать SQL и данные. PDO и
параметры делают работу с базой безопасной.

## Что запомнить

- SQL нужен даже при использовании ORM;
- PDO подключается через DSN;
- ошибки базы — через исключения;
- пользовательские данные передаются параметрами;
- CRUD требует проверки результата;
- транзакции нужны для связанных операций;
- JOIN помогает избежать N+1;
- пагинация требует `LIMIT` и проверки.

## Чек-лист

- [ ] Я не склеиваю SQL с вводом.
- [ ] Я использую `prepare` и `execute`.
- [ ] Я проверяю, что запись найдена.
- [ ] Я не показываю ошибки БД пользователю.
- [ ] Я умею откатить транзакцию.

## Частые ошибки

- **`UPDATE` без `WHERE`.**
- **Пароль БД в коде.**
- **`SELECT *` без необходимости.**
- **N+1 запросов в цикле.**
