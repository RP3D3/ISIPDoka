# Работа с файлами и папками (File, Path, Directory)

Как безопасно склеить путь к сохранению игры, создать недостающую папку и записать туда настройки так, чтобы код одинаково работал и в Windows, и в Linux?

:::gap

## Кратко

Пространство имён `System.IO` предоставляет три главных статичных класса для работы с файловой системой: `Path`, `Directory` и `File`. Класс `Path` безопасно собирает и разбирает пути с учётом разделителей конкретной операционной системы, `Directory` управляет папками и поиском файлов внутри них, а `File` позволяет в одну строчку читать, записывать, копировать и удалять файлы без ручного открытия потоков.

:::gap

## Быстрый пример

Создадим папку для сохранений, запишем туда файл конфигурации, прочитаем его содержимое и выведем список всех текстовых файлов:

```cs
// 1. Безопасно собираем путь с учётом разделителей текущей ОС
string folder = Path.Combine("Saves", "Player1");
string filePath = Path.Combine(folder, "profile.txt");

// 2. Создаём папку (если она уже есть — ошибки не будет)
Directory.CreateDirectory(folder);

// 3. Записываем и дописываем текст в файл (поток закроется автоматически)
File.WriteAllText(filePath, "Name=Артур\n");
File.AppendAllText(filePath, "Level=12\n");

// 4. Проверяем наличие файла и считываем его содержимое
if (File.Exists(filePath))
{
    string content = File.ReadAllText(filePath);
    Console.WriteLine($"Содержимое файла:\n{content}");
}

// 5. Получаем список всех .txt файлов в папке
string[] txtFiles = Directory.GetFiles(folder, "*.txt");
Console.WriteLine($"Найдено файлов: {txtFiles.Length}");

```

:::gap

## Как это работает

При выполнении кода среда .NET взаимодействует с файловой системой операционной системы по следующим шагам:

1. **Кроссплатформенная сборка пути (`Path.Combine`).** В Windows папки разделяются обратным слешем `\`, а в Linux и macOS — прямым `/`. Метод `Path.Combine` сам подставляет нужный разделитель текущей ОС и избавляет от лишних или пропущенных слешей на стыках.
2. **Создание каталогов (`Directory.CreateDirectory`).** Метод создаёт целевую папку `Player1`, а заодно и все недостающие родительские папки (`Saves`). Если папка уже существует, метод просто возвращает информацию о ней без исключений.
3. **Запись и чтение в один вызов (`File.WriteAllText`, `File.ReadAllText`).** Эти методы сами открывают файловый поток, записывают или считывают весь текст в кодировке UTF-8 и гарантированно закрывают файл через внутренний блок `using`.
4. **Поиск по маске (`Directory.GetFiles`).** Второй аргумент `"*.txt"` работает как фильтр по шаблону: `*` заменяет любое количество символов, а `?` — ровно один символ.

> [!TIP]
> Не пишите проверку `if (!Directory.Exists(folder)) Directory.CreateDirectory(folder);` — метод `CreateDirectory` уже проверяет существование папки внутри себя, причём делает это атомарно и без лишнего обращения к диску.

:::gap

## Грабли и частые ошибки

### 1. Ручная склейка путей через `"\\"` и случайные управляющие символы

* **Так сработает неправильно:** написать путь в обычной строке `"C:\Games\new_save.txt"`. Комбинация `\n` превратится в перенос строки, а жёсткий обратный слеш `\` сломает создание папок при запуске программы на Linux.
* **Так правильно:** всегда объединять части пути через `Path.Combine("Games", "new_save.txt")`, а для готовых локальных путей в Windows использовать verbatim-строки с символом `@`: `@"C:\Games\new_save.txt"`.

### 2. Чтение гигантских файлов через `File.ReadAllText` (`OutOfMemoryException`)

* **Так упадёт:** попытаться прочитать лог-файл или архив размером 3 ГБ методом `File.ReadAllText()` или `File.ReadAllBytes()`. Программа попытается загрузить весь файл в оперативную память разом и рухнет с нехваткой памяти.
* **Так правильно:** для больших текстовых файлов использовать ленивое построчное чтение через `foreach (string line in File.ReadLines(path))` или открывать поток `StreamReader`.

### 3. Чтение несуществующего файла без проверки (`FileNotFoundException`)

* **Так упадёт:** вызвать `File.ReadAllText("config.json")` при первом запуске игры, когда файл настроек ещё не создан. Среда выбросит исключение `FileNotFoundException` (а если нет и самой папки — `DirectoryNotFoundException`).
* **Так правильно:** предварительно проверять наличие файла через `if (File.Exists(path))` и при его отсутствии создавать настройки по умолчанию.

### 4. Поиск файла рядом с `Program.cs` по короткому имени `"data.txt"`

* **Так сработает неправильно:** положить файл в папку с исходным кодом и пытаться открыть `"data.txt"`. При запуске программа ищет относительные пути в рабочей директории скомпилированного `.exe` (обычно `bin/Debug/net8.0/`), где этого файла может не оказаться.
* **Так правильно:** явно привязывать путь к папке с исполняемым файлом через `Path.Combine(AppContext.BaseDirectory, "data.txt")` или включать копирование файла в выходной каталог в свойствах проекта.

:::gap

## Под капотом и нюансы

### Статичные `File` / `Directory` против экземплярных `FileInfo` / `DirectoryInfo`

В пространстве `System.IO` есть две пары классов с похожими возможностями, но разным устройством:

* **Статичные `File` и `Directory**` удобны для разовых операций («проверил, прочитал, забыл»). Однако при каждом вызове любого метода операционная система заново выполняет проверку прав доступа (ACL) к файлу.
* **Экземплярные `FileInfo` и `DirectoryInfo**` создают объект в памяти и при первом обращении кешируют метаданные файла (`Length`, `CreationTime`, `Extension`). Если вы в цикле проверяете размер, дату изменения и атрибуты тысяч файлов, `FileInfo` сработает заметно быстрее.

### Кодировка текста по умолчанию

В современном .NET все текстовые методы класса `File` (`WriteAllText`, `ReadAllText`, `AppendAllLines`) по умолчанию работают в кодировке **UTF-8 без BOM** (*Byte Order Mark*). Если вам нужно прочитать старый файл в кодировке Windows-1251, кодировку можно передать последним параметром явно.

### Шпаргалка по популярным методам `System.IO`

| Метод | Что делает |
| --- | --- |
| `Path.Combine(a, b, c)` | Безопасно соединяет части пути с разделителем текущей ОС |
| `Path.GetFileNameWithoutExtension(p)` | Возвращает имя файла без пути и без расширения (`"profile"`) |
| `Path.GetExtension(p)` | Возвращает расширение файла вместе с точкой (`".txt"`) |
| `Directory.CreateDirectory(p)` | Создаёт папку и все недостающие промежуточные каталоги |
| `Directory.EnumerateFiles(p, "*.cs")` | Лениво перебирает файлы по маске (выгоднее `GetFiles` на больших папках) |
| `File.ReadAllText(p)` / `File.WriteAllText(p, s)` | Считывает весь файл в строку или полностью перезаписывает его |
| `File.AppendAllText(p, s)` | Дописывает строку в конец файла (создаёт файл, если его ещё нет) |
| `File.Copy(src, dst, overwrite: true)` | Копирует файл в новое место с разрешением перезаписи |
