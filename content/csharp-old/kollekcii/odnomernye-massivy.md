# Одномерные массивы (T[])

Как хранить список из десяти лучших рекордов игрока или оценки целой группы в одной переменной вместо десятка отдельных?

:::gap

## Кратко

Одномерный массив — это пронумерованный ряд ячеек в памяти, где подряд лежат элементы одного и того же типа (например, только числа или только строки). Он нужен, когда заранее известно точное количество данных и к любому элементу требуется мгновенный доступ по его порядковому номеру. В отличие от списков `List<T>`, размер массива задаётся один раз при создании и больше не меняется.

:::gap

## Быстрый пример

Создадим массив с готовыми данными и пустой массив, изменим элемент по индексу и переберём значения:

```cs
// Массив с начальными значениями (выражение коллекции) и пустой массив на 3 ячейки
int[] scores = [10, 25, 40, 15];
string[] names = new string[3]; // [null, null, null]

// Доступ и изменение по индексу (отсчёт всегда идёт с нуля)
scores[1] = 30;
Console.WriteLine(scores[1]);     // 30
Console.WriteLine(scores[^1]);    // 15 (первый элемент с конца)
Console.WriteLine(scores.Length); // 4 (количество ячеек)

// Перебор всех элементов
foreach (int score in scores)
{
    Console.Write($"{score} ");   // 10 30 40 15
}

```

:::gap

## Как это работает

При выполнении кода среда .NET резервирует в памяти непрерывный блок ячеек и связывает его с переменной:

1. **Создание массива (`int[]` и `new`).** Квадратные скобки после типа говорят компилятору, что перед нами массив. Запись `[10, 25, 40, 15]` (или классическая `new int[] { 10, 25, 40, 15 }`) создаёт ряд из 4 заполненных ячеек. Если значения заранее неизвестны, конструкцией `new string[3]` выделяют пустой массив нужной длины — он автоматически заполняется значениями по умолчанию (`0` для чисел, `false` для `bool`, `null` для ссылочных типов).
2. **Индексация с нуля (`scores[1]`).** Нумерация ячеек в C# всегда начинается с `0`, поэтому первый элемент имеет индекс `0`, второй — `1`, а последний в массиве из 4 элементов — `3`. Строка `scores[1] = 30` перезаписывает вторую ячейку.
3. **Индекс с конца (`scores[^1]`).** Оператор `^` отсчитывает позиции от правого края: `^1` всегда указывает на самый последний элемент массива, а `^2` — на предпоследний.
4. **Длина и перебор (`Length` и `foreach`).** Свойство `Length` возвращает общее число ячеек (`4`). Цикл `foreach` последовательно проходит по каждому элементу от начала до конца без необходимости вручную следить за индексами.

> [!TIP]
> Если количество элементов заранее неизвестно и постоянно меняется (вы часто добавляете или удаляете записи), вместо массива лучше взять `List<T>` — массив хорош там, где размер фиксирован.

:::gap

## Грабли и частые ошибки

### 1. Выход за границы массива (`IndexOutOfRangeException`)

* **Так упадёт:** обратиться к `scores[4]` в массиве длиной `4` или написать `scores[^0]`. Поскольку отсчёт начинается с нуля, последний допустимый индекс равен `Length - 1`, и программа завершится с исключением `IndexOutOfRangeException`.
* **Так правильно:** ограничивать циклы `for` строгим условием `i < array.Length` и использовать `^1` для получения последнего элемента.

### 2. Попытка изменить размер массива после создания

* **Так не скомпилируется:** написать `scores.Length = 5;` или искать у массива методы `.Add()` и `.Remove()` — свойство `Length` доступно только для чтения (ошибка `CS0200`), а длина фиксируется навсегда.
* **Так правильно:** пересоздать массив с новым размером через `Array.Resize(ref scores, 5)` или сразу использовать динамический список `List<T>`.

### 3. Копирование и сравнение массивов через `=` и `==`

* **Так сработает неправильно:** написать `int[] copy = scores;` и изменить `copy[0] = 99;`, ожидая, что исходный `scores` не изменится. Массив — ссылочный тип, поэтому обе переменные указывают на один и тот же блок памяти, а проверка `scores == copy` сравнивает адреса, а не содержимое.
* **Так правильно:** для создания независимой копии использовать `[..scores]` (или `(int[])scores.Clone()`), а для сравнения элементов — `scores.SequenceEqual(copy)`.

### 4. Вызов методов у пустых ячеек ссылочного массива (`NullReferenceException`)

* **Так упадёт:** создать `string[] words = new string[3];` и сразу вызвать `words[0].ToUpper()`. Память выделилась только под 3 пустые ссылки (`null`), а самих строк внутри ещё нет.
* **Так правильно:** сначала записать в ячейку реальный объект (`words[0] = "текст";`) перед обращением к его методам.

:::gap

## Под капотом и нюансы

### Устройство в памяти и мгновенный доступ `O(1)`

В .NET любой массив (наследуется от абстрактного класса `System.Array`) является **ссылочным типом** и всегда выделяется в управляемой куче (*Heap*), даже если внутри лежат значимые типы вроде `int` или `double`.

Главная особенность массива — все его элементы располагаются в оперативной памяти **единым непрерывным куском** друг за другом без разрывов. Благодаря этому процессор вычисляет точный адрес любой ячейки за одну простую операцию: `Адрес_начала + (индекс * размер_элемента)`. Поэтому обращение к миллионному элементу работает с той же мгновенной скоростью, что и к первому — за константное время `O(1)`.

### Срезы и диапазоны (`Range`)

Помимо индексации с конца `^1`, в C# можно вырезать подмассив с помощью оператора диапазона `..`:

```cs
int[] nums = [10, 20, 30, 40, 50];
int[] middle = nums[1..4]; // [20, 30, 40] (правая граница 4 не включается)
int[] tail = nums[2..];    // [30, 40, 50] (от индекса 2 до конца)

```

Учитывайте, что срез `nums[1..4]` выделяет в куче **новый** массив и копирует туда элементы. Если нужно быстро обработать фрагмент массива без копирования и затрат памяти, используйте `Span<int> slice = nums.AsSpan(1, 3);`.

### Полезные статические методы класса `Array`

| Метод | Назначение | Пример |
| --- | --- | --- |
| `Array.Sort(arr)` | Сортирует элементы массива по возрастанию на месте (*in-place*) | `Array.Sort(scores);` |
| `Array.Reverse(arr)` | Разворачивает порядок элементов в массиве задом наперёд | `Array.Reverse(scores);` |
| `Array.IndexOf(arr, val)` | Возвращает индекс первого найденного элемента (или `-1`) | `int idx = Array.IndexOf(scores, 40);` |
| `Array.Clear(arr)` | Сбрасывает все ячейки в значения по умолчанию (`0` или `null`) | `Array.Clear(scores);` |
| `Array.Copy(src, dst, len)` | Быстро копирует блок элементов из одного массива в другой | `Array.Copy(a, b, 3);` |

> [!WARNING]
> Массивы ссылочных типов в C# **ковариантны**: массив `string[]` можно присвоить переменной `object[]`. Однако при попытке записать туда число (`object[] arr = new string[2]; arr[0] = 123;`) программа пройдёт компиляцию, но упадёт во время выполнения с `ArrayTypeMismatchException` — среда .NET при каждой записи проверяет реальный тип элементов в куче.
