# Ввод с клавиатуры

Как получить имя игрока, число для калькулятора или мгновенное нажатие клавиши прямо во время работы программы?

:::gap

## Кратко

Методы `Console.ReadLine` и `Console.ReadKey` останавливают выполнение программы и ждут, пока пользователь что-нибудь введёт с клавиатуры. Первый читает целую строку текста до нажатия `Enter`, а второй мгновенно реагирует на одиночное нажатие любой кнопки. Это основной способ сделать консольное приложение интерактивным: принимать команды, запрашивать данные или управлять меню.

:::gap

## Быстрый пример

Считаем текстовую строку, преобразуем ввод в число и поймаем нажатие клавиши:

```cs
// ReadLine ждёт ввода строки и нажатия Enter
string? name = Console.ReadLine(); // Например: "Макс"

// Ввод всегда приходит как строка — для чисел нужна конвертация
int age = int.Parse(Console.ReadLine()!); // Например: "20" -> 20
Console.WriteLine($"{name}, через год вам будет {age + 1}");

// ReadKey срабатывает мгновенно от одного нажатия (true скрывает символ)
ConsoleKeyInfo key = Console.ReadKey(intercept: true);
if (key.Key == ConsoleKey.Spacebar)
{
    Console.WriteLine("Нажат пробел!");
}

```

:::gap

## Как это работает

При вызове методов ввода программа обращается к стандартному потоку ввода операционной системы и ждёт действий пользователя:

1. **Чтение всей строки (`Console.ReadLine`).** Выполнение замирает до тех пор, пока пользователь не наберёт текст и не нажмёт `Enter`. Символы перевода строки в конце отбрасываются, а сам текст возвращается в виде строки `string?`.
2. **Преобразование текста в число (`int.Parse`).** Клавиатура всегда передаёт символы, даже если пользователь нажал цифры `2` и `0`. Чтобы работать с ними как с числом, строку пропускают через `int.Parse()`, превращая текст `"20"` в значение типа `int`.
3. **Мгновенный перехват кнопки (`Console.ReadKey`).** Этот метод не ждёт `Enter` и возвращает управление сразу после нажатия любой клавиши. Аргумент `intercept: true` запрещает консоли печатать нажатый символ на экране.
4. **Проверка нажатой клавиши (`ConsoleKeyInfo`).** Результат `ReadKey` сохраняется в структуру `ConsoleKeyInfo`. Через свойство `key.Key` мы сравниваем нажатую кнопку с константой из перечисления `ConsoleKey` (например, `ConsoleKey.Spacebar` для пробела).

> [!TIP]
> Для безопасного чтения чисел от пользователя лучше использовать `int.TryParse(Console.ReadLine(), out int age)` — этот метод вернёт `false`, но не уронит программу при случайной опечатке.

:::gap

## Грабли и частые ошибки

### 1. Попытка сохранить результат `ReadLine` сразу в числовую переменную

* **Так не скомпилируется:** написать `int number = Console.ReadLine();`. Метод всегда возвращает строку (`string?`), а не число — компилятор остановит сборку с ошибкой `CS0029`.
* **Так правильно:** явно конвертировать строку в число через `int.TryParse` или `int.Parse`.

### 2. Падение программы при вводе букв вместо числа

* **Так упадёт:** написать `int age = int.Parse(Console.ReadLine()!);` и ввести с клавиатуры `"двадцать"` или просто нажать `Enter` на пустой строке — приложение аварийно закроется с исключением `FormatException`.
* **Так правильно:** проверять корректность ввода через `if (int.TryParse(Console.ReadLine(), out int age))` и просить повторить ввод, если метод вернул `false`.

### 3. Путаница между `Console.Read()` и `Console.ReadKey()`

* **Так сработает неправильно:** вызвать `int num = Console.Read();` и ввести цифру `1`. Метод `Read()` всё равно ждёт нажатия `Enter`, а возвращает не само число `1`, а код символа `'1'` в таблице Юникода — число `49`.
* **Так правильно:** для мгновенной реакции на клавишу использовать `Console.ReadKey()`, а для чтения чисел — `Console.ReadLine()` с последующим парсингом.

### 4. Игнорирование возможного `null` при закрытии потока ввода

* **Так упадёт:** передать `Console.ReadLine()!` напрямую в `int.Parse()` и нажать в терминале комбинацию конца файла (`Ctrl + Z` и `Enter` в Windows или `Ctrl + D` в Linux/macOS) — `ReadLine()` вернёт `null`, и `int.Parse` выбросит `ArgumentNullException`.
* **Так правильно:** использовать `int.TryParse`, который безопасно принимает `null` и просто возвращает `false`.

:::gap

## Под капотом и нюансы

### Сравнение всех методов чтения из `Console`

| Метод | Ждёт `Enter`? | Возвращаемый тип | Что возвращает |
| --- | --- | --- | --- |
| `Console.ReadLine()` | Да | `string?` | Всю введённую строку без символов переноса (или `null` при EOF) |
| `Console.ReadKey(bool)` | Нет | `ConsoleKeyInfo` | Информацию о нажатой физической клавише, символе и модификаторах |
| `Console.Read()` | Да | `int` | Код одного следующего символа из буфера (или `-1`, если поток закрыт) |

### Как устроен `ConsoleKeyInfo` и почему `Key` лучше `KeyChar`

Структура `ConsoleKeyInfo`, которую возвращает `ReadKey()`, хранит сразу три характеристики нажатия:

* `Key` (`ConsoleKey`) — код физической клавиши, который **не зависит от языка раскладки**. Если вы делаете управление на `W`, `A`, `S`, `D` и проверяете `key.Key == ConsoleKey.W`, оно сработает даже при включённой русской раскладке (`Ц`).
* `KeyChar` (`char`) — конкретный напечатанный символ с учётом регистра и языка (`'w'`, `'W'`, `'ц'`). Для служебных клавиш вроде стрелок или `F1` содержит нулевой символ `\0`.
* `Modifiers` (`ConsoleModifiers`) — битовая маска зажатых клавиш-модификаторов (`Shift`, `Alt`, `Control`).

### Буферизация ввода и почему нельзя смешивать `Read()` и `ReadLine()`

Стандартный поток ввода `Console.In` работает через строковый буфер операционной системы. Пока пользователь печатает текст и не нажал `Enter`, символы накапливаются в буфере ОС и не передаются программе. Когда нажимается `Enter`, в буфер попадает весь текст вместе с символами переноса строки (`\r\n` в Windows или `\n` в Linux).

`Console.ReadLine()` забирает из буфера всю строку целиком и очищает перенос. А вот `Console.Read()` забирает только один первый символ, оставляя `\r\n` лежать в буфере — следующий вызов `ReadLine()` после него мгновенно прочитает этот пустой хвост и не станет ждать пользователя.

### Пример: скрытый ввод пароля

С помощью `Console.ReadKey(true)` можно реализовать классический ввод пароля со звёздочками `*` и поддержкой удаления через `Backspace`:

```cs
using System.Text;

var password = new StringBuilder();
while (true)
{
    ConsoleKeyInfo key = Console.ReadKey(intercept: true);
    if (key.Key == ConsoleKey.Enter) break;

    if (key.Key == ConsoleKey.Backspace && password.Length > 0)
    {
        password.Length--;
        Console.Write("\b \b"); // Стираем последнюю звёздочку в консоли
    }
    else if (!char.IsControl(key.KeyChar))
    {
        password.Append(key.KeyChar);
        Console.Write("*");
    }
}

```
