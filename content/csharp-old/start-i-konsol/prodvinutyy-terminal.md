# Продвинутый терминал

Как превратить скучное чёрное окно консоли в интерактивное меню, живой прогресс-бар или простую игру вроде «Змейки»?

:::gap

## Кратко

Стандартный класс `Console` умеет не только печатать строки по очереди, но и управлять окном терминала как двумерным холстом. Вы можете перемещать курсор в любую точку экрана, менять цвета символов и фона, скрывать мигающую каретку и мгновенно ловить нажатия клавиш без ожидания `Enter`. Это превращает обычный скрипт в удобную CLI-утилиту с навигацией стрелками или плавной анимацией.

:::gap

## Быстрый пример

Очистим экран, нарисуем цветную плашку по точным координатам и поймаем нажатие клавиши без вывода символа в консоль:

```cs
Console.CursorVisible = false; // Прячем мигающий курсор
Console.Clear();               // Очищаем окно

// Ставим курсор на 10-й столбец, 3-ю строку и задаём цвета
Console.SetCursorPosition(10, 3);
Console.ForegroundColor = ConsoleColor.Black;
Console.BackgroundColor = ConsoleColor.Cyan;
Console.Write(" [ Нажмите Esc для выхода ] ");
Console.ResetColor(); // Возвращаем стандартную палитру

// Читаем клавишу мгновенно без Enter и без отображения символа (intercept: true)
ConsoleKeyInfo key = Console.ReadKey(intercept: true);
if (key.Key == ConsoleKey.Escape)
{
    Console.Clear();
}

```

:::gap

## Как это работает

При выполнении кода программа обращается к буферу окна терминала и управляет его состоянием напрямую:

1. **Подготовка экрана (`CursorVisible` и `Clear`).** Сначала программа отключает мигающий текстовый курсор, чтобы он не мелькал поверх интерфейса, и очищает окно от системных сообщений.
2. **Позиционирование (`SetCursorPosition`).** Координаты в терминале отсчитываются от левого верхнего угла `(0, 0)`. Первое число (`10`) задаёт отступ слева по горизонтали (`Left`), второе (`3`) — номер строки сверху вниз (`Top`).
3. **Раскраска (`ForegroundColor` и `BackgroundColor`).** Мы меняем цвет букв на чёрный, а фон заливки — на голубой. Всё, что напечатает `Console.Write` после этих строк, выведется в новой цветовой схеме.
4. **Сброс стилей (`ResetColor`).** Возвращает цвета терминала к исходным настройкам пользователя, чтобы последующий вывод не остался на голубом фоне.
5. **Перехват клавиш (`ReadKey(true)`).** Метод ставит программу на паузу до первого нажатия любой кнопки. Аргумент `intercept: true` запрещает консоли печатать нажатый символ на экране, а результат попадает в структуру `ConsoleKeyInfo`, где конкретную клавишу удобно проверить через `key.Key`.

> [!TIP]
> Чтобы проверить комбинации вроде `Ctrl + S` или `Shift + Tab`, используйте свойство `key.Modifiers` (например, `key.Modifiers.HasFlag(ConsoleModifiers.Control)`).

:::gap

## Грабли и частые ошибки

### 1. Выход координат за границы окна (`SetCursorPosition`)

* **Так упадёт:** передать координаты больше текущего размера консоли, например `Console.SetCursorPosition(500, 100);` — программа выбросит исключение `ArgumentOutOfRangeException`.
* **Так правильно:** перед перемещением курсора проверять реальные размеры окна через `Console.WindowWidth` и `Console.WindowHeight` (учитывая, что индексы идут от `0` до `Width - 1`).

### 2. Забытый `Console.ResetColor()`

* **Так сработает неправильно:** покрасить сообщение в красный цвет и выйти из приложения без сброса. После закрытия вашей программы вся командная строка пользователя останется красной.
* **Так правильно:** всегда вызывать `Console.ResetColor()` сразу после вывода цветного блока или оборачивать работу в блок `try ... finally`.

### 3. Зависание анимации на `Console.ReadKey()`

* **Так сработает неправильно:** вызвать `Console.ReadKey()` внутри цикла отрисовки игры или прогресс-бара — вся программа остановится и будет ждать, пока пользователь нажмёт клавишу.
* **Так правильно:** сначала проверять наличие нажатия в буфере через `if (Console.KeyAvailable)` и только после этого вызывать `Console.ReadKey(true)`.

### 4. Работа в среде без интерактивного окна

* **Так упадёт:** запустить утилиту с `Clear()` или `SetCursorPosition` при перенаправлении вывода в файл (`app.exe > log.txt`) или в фоновой службе — вызов выбросит `IOException`.
* **Так правильно:** проверять свойство `Console.IsOutputRedirected` перед вызовом методов управления курсором и очисткой экрана.

> [!IMPORTANT]
> Если вы скрыли курсор через `Console.CursorVisible = false`, обязательно верните `true` перед завершением программы — в некоторых терминалах курсор остаётся невидимым даже после закрытия приложения.

:::gap

## Под капотом и нюансы

### Сетка знакомест вместо полной перерисовки

Экран терминала устроен как двумерная таблица ячеек (знакомест), где каждая клетка хранит один символ и его цвета. Если в цикле постоянно вызывать `Console.Clear()` и рисовать кадр заново, экран начнёт заметно мерцать. Вместо этого в консольных играх и TUI-интерфейсах очищают только изменившиеся клетки: ставят курсор через `SetCursorPosition` на старую позицию объекта, печатают пробел `' '` и рисуют объект на новых координатах.

### Полезные свойства и события `Console`

| Элемент | Тип | Назначение |
| --- | --- | --- |
| `Console.WindowWidth` / `WindowHeight` | `int` | Текущая ширина и высота видимой области в символах |
| `Console.KeyAvailable` | `bool` | Возвращает `true`, если в буфере клавиатуры есть нажатие (не блокирует поток) |
| `Console.TreatControlCAsInput` | `bool` | Если `true`, комбинация `Ctrl + C` не закрывает программу, а ловится через `ReadKey` |
| `Console.CancelKeyPress` | Событие | Срабатывает при нажатии `Ctrl + C`, позволяя корректно сбросить цвета и курсор перед выходом |
| `Console.Beep(freq, ms)` | Метод | Воспроизводит звуковой сигнал заданной частоты и длительности (работает только в Windows) |

### Как это работает на разных ОС и TrueColor (RGB)

В Windows класс `Console` напрямую вызывает функции системного Win32 API (`SetConsoleCursorPosition`, `SetConsoleTextAttribute`). В Linux и macOS такого API нет, поэтому среда .NET прозрачно преобразует вызовы свойств `Console` в **ANSI escape-последовательности** и отправляет их в стандартный поток вывода.

Перечисление `ConsoleColor` ограничено 16 базовыми цветами, но современные терминалы (Windows Terminal, iTerm2, GNOME Terminal) понимают 24-битные RGB-цвета напрямую через ANSI-коды:

```cs
// Вывод текста произвольным RGB-цветом (R=255, G=120, B=50)
Console.WriteLine("\x1b[38;2;255;120;50mОранжевый TrueColor текст\x1b[0m");

```
