# Базовые методы строк (Length, Contains, Split, Replace, Trim)

Как убрать случайные пробелы в логине пользователя, проверить наличие запрещённого слова в чате или разбить строку данных по запятым?

:::gap

## Кратко

Встроенные свойства и методы класса `string` позволяют очищать, проверять, заменять и разрезать текст без написания сложных циклов вручную. С их помощью можно за одну строчку узнать длину пароля, отрезать лишние пробелы по краям, найти нужное слово или превратить строку с перечислением товаров в готовый массив. Важно помнить, что эти методы не меняют исходную строку, а всегда возвращают новую обработанную копию.

:::gap

## Быстрый пример

Очистим пользовательский ввод, проверим содержимое, заменим разделитель и разобьём текст на массив:

```cs
string rawInput = "  sword, shield, potion  ";

string clean = rawInput.Trim();                // "sword, shield, potion"
Console.WriteLine(clean.Length);               // 21 (количество символов)
Console.WriteLine(clean.Contains("shield"));   // True (подстрока найдена)

string updated = clean.Replace(", ", "|");     // "sword|shield|potion"
string[] items = updated.Split('|');           // ["sword", "shield", "potion"]
Console.WriteLine(items[1]);                   // shield

```

:::gap

## Как это работает

При выполнении кода методы вызываются по цепочке, создавая на каждом шаге новую строку с нужным результатом:

1. **Обрезка краёв (`Trim`).** Метод `Trim()` удаляет все пробельные символы (пробелы, табуляцию, переносы строк) в самом начале и в самом конце строки, но не трогает пробелы внутри текста.
2. **Подсчёт длины (`Length`).** Обратите внимание, что `Length` — это свойство, а не метод, поэтому круглые скобки `()` после него не ставятся. Оно возвращает точное количество символов `char` в очищенной строке (`21`).
3. **Поиск подстроки (`Contains`).** Метод проверяет, встречается ли фрагмент `"shield"` внутри строки, и возвращает логическое значение `true` или `false`.
4. **Замена текста (`Replace`).** Находит все вхождения `", "` в строке и заменяет их на вертикальную черту `"|"`. Исходная переменная `clean` при этом остаётся прежней.
5. **Разделение на части (`Split`).** Режет строку по символу-разделителю `'|'` и упаковывает получившиеся куски в массив строк `string[]`, к элементам которого можно обращаться по индексу (`items[1]` вернёт `"shield"`).

> [!TIP]
> Методы строк можно выстраивать в удобную цепочку (*chaining*) в одну строчку: `string[] items = rawInput.Trim().Replace(", ", "|").Split('|');`.

:::gap

## Грабли и частые ошибки

### 1. Вызов метода без сохранения результата

* **Так сработает неправильно:** написать `text.Trim();` или `text.Replace("a", "b");` отдельной строкой и ожидать, что переменная `text` обновится. Из-за неизменяемости строк исходная переменная останется прежней.
* **Так правильно:** всегда записывать результат в переменную: `text = text.Trim();`.

### 2. Забытый регистр букв при поиске в `Contains` и `Replace`

* **Так сработает неправильно:** вызвать `"Привет, мир".Contains("привет")` — метод вернёт `false`, потому что по умолчанию сравнение строк в C# чувствительно к регистру (`'П' != 'п'`).
* **Так правильно:** передавать вторым аргументом режим сравнения без учёта регистра: `text.Contains("привет", StringComparison.OrdinalIgnoreCase)`.

### 3. Лишние пустые элементы после `Split`

* **Так сработает неправильно:** разбить строку с несколькими запятыми подряд `"a,,b".Split(',')` — в итоговом массиве окажутся три элемента: `["a", "", "b"]`, где посередине затесалась пустая строка.
* **Так правильно:** передавать флаги очистки и удаления пустых записей: `text.Split(',', StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries)`.

### 4. Круглые скобки у `Length`

* **Так не скомпилируется:** написать `text.Length()` по аналогии с методами `Trim()` или `Split()`. В C# `Length` — это свойство, поэтому компилятор выдаст ошибку `CS1955`.
* **Так правильно:** обращаться без скобок: `text.Length`.

:::gap

## Под капотом и нюансы

### Полезные соседи базовых методов

Помимо пятёрки основных инструментов, в повседневной работе часто пригодятся их ближайшие родственники:

| Метод | Что делает | Пример |
| --- | --- | --- |
| `TrimStart()` / `TrimEnd()` | Удаляют пробелы (или указанные символы) только слева или только справа | `"###текст###".Trim('#')` > `"текст"` |
| `StartsWith()` / `EndsWith()` | Проверяют, начинается или заканчивается ли строка на нужный фрагмент | `"report.pdf".EndsWith(".pdf")` > `true` |
| `IndexOf()` / `LastIndexOf()` | Возвращают индекс первого или последнего вхождения подстроки (или `-1`) | `"abcabc".IndexOf('b')` > `1` |
| `Substring()` / диапазоны | Вырезают кусок строки начиная с указанного индекса | `text[..5]` или `text.Substring(0, 5)` |
| `string.Join()` | Операция, обратная `Split`: склеивает массив строк обратно через разделитель | `string.Join(", ", items)` |

### Аллокации памяти при цепочках методов и `Split`

Поскольку каждый вызов `Trim`, `Replace` или `Split` создаёт в управляемой куче новые объекты `string` (и массив `string[]`), активная нарезка текста внутри горячих циклов создаёт заметную нагрузку на сборщик мусора (GC). При этом метод `Trim()` оптимизирован: если строка уже не содержит пробелов по краям, он не выделяет новую память, а возвращает ссылку на ту же самую исходную строку.

### Современная альтернатива без лишней памяти: `Span<char>`

В высоконагруженном коде (например, при парсинге огромных CSV-файлов или сетевых логов) вместо `Split()` и `Substring()` используют метод `.AsSpan()`. Он возвращает структуру `ReadOnlySpan<char>` — легковесное «окно» поверх исходной строки в стеке, которое позволяет резать и проверять фрагменты текста с нулевым выделением памяти в куче:

```cs
ReadOnlySpan<char> span = "user_id=42".AsSpan();
ReadOnlySpan<char> idPart = span.Slice(8); // "42" без создания новой строки в куче

```

> [!NOTE]
> В `Trim()`, `TrimStart()` и `TrimEnd()` можно передать любые символы для обрезки, а не только пробелы: например, `url.Trim('/')` аккуратно уберёт лишние слэши с обоих концов адреса.
