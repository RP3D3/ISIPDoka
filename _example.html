Циклы: пример оформления темы

Как повторять действия в C#, чем отличаются while, do while, for и foreach и как не получить бесконечный цикл.

Зачем нужны циклы

Цикл повторяет один и тот же блок кода, пока условие остаётся истинным. Без циклов пришлось бы копировать строки вручную — и легко ошибиться в количестве повторений.

  • обработать все элементы коллекции;
  • повторять запрос, пока пользователь не введёт корректное значение;
  • выполнить действие ровно N раз.

Важно: условие цикла в C# всегда имеет тип bool. Число само по себе условием не является.

Цикл while

while проверяет условие до каждой итерации. Если условие сразу ложно, тело цикла не выполнится ни разу. 

int attempts = 0;

while (attempts < 3)
{
    Console.WriteLine($"Попытка {attempts + 1}");
    attempts++;
}

Как читать условие

Условие — это вопрос, на который программа отвечает «да» или «нет». В примере вопрос звучит так: «попыток меньше трёх?». Как только ответ становится «нет», цикл завершается.

Сравнение циклов

Выбор цикла зависит от того, что известно заранее: количество повторений или условие выхода.

Цикл Когда использовать Особенность
while Количество повторений неизвестно Проверяет условие до итерации
do while Тело должно выполниться хотя бы раз Проверяет условие после итерации
for Известно число повторений Инициализация, условие и шаг в одной строке
foreach Нужно перебрать коллекцию Не требует ручного управления индексом

Типичные ошибки

  • Забыть изменить переменную условия — получится бесконечный цикл.
  • Изменить условие в теле так, что оно никогда не станет ложным.
  • Использовать while там, где достаточно foreach.
  • Сравнивать число с true вместо явного условия.

Чек-лист

  • Условие цикла имеет тип bool.
  • Переменная условия меняется внутри тела.
  • Есть понятный способ выйти из цикла.
  • Для коллекции выбран foreach, если индекс не нужен.
